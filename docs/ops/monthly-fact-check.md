# Ежемесячная сверка уроков с документацией

Запускается сама 1-го числа каждого месяца (запланированная задача «Navyk: ежемесячная сверка уроков»).
Цель — чтобы уроки не устаревали: функции, названия кнопок, тарифы и лимиты Claude меняются часто.

## Что проверять

1. Все уроки с `volatile: true` в шапке (`content/**/*.ru.md`) — см. `grep -l "volatile: true" content/*/*/*.ru.md`.
2. Все факты из `content/data/volatile/*.md` (таблицы «что, где проверено, ссылка, дата»).
3. Значения в `content/data/ui.json` и `content/data/modules/*.json` (названия кнопок, тарифы, лимиты, ID моделей, цены API).
4. Раздел «Быстро меняющиеся темы» в `research/02-curriculum.md` и release notes:
   https://support.claude.com/en/articles/12138966-release-notes (если адрес изменился — найти через поиск).

Источники — только официальные: support.claude.com, platform.claude.com/docs, code.claude.com/docs,
claude.com/pricing, modelcontextprotocol.io, anthropic.com/engineering. Не по памяти.

## Как исправлять

- Сначала данные (`ui.json`, `modules/*.json`): там названия, тарифы, лимиты — правка сразу во всех языках (ru, uk, en, pl).
- Если изменилась суть (функция переименована, убрана, работает иначе) — правка текста урока во всех четырёх языках
  с той же структурой (сборка сверяет структуру с ru).
- В изменённых уроках обновить `verified_at` и `sources` (url + что подтверждает), в `content/data/volatile/*.md` — дату и ссылку.
- Если факт не удаётся подтвердить — не утверждать его; сформулировать осторожно и записать в отчёт.
- Тон уроков: «ты», мужской род во всех языках; названия элементов интерфейса Claude — по-английски.

## Проверка перед PR

```bash
python3 scripts/build_content.py          # должно быть «OK: … уроков»
python3 scripts/build_course_md.py
cd server && npm test && cd ../web && node --test test/index.js
```

## Результат

- Изменения — в ветке `factcheck/<ГГГГ-ММ>` и pull request в `main` (не пушить в `main` напрямую: `main` сам выкатывается на сервер).
- В описании PR: таблица «урок / что изменилось / источник», список неподтверждённого.
- Если ничего не изменилось — PR не нужен; отчёт об этом в итоговом сообщении задачи.
