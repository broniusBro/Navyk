# Navyk — контекст проекта

Navyk — мобильное/веб-приложение для изучения Claude и Claude Code с нуля до профессионального уровня.
Формат: короткие уроки (3–5 минут), вопросы, практика, серии дней, XP, интервальное повторение
(по мотивам механик Kodree и EWA, но собственный движок).

## Языки
Русский (ru), украинский (uk), английский (en). Все три — полноценные, ни один не «машинный черновик».
Исходный язык контента — русский; uk и en — профессиональная локализация, а не дословный перевод.

## Уровни
- Новичок: чат, формулировка запросов, файлы, проекты, память, типичные ошибки.
- Продвинутый: артефакты, документы и таблицы, исследование, коннекторы, навыки, длинные задачи.
- Профессионал: Claude Code, API, MCP, агенты, автоматизация, запланированные задачи.

## Ключевая фича
Практика промптинга: пользователь пишет запрос, бэкенд отправляет его в Claude API с инструкцией
проверяющего, Claude возвращает разбор (что хорошо, чего не хватает, как улучшить).
Проверка стоит денег → дешёвая модель для проверки, кеширование промпта, дневные лимиты, платный уровень.
Ключ API хранится только на сервере.

## Платформа
Сначала веб-версия (mobile-first вёрстка, PWA), затем iOS и Android из той же кодовой базы.
Решение и стек — в `docs/adr/0001-web-first-then-mobile.md`. Не использовать API браузера,
которые не переносятся в мобильное приложение, без обёртки-абстракции.

## Полная автономность (требование владельца)
Система работает от А до Я без менеджера. Любая новая функция проектируется так, чтобы не требовать
ручных действий. Сейчас и в плане:
- Обучение: каждый вариант ответа объяснён (why), у каждого упражнения есть подсказка; ИИ-разбор
  промптов; если ИИ недоступен — статичный чек-лист самопроверки (fallback_feedback).
- Контент: `scripts/build_content.py` проверяет уроки в CI; урок с ошибкой не попадает в приложение.
- Качество проверяющего: `.github/workflows/reviewer-eval.yml` сам прогоняет эталонный набор при изменениях.
- Актуальность: ежемесячная запланированная задача — claude-expert сверяет уроки с ⚠️ с документацией
  и открывает PR с правками.
- Безопасность: приватность (R10) и попытки «взломать» проверяющего обрабатываются автоматически.
- Сертификаты: выдаются и проверяются автоматически (`docs/adr/0002-certificate.md`).
- Оплата и отмена подписки — самообслуживание; поддержка — ИИ-ответы по базе FAQ.
Человек нужен только для необратимых решений (деньги, удаление данных, публикация в сторах).

## Сертификаты
Выдаёт Navyk, а не Claude/Anthropic: без их логотипов, с пометкой «не связан с Anthropic».

## Принципы архитектуры
- Контент отделён от кода: уроки — данные (JSON/Markdown в `content/`), обновляются без релиза в сторах.
- Структура контента: `content/{level}/{module}/{lesson}.{ru|uk|en}.md` + метаданные.
- Все тексты интерфейса — через i18n-ключи, никаких строк в коде.

## Бренд и юридическое
Navyk — неофициальное обучающее приложение о Claude. Не использовать логотипы и фирменный стиль Anthropic.
В описаниях и в приложении указывать, что проект не связан с Anthropic.

## Актуальность
Функции Claude меняются часто. Любые факты о продуктах Anthropic проверять по
https://platform.claude.com/docs (API, промптинг; бывший docs.claude.com), https://code.claude.com/docs
(Claude Code, Agent SDK) и https://support.claude.com, а не по памяти. В каждом уроке хранить дату проверки.
Названия моделей, тарифы, лимиты и пути в интерфейсе хранить как данные, а не в тексте уроков.

## Регионы
Claude не доступен в России и Беларуси; в Украине доступен, кроме оккупированных территорий
(список: https://www.anthropic.com/supported-countries). Интерфейс Claude не переведён на ru/uk —
в уроках показываем английские названия элементов с объяснением.
