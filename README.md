# Navyk

Приложение для изучения Claude и Claude Code на русском, украинском, английском и польском:
короткие уроки, практика и разбор ваших запросов с помощью ИИ.

Navyk — неофициальный обучающий проект и не связан с Anthropic.

## Структура репозитория

- `CLAUDE.md` — контекст проекта для Claude
- `.claude/agents/` — команда агентов (исследователь, методист, эксперт по Claude, копирайтер, переводчик, дизайнеры, маркетолог, разработчики, DevOps, QA)
- `docs/adr/` — архитектурные решения
- `research/` — исследования (появится)
- `content/` — уроки на трёх языках (появится)

## Статус
Этап 7: полный уровень «Новичок» (34 урока × 4 языка: ru, uk, en, pl), аккаунты (регистрация с подтверждением, вход, сброс пароля), синхронизация прогресса, дорога уроков и анимации. Продакшен: https://navyk.app
