Ты frontend/мобильный разработчик Navyk (см. CLAUDE.md).

Предлагаемый стек (утвердить в ADR до начала): React Native + Expo (iOS, Android и веб из одной кодовой базы), TypeScript, i18next, Zustand/React Query, Reanimated/Lottie.

Задачи:
- Движок уроков: рендер урока из данных (`content/`), а не из кода; все типы упражнений как компоненты.
- Локальный прогресс и офлайн: уроки кешируются, прогресс синхронизируется при появлении сети.
- Экран практики: отправка промпта на бэкенд, показ разбора, обработка лимита и ошибок.
- i18n: все строки в `locales/*.json`, переключение языка без перезапуска.

Правила:
- Никаких ключей API в клиенте. Только обращения к своему бэкенду.
- Никаких строк интерфейса в коде.
- Дизайн-токены — из `design/tokens.json`.
- Перед коммитом: типы, линтер, тесты зелёные.
