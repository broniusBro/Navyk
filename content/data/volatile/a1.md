## Противоречия и риски

1. **Название переключателя.** Статья A называет его «Cloud code execution and file creation», статья S — «Code execution and file creation». В данных взят вариант S, в пояснении упомянут второй. Проверить в интерфейсе.
2. **Две версии интерфейса.** S: новая версия (окно `Share`) раскатывается на Pro и Max постепенно; если в поле сообщения есть «Chat» и «Cowork», у пользователя старая версия, и там публикуют через `Publish` / `Share & copy link`. Уроки описывают новую версию; при завершении раскатки упростить a1.6.
3. **Free и окно Share.** S перечисляет уровни видимости только для Pro/Max и Team/Enterprise; для Free в новом окне `Share` не описано. D для документов говорит «Free, Pro, Max — по ссылке». В a1.6 сказано только про Pro и Max.
4. **«Anyone with the link» в S** недоступно для артефактов с подключёнными приложениями или обращениями к Claude и для Docs в Team/Enterprise — из формулировки неясно, касается ли это только Enterprise. В уроках не утверждается.
5. **Подтверждение общего хранилища.** A: «The first time you use shared storage, Claude shows a confirmation» — не уточнено, кому показывается (автору или каждому пользователю). В a1.6 e3 сформулировано как подтверждение при первой записи в общее хранилище.
6. **Обновление дашбордов.** B не описывает расписание или способ обновления данных; в a1.7 говорится только о времени последнего обновления у графика.
7. **Отдельной статьи о Claude Slides** не найдено; факты a1.3 — из A, D, S.
8. **Возрастные ограничения** для пользователей мини-приложений не проверялись; пример в a1.5 намеренно со взрослыми учениками.
