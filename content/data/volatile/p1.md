## Риски и что не подтверждено

1. **Стартовый режим Auto.** Зависит от версии (v2.1.283), способа запуска (`claude -p` стартует в `default`), настроек и первой сессии после обновления. В уроке p1.5 сказано упрощённо: «с версии … сессия в терминале и VS Code по умолчанию стартует в Auto». При изменении поведения — править p1.5 и p1.6.
2. **Доступ на бесплатном плане.** Quickstart перечисляет Pro, Max, Team, Enterprise, Console и облачных провайдеров; Free в списке нет. Явной фразы «на Free Claude Code недоступен» на открытых страницах не найдено — в уроках это не утверждается.
3. **Облачные сессии и /clear.** В облачных сессиях `/clear` не работает (новая сессия — из боковой панели). В уроке p1.8 не уточнено; если пользователи будут путаться — добавить пояснение.
4. **Названия режимов в разных поверхностях** отличаются: в VS Code `Accept edits` называется `Edit automatically`; в облачных сессиях вместо Manual показывается Accept edits. Уроки описывают CLI.
5. **Регионы.** Страница поддерживаемых стран (https://www.anthropic.com/supported-countries) в рамках этого модуля не открывалась; уроки p1 о регионах ничего не утверждают.
