## Противоречия и риски

1. **Навыки на Free.** На 2026-11-01 все три статьи («What are skills?», «Use skills in Claude», «How to create custom skills») указывают Free, Pro, Max, Ultra, Team, Enterprise — расхождение снято. В уроках план для навыков по-прежнему не называется.
2. **Где переключатели навыков.** На 2026-11-01 и «Use skills in Claude» описывает переключатели навыков в `Customize > Skills` (расхождение снято); выполнение кода — `Settings > Capabilities`, для организаций статья о навыках называет `Organization settings > Plugins & skills` (вкладка Policy), а статья о файлах — `Organization settings > Capabilities`. В уроках путь организации не называется. В уроках использован `Customize → Skills`; переключатель выполнения кода — `Settings → Capabilities` (подтверждён статьёй о файлах).
3. **Имя файла.** Справка пишет `skill.md` / `Skill.md`, документация API — `SKILL.md`. В уроках используется `SKILL.md`. Допустимость кириллицы в `description` не подтверждена (справка: «нельзя использовать недопустимые символы»); `name` в уроках латиницей через дефис — допустимо по обеим статьям.
4. **YAML.** В примерах `description` без двоеточий: двоеточие с пробелом в незакавыченной строке ломает YAML-шапку.
5. **Cowork.** Справка о плагинах ещё упоминает вкладку Cowork; по учебному плану Cowork слит с чатом. В уроках Cowork не упоминается.
6. **Тариф Ultra (2026-11-01).** Появился план Ultra — бывший Max 20x (https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan). В списки планов добавлен там, где статья называет его явно.
7. **Изоляция навыков (2026-11-01).** «Use skills in Claude» больше не пишет об изолированной среде без сохранения данных между сессиями; статья о файлах подтверждает только изолированный контейнер (sandbox). Строка a5.2 оставлена с прежней датой, вопрос в a5.2 (не volatile) не противоречит справке.
8. **Неподтверждённое и не вошедшее в уроки:** точный лимит размера ZIP, запись навыка с экрана (Pro/Max/Team, Cowork на Mac) — не используется; индикатор «навык использован» в интерфейсе — справка советует смотреть рассуждения Claude.
