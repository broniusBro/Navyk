## Противоречия и риски

1. **Навыки на Free.** «What are skills?» и «How to create custom skills» указывают Free, Pro, Max, Team, Enterprise; «Using Skills in Claude» — только Pro, Max, Team, Enterprise. В уроках план для навыков не называется; в a5.5 сказано лишь, что плагины только на платных планах. Нужна проверка в интерфейсе на Free-аккаунте.
2. **Где переключатели навыков.** «Using Skills in Claude» описывает раздел Skills в `Settings > Capabilities`; более свежие статьи (каталог, создание навыков) — `Customize > Skills`. В уроках использован `Customize → Skills`; переключатель выполнения кода — `Settings → Capabilities` (подтверждён статьёй о файлах).
3. **Имя файла.** Справка пишет `skill.md` / `Skill.md`, документация API — `SKILL.md`. В уроках используется `SKILL.md`. Допустимость кириллицы в `description` не подтверждена (справка: «нельзя использовать недопустимые символы»); `name` в уроках латиницей через дефис — допустимо по обеим статьям.
4. **YAML.** В примерах `description` без двоеточий: двоеточие с пробелом в незакавыченной строке ломает YAML-шапку.
5. **Cowork.** Справка о плагинах ещё упоминает вкладку Cowork; по учебному плану Cowork слит с чатом. В уроках Cowork не упоминается.
6. **Неподтверждённое и не вошедшее в уроки:** точный лимит размера ZIP, запись навыка с экрана (Pro/Max/Team, Cowork на Mac) — не используется; индикатор «навык использован» в интерфейсе — справка советует смотреть рассуждения Claude.
