# Изменчивые факты модуля p4 «Claude API»

Проверено: 2026-10-14 (автор модуля, по platform.claude.com/docs). Ежемесячная сверка: claude-expert.
Значения в уроках подставляются через `{{data.<раздел>.<ключ>}}` из `content/data/modules/p4.json`.

**Префикс ключей — `pfour_`, а не `p4_`.** Регулярное выражение плейсхолдеров в `scripts/build_content.py`
(`\{\{\s*data\.([a-z_]+)\.([a-z_]+)\s*\}\}`) не допускает цифр: `{{data.models.p4_haiku_id}}` не подставился бы
и без ошибки остался бы в тексте урока. Если регулярное выражение расширят до `[a-z0-9_]`, ключи можно переименовать.

## Не подтверждено / риски

1. **Страницы Get started и Pricing открылись частично.** На get-started не видны вкладки cURL и TypeScript; пример curl взят со страницы «Using the Messages API». Пакет TypeScript SDK в уроках не упоминается.
2. **Endpoint создания пакета** (`POST /v1/messages/batches`) на странице Batch processing дословно не приведён — в уроке только Python SDK (`client.messages.batches.create`, `client.messages.batches.results`). Атрибут `item.result.message` у успешного результата взят из устройства SDK, на странице дословно не показан.
3. **Нужны ли кредиты/оплата до первого вызова** — страница Get an API key об этом молчит; в уроке не утверждается.
4. **Haiku 5.5 и thinking.** В таблице моделей у Haiku 5.5 «Adaptive», у Opus 5.5 и Fable 5.1 — «Adaptive (always on)». Поэтому в примерах кода текст берётся из блока `type == "text"`, а не из `content[0]`.
5. **Параметры `temperature`, `top_p`, `top_k`** не поддерживаются на Claude 4.7+ (400 при значении не по умолчанию) — в уроках не используются; стоит учесть в p7.4 (миграция).
