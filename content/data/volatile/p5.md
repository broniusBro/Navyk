# Изменчивые факты модуля p5 «MCP»

Ежемесячно сверяет claude-expert. При расхождении правится и эта таблица, и затронутые уроки (`content/pro/p5/*`), и значения в `content/data/modules/p5.json`.
Значения в уроках не пишутся текстом, а подставляются через `{{data.<раздел>.<ключ>}}` либо формулируются без цифр.

Уроки опираются на спецификацию MCP **2026-07-28** (на 2026-11-01 это текущая версия: страница Versioning называет её **current**).

## Ключи `content/data/modules/p5.json`

Префикс `pfive_`, потому что сборщик (`DATA_RE` в `scripts/build_content.py`) принимает в ключах только `[a-z_]`: ключ вида `p5_…` не распознаётся, и плейсхолдер молча остаётся в тексте.

| section.key | value (ru) | урок |
|---|---|---|
| `versions.pfive_mcp_spec` | 2026-07-28 | p5.1, p5.2, p5.3, p5.4 |
| `versions.pfive_python_sdk_min` | 2.0.0 | p5.4 |
| `versions.pfive_api_beta` | mcp-client-2025-11-20 | p5.5 |

- Страницы `modelcontextprotocol.io/docs/getting-started/intro`, `/docs/learn/architecture` (без версии), `/specification/latest` (обзор) и `/specification/2026-07-28/server` не открылись (ограничение доступа); использованы версионные адреса тех же страниц (`/docs/2026-07-28/...`, `.md`).
- Как Claude Code показывает MCP prompts (формат slash-команды) — в прочитанной части документации не найдено; в уроке p5.2 сказано только «как slash-команду» со ссылкой на таблицу спецификации (пример: slash commands, menu options).

- Ведёт ли Python SDK 2.x инструмент к `isError: true`, если функция возвращает строку с ошибкой или бросает исключение — не проверено; пример в p5.4 возвращает текст ошибки, механизм `isError` описан в p5.6 только на уровне спецификации.
