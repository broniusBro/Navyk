::: step hook
В CLAUDE.md у Марины написано: «После каждой правки запускай `npx eslint`». Обычно Claude так и делает.

Но в длинной сессии он пару раз забыл, и ошибки линтера всплыли уже в CI. Марине нужно не «обычно», а «каждый раз».
:::

::: step explain
Для этого есть *хук* (*hook*) — твоя команда, которую Claude Code сам запускает в определённый момент. Как датчик дыма: он срабатывает не потому, что кто-то вспомнил, а потому, что появился дым.

CLAUDE.md — просьба к Claude. Хук выполняет Claude Code, а не модель, поэтому он срабатывает на каждом подходящем событии.
:::

::: step explain
Хук описывают в блоке `hooks` файла настроек. `.claude/settings.json` — для проекта, его можно закоммитить. `~/.claude/settings.json` — для всех твоих проектов.

Главные части:

- *событие*: `PostToolUse` — после успешного вызова инструмента, `PreToolUse` — до него;
- *matcher*: `Edit|Write` — только инструменты правки файлов;
- *команда*, которая получает данные события в формате JSON на вход (stdin).
:::

::: step example
Марина добавляет в `.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/lint.sh"
          }
        ]
      }
    ]
  }
}
```

И скрипт `.claude/hooks/lint.sh`:

```bash
#!/bin/bash
FILE_PATH=$(jq -r '.tool_input.file_path // empty')
case "$FILE_PATH" in
  *.js|*.ts) npx eslint "$FILE_PATH" >&2 || exit 2 ;;
esac
exit 0
```

Не забудь `chmod +x .claude/hooks/lint.sh`: скрипт должен быть исполняемым.
:::

::: step explain
Что значит `exit 2`? Хук отвечает кодом выхода:

- `0` — возражений нет;
- `2` — сигнал Claude Code, текст из stderr идёт как причина;
- другой код — неблокирующая ошибка, работа продолжается.

Для `PostToolUse` код 2 показывает stderr Claude: правка уже сделана, но Claude видит ошибки линтера и исправляет их. Поэтому вывод ESLint направлен в stderr (`>&2`).
:::

::: step summary
**Хук — команда, которую Claude Code запускает на событии. Правило в CLAUDE.md — совет, хук — гарантия.**

Линтер после правок: `PostToolUse` + `Edit|Write` + `exit 2` с ошибками в stderr. Запрет на правку: `PreToolUse` + `exit 2`.
