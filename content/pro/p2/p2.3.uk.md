::: step hook
Тарас попросив Claude Code розібратися, як у проєкті влаштовано авторизацію. Claude прочитав тридцять файлів, усе пояснив, і Тарас сказав: «Чудово, тепер додай вхід через Google».

А далі Claude почав плутатися в деталях, які обговорювали десять хвилин тому. Контекст забитий вмістом тих тридцяти файлів.
:::

::: step explain
Таке дослідження краще доручити *субагентові* — окремому помічникові з власним контекстом. Як відправити стажера в архів: він сам перегорне теки й принесе тобі одну сторінку висновків.

У субагента свій системний промпт, свій набір інструментів і своє вікно контексту. У головну розмову повертається лише підсумок.
:::

::: step example
Субагент — це Markdown-файл зі шапкою. Файл `.claude/agents/code-researcher.md`:

```markdown
---
name: code-researcher
description: Досліджує кодову базу й відповідає, де і як щось влаштовано. Використовуй перед змінами в незнайомих модулях.
tools: Read, Grep, Glob
---

Ти дослідник коду. Тобі ставлять запитання про проєкт.
Знайди відповідь, читаючи файли. Нічого не змінюй.
Поверни: відповідь у 3–5 реченнях, список файлів із номерами рядків, відкриті запитання.
```

Обов'язкові лише `name` і `description`. Рядок `tools` залишає йому тільки читання й пошук.
:::

::: step explain
Як Claude передає завдання субагентові:

- **Сам**, за `description`. Що точніше описано, коли його кликати, то частіше Claude це робить. Документація радить додавати фрази на кшталт «use proactively».
- **На твоє прохання**: «Використай субагента code-researcher, щоб…»
- **Через @**: набери `@` і вибери його зі списку.

Якщо теки `.claude/agents/` раніше не було, після першого файлу перезапусти сесію.
:::

::: step explain
Тепер створи власного субагента. Наприклад, рев'юера, який шукає проблеми в змінах перед комітом, або дослідника твого проєкту.

Напиши весь файл: шапку й системний промпт. Подумай, які інструменти йому справді потрібні. Navyk надішле файл Claude на розбір.
:::

::: step summary
**Субагент — файл у `.claude/agents/` з `name`, `description` і, коли треба, `tools`. Він працює у власному контексті й повертає підсумок.**

Без `tools` субагент отримує всі інструменти, тому досліднику залишай лише читання. Завдання став конкретно: він не бачить твоєї розмови.

Далі: хуки — те, що спрацьовує завжди.
:::
