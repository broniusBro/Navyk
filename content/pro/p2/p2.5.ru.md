::: step hook
Каждое утро Ярослав открывает в браузере базу знаний команды, копирует оттуда описание задачи и вставляет его в Claude Code.

Claude не видит вкладки браузера, поэтому без копирования никак. Или всё-таки можно дать ему доступ напрямую?
:::

::: step explain
Можно, через *MCP* (Model Context Protocol) — открытый стандарт подключения внешних сервисов. *MCP-сервер* — как переходник: с одной стороны сервис, с другой Claude Code. Сервер даёт Claude инструменты: найти страницу, прочитать задачу, создать запись.

Серверы бывают удалённые (по адресу в интернете) и локальные (процесс на твоём компьютере).
:::

::: step example
Удалённый сервер подключают одной командой в терминале. Для удалённых серверов рекомендуют транспорт HTTP:

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Здесь `notion` — имя, под которым сервер будет виден в Claude Code, а дальше — его адрес.

Если сервер просит вход через браузер (OAuth), набери в Claude Code `/mcp` и войди. Там же видно, подключён ли сервер.
:::

::: step explain
У сервера есть *область действия* (флаг `--scope`):

- `local` — по умолчанию: только ты и только в этом проекте;
- `project` — для всей команды: запись попадает в файл `.mcp.json` в корне проекта, его коммитят;
- `user` — только ты, но во всех твоих проектах.

Серверы из `.mcp.json` Claude Code перед первым использованием покажет и спросит подтверждение.
:::

::: step explain
Локальный сервер — это программа на твоём компьютере (транспорт *stdio*). Тут важен разделитель `--`:

```bash
claude mcp add --env AIRTABLE_API_KEY=YOUR_KEY --transport stdio airtable \
  -- npx -y airtable-mcp-server
```

Всё до `--` — опции самого Claude Code. Всё после — команда запуска сервера, она передаётся как есть.

Проверить: `claude mcp list`, `claude mcp get airtable`. Удалить: `claude mcp remove airtable`.
:::

::: step summary
**MCP-сервер даёт Claude Code инструменты внешнего сервиса. Удалённый: `claude mcp add --transport http <имя> <адрес>`. Локальный: опции, потом `--` и команда сервера.**

Область: `local` для себя, `project` для команды через `.mcp.json`, `user` для всех своих проектов. Секреты не коммить и подключай только серверы, которым доверяешь.

:::
