::: step hook
У CLAUDE.md у Мар'яни написано: «Після кожного редагування запускай `npx eslint`». Зазвичай Claude так і робить.

Але в довгій сесії він кілька разів забув, і помилки лінтера виринули вже в CI. Мар'яні потрібно не «зазвичай», а «щоразу».
:::

::: step explain
Для цього є *хук* (*hook*) — твоя команда, яку Claude Code сам запускає в певний момент. Як датчик диму: він спрацьовує не тому, що хтось згадав, а тому, що з'явився дим.

CLAUDE.md — прохання до Claude. Хук виконує Claude Code, а не модель, тому він спрацьовує на кожній відповідній події.
:::

::: step explain
Хук описують у блоці `hooks` файлу налаштувань. `.claude/settings.json` — для проєкту, його можна закомітити. `~/.claude/settings.json` — для всіх твоїх проєктів.

Головні частини:

- *подія*: `PostToolUse` — після успішного виклику інструмента, `PreToolUse` — до нього;
- *matcher*: `Edit|Write` — лише інструменти редагування файлів;
- *команда*, яка отримує дані події у форматі JSON на вхід (stdin).
:::

::: step example
Мар'яна додає в `.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/lint.sh"
          }
        ]
      }
    ]
  }
}
```

І скрипт `.claude/hooks/lint.sh`:

```bash
#!/bin/bash
FILE_PATH=$(jq -r '.tool_input.file_path // empty')
case "$FILE_PATH" in
  *.js|*.ts) npx eslint "$FILE_PATH" >&2 || exit 2 ;;
esac
exit 0
```

Не забудь `chmod +x .claude/hooks/lint.sh`: скрипт має бути виконуваним.
:::

::: step explain
Що означає `exit 2`? Хук відповідає кодом виходу:

- `0` — заперечень немає;
- `2` — сигнал для Claude Code, текст зі stderr іде як причина;
- інший код — неблокувальна помилка, робота триває.

Для `PostToolUse` код 2 показує stderr Claude: зміну вже зроблено, але Claude бачить помилки лінтера й виправляє їх. Тому вивід ESLint спрямовано в stderr (`>&2`).
:::

::: step summary
**Хук — команда, яку Claude Code запускає на подію. Правило в CLAUDE.md — порада, хук — гарантія.**

Лінтер після змін: `PostToolUse` + `Edit|Write` + `exit 2` з помилками в stderr. Заборона на редагування: `PreToolUse` + `exit 2`.

Далі: MCP — як підключити до Claude Code зовнішні сервіси.
:::
