::: step hook
Коллега пишет Богдану в рабочий чат: «Поставь `/plugin install turbo-dev@super-tools`, там всё сразу: навыки, хуки, MCP. Я поставил, огонь!»

Одна команда — и готовый набор, который кто-то уже собрал. Удобно. Но что именно окажется на компьютере Богдана?
:::

::: step explain
*Плагин* — это упаковка расширений: навыки, субагенты, хуки, MCP-серверы. *Маркетплейс* — каталог плагинов, как магазин приложений.

Навыки плагина вызываются с его именем: у плагина `commit-commands` команда будет `/commit-commands:commit`. Так навыки разных плагинов не путаются.

Официальный каталог `claude-plugins-official` Claude Code добавляет сам при первом интерактивном запуске.
:::

::: step example
Установка из официального каталога:

```text
/plugin install commit-commands@claude-plugins-official
```

В сессии эта команда не ставит плагин сразу, а открывает его карточку. В {{data.ui_paths.p2_plugin_will_install}} видно, какие команды, агенты, навыки, хуки и серверы он добавит. Затем выбираешь область.

Просто `/plugin` открывает панель с вкладками {{data.ui_paths.p2_plugin_discover}}, {{data.ui_paths.p2_plugin_installed}}, {{data.ui_paths.p2_plugin_marketplaces}} и {{data.ui_paths.p2_plugin_errors}}.
:::

::: step explain
Теперь о доверии. Документация говорит прямо: установленный плагин может выполнять произвольный код с правами твоего пользователя.

- Его хуки — это shell-команды.
- Его MCP-серверы могут запускаться как процессы на твоём компьютере.
- Его навыки и агенты попадают в контекст Claude как инструкции.

Хуки и серверы плагина работают вне песочницы, правила разрешений их не сдерживают.
:::

::: step explain
Читать чужой `hooks.json` и скрипты долго. Можно поручить первый разбор Claude: склонировать репозиторий плагина и попросить его изучить, ничего не запуская.

Но слабый запрос даст слабую проверку. Улучши его так, чтобы Claude знал, что смотреть, чего не делать и какой отчёт вернуть. Navyk отправит запрос на разбор Claude.

::: step summary
**Плагин — упаковка навыков, субагентов, хуков и MCP-серверов. Ставь через `/plugin install <плагин>@<каталог>`, сначала читай карточку и выбирай область.**

Плагин выполняет код с твоими правами, поэтому перед установкой смотри источник каталога, раздел {{data.ui_paths.p2_plugin_will_install}} и исходники хуков, серверов и `bin/`. Имя каталога — не гарантия.

Модуль пройден: ты знаешь все способы расширить Claude Code.
:::
