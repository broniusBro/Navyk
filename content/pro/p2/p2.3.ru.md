::: step hook
Тимур попросил Claude Code разобраться, как в проекте устроена авторизация. Claude прочитал тридцать файлов, всё объяснил, и Тимур сказал: «Отлично, теперь добавь вход через Google».

А дальше Claude начал путаться в деталях, которые обсуждали десять минут назад. Контекст забит содержимым тех тридцати файлов.
:::

::: step explain
Такое исследование лучше поручить *субагенту* — отдельному помощнику со своим контекстом. Как отправить стажёра в архив: он перечитает папки сам и принесёт тебе одну страницу выводов.

У субагента свой системный промпт, свой набор инструментов и своё окно контекста. В главный разговор возвращается только сводка.
:::

::: step example
Субагент — это Markdown-файл с шапкой. Файл `.claude/agents/code-researcher.md`:

```markdown
---
name: code-researcher
description: Исследует кодовую базу и отвечает, где и как что-то устроено. Используй перед изменениями в незнакомых модулях.
tools: Read, Grep, Glob
---

Ты исследователь кода. Тебе дают вопрос о проекте.
Найди ответ, читая файлы. Ничего не меняй.
Верни: ответ в 3–5 предложениях, список файлов с номерами строк, открытые вопросы.
```

Обязательны только `name` и `description`. Строка `tools` оставляет ему только чтение и поиск.
:::

::: step explain
Как Claude отдаёт задачу субагенту:

- **Сам**, по `description`. Чем точнее описано, когда его звать, тем чаще Claude это делает. Документация советует добавлять фразы вроде «use proactively».
- **По твоей просьбе**: «Используй субагента code-researcher, чтобы…»
- **Через @**: набери `@` и выбери его из списка.

Если папки `.claude/agents/` раньше не было, после первого файла перезапусти сессию.
:::

::: step explain
Теперь сделай своего субагента. Например, проверяющего, который ищет проблемы в изменениях перед коммитом, или исследователя по твоему проекту.

Напиши весь файл: шапку и системный промпт. Подумай, какие инструменты ему действительно нужны. Navyk отправит файл на разбор Claude.

::: step summary
**Субагент — файл в `.claude/agents/` с `name`, `description` и, по делу, `tools`. Он работает в своём контексте и возвращает сводку.**

Без `tools` субагент получает все инструменты, поэтому исследователю оставляй только чтение. Задачу ставь конкретно: он не видит твой разговор.

Дальше: хуки — то, что срабатывает всегда.
:::
