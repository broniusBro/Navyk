::: step hook
Każdego ranka Jarek otwiera w przeglądarce bazę wiedzy zespołu, kopiuje stamtąd opis zadania i wkleja go do Claude Code.

Claude nie widzi kart przeglądarki, więc bez kopiowania ani rusz. A może jednak da się dać mu bezpośredni dostęp?
:::

::: step explain
Da się, przez *MCP* (Model Context Protocol) — otwarty standard podłączania usług zewnętrznych. *Serwer MCP* działa jak przejściówka: z jednej strony usługa, z drugiej Claude Code. Serwer daje Claude narzędzia: znaleźć stronę, przeczytać zadanie, utworzyć wpis.

Serwery bywają zdalne (pod adresem w internecie) i lokalne (proces na twoim komputerze).
:::

::: step example
Zdalny serwer podłącza się jednym poleceniem w terminalu. Dla serwerów zdalnych zalecany jest transport HTTP:

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Tutaj `notion` to nazwa, pod którą serwer będzie widoczny w Claude Code, a dalej jego adres.

Jeśli serwer wymaga logowania przez przeglądarkę (OAuth), wpisz w Claude Code `/mcp` i się zaloguj. Tam też widać, czy serwer jest połączony.
:::

::: step explain
Serwer ma *zakres* (flaga `--scope`):

- `local` — domyślny: tylko ty i tylko w tym projekcie;
- `project` — dla całego zespołu: wpis trafia do pliku `.mcp.json` w katalogu głównym projektu, który się commituje;
- `user` — tylko ty, ale we wszystkich twoich projektach.

Serwery z `.mcp.json` Claude Code przed pierwszym użyciem pokaże i poprosi o potwierdzenie.
:::

::: step explain
Serwer lokalny to program na twoim komputerze (transport *stdio*). Tu ważny jest separator `--`:

```bash
claude mcp add --env AIRTABLE_API_KEY=YOUR_KEY --transport stdio airtable \
  -- npx -y airtable-mcp-server
```

Wszystko przed `--` to opcje samego Claude Code. Wszystko po nim to polecenie uruchamiające serwer, przekazywane bez zmian.

Sprawdzenie: `claude mcp list`, `claude mcp get airtable`. Usunięcie: `claude mcp remove airtable`.
:::

::: step summary
**Serwer MCP daje Claude Code narzędzia zewnętrznej usługi. Zdalny: `claude mcp add --transport http <nazwa> <adres>`. Lokalny: opcje, potem `--` i polecenie serwera.**

Zakres: `local` dla siebie, `project` dla zespołu przez `.mcp.json`, `user` dla wszystkich swoich projektów. Nie commituj sekretów i podłączaj tylko serwery, którym ufasz.

Dalej: wtyczki, czyli jak dostać to wszystko jedną instalacją.
:::
