::: step hook
Щоранку Ярослав відкриває в браузері базу знань команди, копіює звідти опис завдання й вставляє його в Claude Code.

Claude не бачить вкладок браузера, тож без копіювання ніяк. Чи все-таки можна дати йому доступ напряму?
:::

::: step explain
Можна, через *MCP* (Model Context Protocol) — відкритий стандарт підключення зовнішніх сервісів. *MCP-сервер* — як перехідник: з одного боку сервіс, з іншого Claude Code. Сервер дає Claude інструменти: знайти сторінку, прочитати завдання, створити запис.

Сервери бувають віддалені (за адресою в інтернеті) і локальні (процес на твоєму комп'ютері).
:::

::: step example
Віддалений сервер підключають однією командою в терміналі. Для віддалених серверів рекомендують транспорт HTTP:

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Тут `notion` — назва, під якою сервер буде видно в Claude Code, а далі — його адреса.

Якщо сервер просить увійти через браузер (OAuth), набери в Claude Code `/mcp` і увійди. Там само видно, чи підключено сервер.
:::

::: step explain
У сервера є *область дії* (прапорець `--scope`):

- `local` — за замовчуванням: лише ти й лише в цьому проєкті;
- `project` — для всієї команди: запис потрапляє у файл `.mcp.json` у корені проєкту, його комітять;
- `user` — лише ти, але в усіх твоїх проєктах.

Сервери з `.mcp.json` Claude Code перед першим використанням покаже й попросить підтвердження.
:::

::: step explain
Локальний сервер — це програма на твоєму комп'ютері (транспорт *stdio*). Тут важливий розділювач `--`:

```bash
claude mcp add --env AIRTABLE_API_KEY=YOUR_KEY --transport stdio airtable \
  -- npx -y airtable-mcp-server
```

Усе до `--` — опції самого Claude Code. Усе після — команда запуску сервера, вона передається як є.

Перевірити: `claude mcp list`, `claude mcp get airtable`. Видалити: `claude mcp remove airtable`.
:::

::: step summary
**MCP-сервер дає Claude Code інструменти зовнішнього сервісу. Віддалений: `claude mcp add --transport http <назва> <адреса>`. Локальний: опції, потім `--` і команда сервера.**

Область: `local` для себе, `project` для команди через `.mcp.json`, `user` для всіх своїх проєктів. Секретів не коміть і підключай лише сервери, яким довіряєш.

Далі: плагіни — як отримати все це одним встановленням.
:::
