::: step hook
Kolega pisze do Bartka na firmowym czacie: „Odpal `/plugin install turbo-dev@super-tools`, tam jest wszystko naraz: skille, hooki, MCP. Zainstalowałem, petarda!”

Jedno polecenie i gotowy zestaw, który ktoś już złożył. Wygodne. Ale co dokładnie wyląduje na komputerze Bartka?
:::

::: step explain
*Wtyczka* (*plugin*) to paczka rozszerzeń: skille, subagenci, hooki, serwery MCP. *Marketplace* to katalog wtyczek, jak sklep z aplikacjami.

Skille wtyczki wywołuje się z jej nazwą: we wtyczce `commit-commands` polecenie będzie brzmiało `/commit-commands:commit`. Dzięki temu skille z różnych wtyczek się nie mylą.

Oficjalny katalog `claude-plugins-official` Claude Code dodaje sam przy pierwszym interaktywnym uruchomieniu.
:::

::: step example
Instalacja z oficjalnego katalogu:

```text
/plugin install commit-commands@claude-plugins-official
```

W sesji to polecenie nie instaluje wtyczki od razu, tylko otwiera jej kartę. W sekcji {{data.ui_paths.p2_plugin_will_install}} widać, jakie polecenia, agentów, skille, hooki i serwery doda. Potem wybierasz zakres.

Samo `/plugin` otwiera panel z zakładkami {{data.ui_paths.p2_plugin_discover}}, {{data.ui_paths.p2_plugin_installed}}, {{data.ui_paths.p2_plugin_marketplaces}} i {{data.ui_paths.p2_plugin_errors}}.
:::

::: step explain
Teraz o zaufaniu. Dokumentacja mówi wprost: zainstalowana wtyczka może wykonywać dowolny kod z uprawnieniami twojego użytkownika.

- Jej hooki to polecenia powłoki.
- Jej serwery MCP mogą działać jako procesy na twoim komputerze.
- Jej skille i agenci trafiają do kontekstu Claude jako instrukcje.

Hooki i serwery wtyczki działają poza piaskownicą, reguły uprawnień ich nie ograniczają.
:::

::: step explain
Czytanie cudzego `hooks.json` i skryptów trwa. Pierwszy przegląd możesz zlecić Claude: sklonować repozytorium wtyczki i poprosić, żeby je zbadał, niczego nie uruchamiając.

Ale słaby prompt da słabe sprawdzenie. Popraw go tak, żeby Claude wiedział, na co patrzeć, czego nie robić i jaki raport zwrócić. Navyk wyśle prompt do Claude do oceny.
:::

::: step summary
**Wtyczka to paczka skilli, subagentów, hooków i serwerów MCP. Instaluj ją przez `/plugin install <wtyczka>@<katalog>`, najpierw czytaj kartę i wybieraj zakres.**

Wtyczka wykonuje kod z twoimi uprawnieniami, więc przed instalacją sprawdź źródło katalogu, sekcję {{data.ui_paths.p2_plugin_will_install}} i kod źródłowy hooków, serwerów oraz `bin/`. Nazwa katalogu to nie gwarancja.

Moduł ukończony: znasz już wszystkie sposoby rozszerzania Claude Code.
:::
