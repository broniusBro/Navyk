::: step hook
Колега пише Богданові в робочий чат: «Постав `/plugin install turbo-dev@super-tools`, там усе одразу: навички, хуки, MCP. Я поставив — вогонь!»

Одна команда — і готовий набір, який хтось уже зібрав. Зручно. Але що саме опиниться на комп'ютері Богдана?
:::

::: step explain
*Плагін* — це пакунок розширень: навички, субагенти, хуки, MCP-сервери. *Маркетплейс* — каталог плагінів, як магазин застосунків.

Навички плагіна викликаються з його назвою: у плагіна `commit-commands` команда буде `/commit-commands:commit`. Так навички різних плагінів не плутаються.

Офіційний каталог `claude-plugins-official` Claude Code додає сам під час першого інтерактивного запуску.
:::

::: step example
Встановлення з офіційного каталогу:

```text
/plugin install commit-commands@claude-plugins-official
```

У сесії ця команда не ставить плагін одразу, а відкриває його картку. У розділі {{data.ui_paths.p2_plugin_will_install}} видно, які команди, агенти, навички, хуки й сервери він додасть. Потім обираєш область.

Просто `/plugin` відкриває панель із вкладками {{data.ui_paths.p2_plugin_discover}}, {{data.ui_paths.p2_plugin_installed}}, {{data.ui_paths.p2_plugin_marketplaces}} і {{data.ui_paths.p2_plugin_errors}}.
:::

::: step explain
Тепер про довіру. Документація каже прямо: установлений плагін може виконувати довільний код із правами твого користувача.

- Його хуки — це shell-команди.
- Його MCP-сервери можуть запускатися як процеси на твоєму комп'ютері.
- Його навички й агенти потрапляють у контекст Claude як інструкції.

Хуки й сервери плагіна працюють поза пісочницею, правила дозволів їх не стримують.
:::

::: step explain
Читати чужий `hooks.json` і скрипти довго. Можна доручити перший розбір Claude: склонувати репозиторій плагіна й попросити його вивчити, нічого не запускаючи.

Але слабкий запит дасть слабку перевірку. Покращ його так, щоб Claude знав, що дивитися, чого не робити і який звіт повернути. Navyk надішле запит Claude на розбір.

::: step summary
**Плагін — пакунок навичок, субагентів, хуків і MCP-серверів. Став через `/plugin install <плагін>@<каталог>`, спершу читай картку й обирай область.**

Плагін виконує код із твоїми правами, тому перед встановленням дивись джерело каталогу, розділ {{data.ui_paths.p2_plugin_will_install}} і вихідний код хуків, серверів і `bin/`. Назва каталогу — не гарантія.

Модуль пройдено: ти знаєш усі способи розширити Claude Code.
:::
