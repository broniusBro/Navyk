::: step hook
W CLAUDE.md Marty jest napisane: „Po każdej edycji uruchom `npx eslint`”. Zwykle Claude tak robi.

Ale w długiej sesji kilka razy zapomniał i błędy lintera wyszły dopiero w CI. Marcie nie wystarczy „zwykle”, potrzebuje „za każdym razem”.
:::

::: step explain
Do tego służy *hook* — twoje polecenie, które Claude Code sam uruchamia w określonym momencie. Jak czujnik dymu: nie włącza się dlatego, że ktoś sobie przypomniał, tylko dlatego, że pojawił się dym.

CLAUDE.md to prośba do Claude. Hook wykonuje Claude Code, a nie model, więc działa przy każdym pasującym zdarzeniu.
:::

::: step explain
Hook opisuje się w bloku `hooks` pliku ustawień. `.claude/settings.json` — dla projektu, można go zacommitować. `~/.claude/settings.json` — dla wszystkich twoich projektów.

Najważniejsze części:

- *zdarzenie*: `PostToolUse` — po udanym wywołaniu narzędzia, `PreToolUse` — przed nim;
- *matcher*: `Edit|Write` — tylko narzędzia do edycji plików;
- *polecenie*, które dostaje dane zdarzenia w formacie JSON na wejściu (stdin).
:::

::: step example
Marta dodaje do `.claude/settings.json`:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/lint.sh"
          }
        ]
      }
    ]
  }
}
```

I skrypt `.claude/hooks/lint.sh`:

```bash
#!/bin/bash
FILE_PATH=$(jq -r '.tool_input.file_path // empty')
case "$FILE_PATH" in
  *.js|*.ts) npx eslint "$FILE_PATH" >&2 || exit 2 ;;
esac
exit 0
```

Nie zapomnij o `chmod +x .claude/hooks/lint.sh`: skrypt musi być wykonywalny.
:::

::: step explain
Co znaczy `exit 2`? Hook odpowiada kodem wyjścia:

- `0` — brak zastrzeżeń;
- `2` — sygnał dla Claude Code, tekst ze stderr idzie jako powód;
- inny kod — błąd nieblokujący, praca toczy się dalej.

Dla `PostToolUse` kod 2 pokazuje stderr Claude: edycja już się odbyła, ale Claude widzi błędy lintera i je poprawia. Dlatego wynik ESLint jest przekierowany do stderr (`>&2`).
:::

  - left: "Dowolne zdarzenie, kod 0"
    right: "Brak zastrzeżeń, praca idzie dalej"
    why: "Zwykły udany wynik. Przy większości zdarzeń nic się nie wyświetla."

    right: "Błąd nieblokujący: komunikat w logu, akcja trwa dalej"

::: step summary
**Hook to polecenie, które Claude Code uruchamia przy zdarzeniu. Zasada w CLAUDE.md to rada, hook to gwarancja.**

Linter po edycjach: `PostToolUse` + `Edit|Write` + `exit 2` z błędami w stderr. Zakaz edycji: `PreToolUse` + `exit 2`.

Dalej: MCP, czyli jak podłączyć do Claude Code usługi zewnętrzne.
:::
