::: step hook
Щоп'ятниці Олена зі Львова пише в Claude Code той самий довгий запит: «Візьми коміти з останнього тегу, згрупуй, прибери хеші, пиши для користувачів…»

Дванадцять рядків, і щоразу вона щось забуває. Хочеться набрати `/release-notes 2.4.0` й отримати готовий текст.
:::

::: step explain
Для цього є *навичка* (*skill*) — тека з файлом `SKILL.md`. Як пам'ятка для колеги: відкрив і зробив крок за кроком.

Де лежить:

- `.claude/skills/<назва>/SKILL.md` — навичка проєкту. Закоміть її, і вона буде в усієї команди.
- `~/.claude/skills/<назва>/SKILL.md` — особиста навичка, в усіх твоїх проєктах.

Назва теки стає командою: `/release-notes`.
:::

::: step example
Файл `.claude/skills/release-notes/SKILL.md`:

```markdown
---
description: Пише нотатки до релізу за комітами з останнього git-тегу. Використовуй, коли просять release notes або список змін до релізу.
argument-hint: "[версія]"
---

Збери нотатки до релізу версії $ARGUMENTS.

1. Переглянь коміти з останнього тегу: `git log $(git describe --tags --abbrev=0)..HEAD --oneline`.
2. Згрупуй їх: «Нове», «Виправлення», «Інше».
3. Пиши для користувачів: без хешів комітів і назв файлів.
4. Незрозумілі коміти винеси в кінець із позначкою «уточнити».
```

Виклик: `/release-notes 2.4.0`. Замість `$ARGUMENTS` підставиться `2.4.0`.
:::

::: step explain
Claude може й сам завантажити навичку, без команди. На початку сесії він бачить лише *опис* (`description`) кожної навички й за ним вирішує, чи підходить вона до завдання. Розмитий опис — і навичка не спрацює або спрацює не там.

Два поля керують викликом:

- `disable-model-invocation: true` — лише ти, через `/назва`. Для навичок із побічними ефектами, наприклад деплою.
- `user-invocable: false` — лише Claude, у меню `/` навички немає.
:::

    right: "Сюди підставляється те, що ти написав після команди"

::: step explain
Тепер напиши власну навичку. Візьми завдання, яке ти повторюєш у Claude Code: опис pull request, перевірку коду за чек-листом команди, розбір тестів, що впали.

Потрібні шапка з `description` та покрокова інструкція. Navyk надішле навичку Claude на розбір. Секретів і токенів у навичку не пиши.
:::

::: step summary
**Навичка — тека з `SKILL.md`: шапка з описом та інструкція. Проєктна навичка лежить у `.claude/skills/<назва>/`, викликається `/назва`.**

Опис вирішує, чи спрацює навичка сама. Навички з наслідками запускай лише вручну: `disable-model-invocation: true`.

Далі: субагенти — помічники з власним контекстом.
:::
