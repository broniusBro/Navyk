::: step hook
Ірина щоночі розкладає за темами відгуки за день — 20 тисяч штук. Зараз скрипт надсилає їх по одному, наче хтось чекає на кожну відповідь.

Але звіт дивляться лише вранці. Навіщо платити за швидкість, яка нікому не потрібна?
:::

::: step explain
Для таких завдань є *Message Batches API* — пакетна обробка. Ти надсилаєш одразу багато запитів, а результати забираєш пізніше.

Ціна — {{data.prices.pfour_batch_discount}} від звичайної, і на вхідні, і на вихідні токени. Натомість чекаєш: {{data.limits.pfour_batch_typical}}, максимум {{data.limits.pfour_batch_expire}}.
:::

::: step explain
Кожен запит у пакеті — це `custom_id` і звичайні параметри Messages API:

```python
batch = client.messages.batches.create(
    requests=[
        {
            "custom_id": f"review-{r.id}",
            "params": {
                "model": "{{data.models.pfour_haiku_id}}",
                "max_tokens": 50,
                "messages": [{"role": "user", "content": r.text}],
            },
        }
        for r in reviews
    ]
)
```

`custom_id` — від 1 до 64 символів: латинські літери, цифри, `-` і `_`.
:::

::: step explain
Поки пакет працює, `processing_status` дорівнює `in_progress`. Коли стане `ended`, забираєш результати:

```python
for item in client.messages.batches.results(batch.id):
    if item.result.type == "succeeded":
        save(item.custom_id, item.result.message)
```

Результати приходять *у будь-якому порядку*. Зіставляй їх лише за `custom_id`. Зберігаються вони {{data.limits.pfour_batch_results_days}}.
:::

::: step explain
Не кожен запит у пакеті завершується успіхом. Результат має чотири типи:

- `succeeded` — готово, всередині звичайна відповідь;
- `errored` — помилка в запиті або на сервері;
- `canceled` — ти скасував пакет раніше;
- `expired` — пакет не встиг за {{data.limits.pfour_batch_expire}}.

За `errored`, `canceled` і `expired` не платиш.
:::

::: step summary
**Не чекаєш на відповідь просто зараз — надсилай пакетом і плати половину.**

Кожному запиту — унікальний `custom_id`, результати зіставляй лише за ним. Кешування й пакети разом дають максимальну економію.

Модуль «Claude API» пройдено: ключ, моделі, системний промпт, effort, JSON за схемою, інструменти, кеш і пакети.
:::
