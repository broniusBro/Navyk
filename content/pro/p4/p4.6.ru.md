::: step hook
Клиент пишет боту книжного магазина из Ровно: «Где мой заказ 1042?» Бот уверенно отвечает: «Ваш заказ уже в пути!»

Заказ ещё даже не собран. Бот не имеет доступа к базе и просто угадал.
:::

::: step explain
*Tool use* — способ дать Claude инструменты: функции твоего приложения, которые он может попросить вызвать. Например, «найти заказ по номеру».

Важно: Claude не выполняет код сам. Он говорит: «вызови get_order с номером 1042». Вызывает твой сервер, а результат ты возвращаешь Claude.
:::

::: step explain
Инструмент описывается тремя полями:

```python
tools = [{
    "name": "get_order_status",
    "description": "Возвращает статус заказа книжного магазина по номеру: собирается, передан в доставку, доставлен. Используй, когда клиент спрашивает, где его заказ. Не возвращает адрес и состав заказа.",
    "input_schema": {
        "type": "object",
        "properties": {
            "order_id": {"type": "string", "description": "Номер заказа, только цифры, например 1042"}
        },
        "required": ["order_id"],
    },
}]
```
:::

::: step explain
Дальше цикл:

1. Отправляешь запрос с `tools`.
2. Claude отвечает `stop_reason: "tool_use"` и блоком `tool_use` с `id`, `name` и `input`.
3. Твой код вызывает функцию.
4. Ты отправляешь новое сообщение `user` с блоком `tool_result` и тем же `tool_use_id`.
5. Claude пишет ответ клиенту.
:::

::: step explain
Главное в инструменте — *описание*. Документация называет его самым важным фактором качества. В описании:

- что делает инструмент;
- когда его использовать и когда *нет*;
- что значит каждый параметр;
- чего он не умеет.

Хотя бы 3–4 предложения. Если функция упала, верни `tool_result` с `"is_error": true` и понятным текстом: что случилось и что делать.
:::

::: step summary
**Claude не выполняет инструменты, он просит их вызвать. Выполняет и возвращает результат твой код.**

Инструмент = имя, подробное описание, схема входа. Ответ `tool_use` → твой вызов → `tool_result` с тем же `tool_use_id`.

Дальше: как не платить полную цену за одинаковое начало запросов.
:::
