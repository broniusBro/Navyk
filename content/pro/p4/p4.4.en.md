::: step hook
Tom built two services on the same model. The bot that answers “what time does the shop close” thinks for ages and costs as much as a consultant.

Meanwhile, the agent that hunts for a bug in a large project replies quickly and superficially.

Same model. What's missing?
:::

::: step explain
What's missing is the *effort* setting: how much work Claude puts into a reply. It's like telling a colleague “just give me a quick answer” or “dig into it properly”.

Levels: {{data.limits.pfour_effort_levels}}. Default: {{data.models.pfour_effort_defaults}}. Which levels are available depends on the model.
:::

::: step explain
effort affects *all* output tokens: the reply text, tool calls and thinking. It's a behavioural signal, not a hard limit.

```python
response = client.messages.create(
    model="{{data.models.pfour_haiku_id}}",
    max_tokens=2048,
    output_config={"effort": "low"},
    messages=[{"role": "user", "content": "What time do you close?"}],
)
```
:::

::: step explain
*Adaptive thinking* is a mode where Claude decides for itself whether to think before replying, and how much. effort tells it how hard to try.

```python
response = client.messages.create(
    model="{{data.models.pfour_opus_id}}",
    max_tokens=16000,
    thinking={"type": "adaptive"},
    output_config={"effort": "high"},
    messages=[{"role": "user", "content": "Find the cause of the memory leak: …"}],
)
```

Note: effort lives in `output_config`, not inside `thinking`.
:::

::: step explain
Thinking used to be switched on manually: `thinking: {"type": "enabled", "budget_tokens": …}`. That mode was deprecated on generation 4.6 models, and newer models don't accept it.

Thinking is billed as output tokens. Even if you hide its text with the `display` setting, the bill stays the same.
:::

::: step summary
**effort is the “how hard to try” dial: low for simple, high-volume work, high for complex work.**

Adaptive thinking decides when to think. effort is set in `output_config`, the manual `budget_tokens` doesn't work on new models, and thinking is billed as output.
