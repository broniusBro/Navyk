::: step explain
Цена считается за *миллион токенов* (MTok), отдельно за вход и за выход. Выходные токены дороже входных.

Формула: `токены × цена за MTok / 1 000 000`, для входа и выхода отдельно, потом сложить.
:::

::: step explain
Каждая модель в API вызывается по *ID*, например `{{data.models.pfour_haiku_id}}`. Это *закреплённый снимок*: поведение модели под этим ID не поменяется втихую. Новая версия приходит с новым ID.

У старых моделей (до поколения 4.6) был короткий *алиас*, который указывал на ID с датой. У каждой модели есть дата вывода из эксплуатации.
:::

::: step summary
**Начни с модели под задачу, проверь на своих данных и только потом масштабируй.**

Стоимость = токены × цена за миллион, отдельно вход и выход. ID модели — закреплённый снимок; держи его в конфиге.
