::: step hook
Клієнт пише боту книгарні з Рівного: «Де моє замовлення 1042?» Бот упевнено відповідає: «Ваше замовлення вже в дорозі!»

Замовлення ще навіть не зібрали. Бот не має доступу до бази і просто вгадав.
:::

::: step explain
*Tool use* — спосіб дати Claude інструменти: функції твого застосунку, які він може попросити викликати. Наприклад, «знайти замовлення за номером».

Важливо: Claude не виконує код сам. Він каже: «виклич get_order з номером 1042». Викликає твій сервер, а результат ти повертаєш Claude.
:::

::: step explain
Інструмент описують трьома полями:

```python
tools = [{
    "name": "get_order_status",
    "description": "Повертає статус замовлення книгарні за номером: збирається, передано в доставку, доставлено. Використовуй, коли клієнт питає, де його замовлення. Не повертає адресу й склад замовлення.",
    "input_schema": {
        "type": "object",
        "properties": {
            "order_id": {"type": "string", "description": "Номер замовлення, лише цифри, наприклад 1042"}
        },
        "required": ["order_id"],
    },
}]
```
:::

::: step explain
Далі цикл:

1. Надсилаєш запит із `tools`.
2. Claude відповідає `stop_reason: "tool_use"` і блоком `tool_use` з `id`, `name` та `input`.
3. Твій код викликає функцію.
4. Ти надсилаєш нове повідомлення `user` з блоком `tool_result` і тим самим `tool_use_id`.
5. Claude пише відповідь клієнтові.
:::

::: step explain
Головне в інструменті — *опис*. Документація називає його найважливішим чинником якості. В описі:

- що робить інструмент;
- коли його використовувати і коли *ні*;
- що означає кожен параметр;
- чого він не вміє.

Хоча б 3–4 речення. Якщо функція впала, поверни `tool_result` з `"is_error": true` і зрозумілим текстом: що сталося і що робити.
:::

::: step summary
**Claude не виконує інструменти, він просить їх викликати. Виконує й повертає результат твій код.**

Інструмент = назва, докладний опис, схема входу. Відповідь `tool_use` → твій виклик → `tool_result` з тим самим `tool_use_id`.

Далі: як не платити повну ціну за однаковий початок запитів.
:::
