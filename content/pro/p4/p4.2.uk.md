::: step explain
Ціна рахується за *мільйон токенів* (MTok), окремо за вхід і за вихід. Вихідні токени дорожчі за вхідні.

Формула: `токени × ціна за MTok / 1 000 000`, для входу й виходу окремо, потім додати.
:::

::: step explain
Кожну модель в API викликають за *ID*, наприклад `{{data.models.pfour_haiku_id}}`. Це *закріплений знімок*: поведінка моделі під цим ID не зміниться потай. Нова версія приходить з новим ID.

У старих моделей (до покоління 4.6) був короткий *аліас*, що вказував на ID з датою. У кожної моделі є дата виведення з експлуатації.
:::

::: step summary
**Почни з моделі під завдання, перевір на своїх даних і лише потім масштабуй.**

Вартість = токени × ціна за мільйон, окремо вхід і вихід. ID моделі — закріплений знімок; тримай його в конфігу.

Далі: системний промпт — як задати ботові роль і правила.
:::
