::: step hook
Ирина каждую ночь раскладывает по темам отзывы за день — 20 тысяч штук. Сейчас скрипт отправляет их по одному, как будто кто-то ждёт каждый ответ.

Но отчёт смотрят только утром. Зачем платить за скорость, которая никому не нужна?
:::

::: step explain
Для таких задач есть *Message Batches API* — пакетная обработка. Ты отправляешь сразу много запросов, а результаты забираешь позже.

Цена — {{data.prices.pfour_batch_discount}} от обычной, и на входные, и на выходные токены. Взамен ждёшь: {{data.limits.pfour_batch_typical}}, максимум {{data.limits.pfour_batch_expire}}.
:::

::: step explain
Каждый запрос в пакете — это `custom_id` и обычные параметры Messages API:

```python
batch = client.messages.batches.create(
    requests=[
        {
            "custom_id": f"review-{r.id}",
            "params": {
                "model": "{{data.models.pfour_haiku_id}}",
                "max_tokens": 50,
                "messages": [{"role": "user", "content": r.text}],
            },
        }
        for r in reviews
    ]
)
```

`custom_id` — от 1 до 64 символов: латинские буквы, цифры, `-` и `_`.
:::

::: step explain
Пока пакет работает, `processing_status` равен `in_progress`. Когда станет `ended`, забираешь результаты:

```python
for item in client.messages.batches.results(batch.id):
    if item.result.type == "succeeded":
        save(item.custom_id, item.result.message)
```

Результаты приходят *в любом порядке*. Сопоставляй их только по `custom_id`. Хранятся они {{data.limits.pfour_batch_results_days}}.
:::

::: step explain
Не каждый запрос в пакете заканчивается успехом. У результата четыре типа:

- `succeeded` — готово, внутри обычный ответ;
- `errored` — ошибка в запросе или на сервере;
- `canceled` — ты отменил пакет раньше;
- `expired` — пакет не успел за {{data.limits.pfour_batch_expire}}.

За `errored`, `canceled` и `expired` не платишь.
:::

::: step summary
**Не ждёшь ответа прямо сейчас — отправляй пакетом и плати половину.**

Каждому запросу — уникальный `custom_id`, результаты сопоставляй только по нему. Кеширование и пакеты вместе дают максимальную экономию.

Модуль «Claude API» пройден: ключ, модели, системный промпт, effort, JSON по схеме, инструменты, кеш и пакеты.
