::: step hook
Ты пишешь Claude Code одну фразу:

```prompt
fix the failing tests
```

И видишь, как он сам запускает тесты, читает ошибки, ищет файлы, правит код и снова запускает тесты. Ты не говорил ему, какие файлы открыть и какие команды выполнить. Откуда он знает, что делать?
:::

::: step explain
Claude работает по *агентному циклу* из трёх фаз:

1. **Собрать контекст**: прочитать файлы, найти нужное.
2. **Действовать**: править код, запускать команды.
3. **Проверить результат**: запустить тесты, посмотреть вывод.

Если проверка не прошла, цикл повторяется. Каждый следующий шаг Claude выбирает по тому, что узнал на предыдущем.
:::

    why: "Без понимания кода правка будет наугад."

:::

::: step explain
Что делает цикл возможным? *Инструменты*. Без них Claude может только писать текст. С ними он действует.

Модель Claude рассуждает и решает, что делать. Claude Code вокруг неё даёт инструменты и следит, что модель видит. Эту оболочку называют *агентной обвязкой*.

Пять групп инструментов: работа с файлами, поиск, выполнение команд, веб и анализ кода.
:::

::: step explain
Ты тоже часть цикла. Если видишь, что Claude ушёл не туда:

- нажми {{data.ui_paths.p1_esc}} и напиши, что не так;
- или просто напечатай поправку и нажми Enter, не останавливая его. Сообщение встанет в очередь, и Claude прочитает его после текущего шага.

Начинать заново не нужно.
:::

::: step explain
Последний принцип из документации: *делегируй, а не диктуй*. Объясни задачу как толковому коллеге: что не так, где искать, как понять, что готово. Какие файлы читать и какие команды запускать, Claude решит сам.

```prompt
Оплата ломается у пользователей с просроченной картой. Код оплаты в src/payments/. Разберись и исправь.
```
:::

::: step summary
**Агентный цикл: собрать контекст → действовать → проверить, и так по кругу.**

Модель решает, инструменты действуют. Ты можешь вмешаться в любой момент: {{data.ui_paths.p1_esc}} или поправка в очередь. Давай задачу как коллеге: симптом, где искать, как понять, что готово.

Дальше: файл CLAUDE.md, чтобы не объяснять одно и то же каждый раз.
:::
