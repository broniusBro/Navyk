::: step hook
Олег нашёл в старом блоге команду установки Claude Code через npm, а в другом — через какой-то скрипт. Какую выбрать? И как понять, что всё получилось?

Официальная документация советует *нативный установщик*: одну команду для твоей системы. Разберём по шагам.
:::

::: step explain
Всё начинается в *терминале* — окне, куда пишут текстовые команды. На macOS это приложение «Терминал», на Windows — PowerShell.

Команда для macOS, Linux и WSL (Linux внутри Windows):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Для Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Установщик не показывает прогресс, просто подожди.
:::

question: "Соедини систему с командой установки из документации."
pairs:
  - left: "macOS, Linux или WSL"
    right: "curl -fsSL https://claude.ai/install.sh | bash"
    why: "Это нативный установщик для Unix-систем. Рекомендуемый способ: такая установка сама обновляется в фоне."
  - left: "Windows PowerShell"
    right: "irm https://claude.ai/install.ps1 | iex"
    why: "irm скачивает скрипт, iex его выполняет. Эта пара работает только в PowerShell."
  - left: "Windows CMD"
    right: "curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd"
    why: "В обычной командной строке CMD скрипт скачивается в файл, запускается и удаляется."
  - left: "macOS с менеджером пакетов Homebrew"
    right: "brew install --cask claude-code"
    why: "Тоже официальный способ, но такая установка сама не обновляется: время от времени нужно запускать brew upgrade claude-code."
hint: "Ищи подсказки в самих командах: .sh — для macOS и Linux, .ps1 — для PowerShell, .cmd — для CMD."
:::

::: step explain
Установил? Теперь проверь. Открой **новое** окно терминала (старое не знает о новой программе) и выполни:

```bash
claude --version
```

Если всё в порядке, появится номер версии и надпись `(Claude Code)`.

Если терминал пишет, что `claude` не найден, папка установки ещё не попала в *PATH* — список мест, где система ищет программы. Решение — в разделе Troubleshoot installation документации.
:::

::: step explain
Ещё про Windows: документация советует поставить Git for Windows. Тогда Claude Code сможет пользоваться привычной командной оболочкой Bash. Без него он будет работать через PowerShell. В WSL это не нужно.

Нативная установка обновляется сама в фоне. Установки через Homebrew и WinGet — нет, их обновляешь вручную.
:::

::: step explain
Осталось войти. Перейди в папку проекта командой `cd` и запусти Claude Code:

```bash
cd ~/projects/bakery-site
claude
```

При первом запуске откроется браузер для входа. Подойдёт {{data.plans.p1_cli_accounts}}.

Данные входа сохраняются, второй раз входить не нужно. Сменить аккаунт можно командой `/login` внутри сессии.
:::

::: step explain
Пара команд на каждый день. Их пишут прямо в поле ввода Claude Code:

- `/help` — список доступных команд;
- `/login` — войти или сменить аккаунт;
- `/exit` — выйти.

А эта команда пишется в обычном терминале и продолжает последний разговор в этой папке:

```bash
claude -c
```
:::

::: step summary
**Установка: одна команда нативного установщика → новое окно терминала → `claude --version`.**

Потом `cd` в папку проекта, `claude` и вход через браузер. Нативная версия обновляется сама.
