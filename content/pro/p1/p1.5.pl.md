::: step hook
Dziesiąty raz w ciągu pół godziny Claude pyta: „Czy mogę uruchomić npm test?” Klikasz już „tak” bez czytania.

A u Dawida odwrotnie: Claude sam usunął folder, którego nie wolno było ruszać.

Oba problemy rozwiązuje jedno ustawienie — *tryb uprawnień*.
:::

::: step explain
*Tryb uprawnień* określa, co Claude robi bez twojego potwierdzenia:

- {{data.ui_paths.p1_mode_manual}} — pyta przed edycją plików i poleceniami;
- {{data.ui_paths.p1_mode_accept_edits}} — sam edytuje pliki i wykonuje proste polecenia, takie jak `mkdir`, o resztę pyta;
- {{data.ui_paths.p1_mode_plan}} — bada projekt i proponuje plan, niczego nie edytuje;
- {{data.ui_paths.p1_mode_auto}} — model-klasyfikator sprawdza działania zamiast ciebie i blokuje ryzykowne.
:::

::: step explain
Przełączasz klawiszami {{data.ui_paths.p1_shift_tab}}. Każde naciśnięcie to kolejny tryb, a bieżący widać w wierszu pod polem wiadomości.

Od wersji {{data.limits.p1_auto_default_version}} sesja w terminalu i VS Code domyślnie startuje w trybie {{data.ui_paths.p1_mode_auto}}. Z trybu automatycznego kolejność jest taka: ręczny → edycje bez pytania → plan → znowu automatyczny.

Możesz od razu uruchomić potrzebny tryb:

```bash
claude --permission-mode plan
```

::: step explain
Żeby nie odpowiadać ciągle na te same pytania, załóż *listę dozwolonych poleceń* (allowlist). Polecenie `/permissions` otwiera okno reguł:

- **allow** — zezwalaj bez pytania;
- **ask** — zawsze pytaj;
- **deny** — zabroń.

Reguły sprawdzane są w kolejności deny → ask → allow i decyduje pierwsze dopasowanie. Dlatego zakazu deny nie da się „przebić” zezwoleniem.
:::

::: step explain
Reguły można zapisać w pliku `.claude/settings.json` w folderze projektu — wtedy dostanie je cały zespół. Gwiazdka `*` zastępuje dowolny tekst:

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "deny": ["Bash(git push *)"]
  }
}
```

Inny sposób: w pytaniu o uprawnienie wybierz {{data.ui_paths.p1_dont_ask_again}}, a reguła zapisze się sama.
:::

::: step summary
**Tryb uprawnień to ile swobody dajesz Claude. Przełączaj klawiszami {{data.ui_paths.p1_shift_tab}}.**

Ręczny pyta o wszystko; edycje bez pytania — sam edytuje; plan — tylko bada; automatyczny — sprawdza klasyfikator. Częste bezpieczne polecenia dopuść przez `/permissions`, niebezpieczne zablokuj przez deny.

Dalej: jak przeprowadzić zadanie przez plan.
:::
