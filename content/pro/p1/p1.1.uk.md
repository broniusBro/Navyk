::: step hook
Максим робить сайт для своєї пекарні. У звичайному чаті з Claude усе виглядає так:

1. просить код;
2. копіює його у файл;
3. запускає, отримує помилку;
4. копіює помилку назад у чат.

І так по колу. Половина часу йде на «скопіювати-вставити». А можна, щоб Claude сам відкрив файли, виправив їх і перевірив результат?
:::

::: step explain
Можна. Для цього є *Claude Code* — агентний інструмент для програмування.

*Агентний* означає, що Claude сам вибирає кроки: читає файли проєкту, редагує їх, запускає команди й дивиться на результат. Як майстер, якого впустили в майстерню, а не консультант по телефону.

Приклад цілого завдання:

```bash
claude "write tests for the auth module, run them, and fix any failures"
```
:::

::: step explain
Де живе Claude Code? Ці місця називають *поверхнями*:

- **Термінал** — вікно для текстових команд. Найповніша версія.
- **VS Code** (і Cursor) — розширення просто в редакторі коду.
- **JetBrains** (PyCharm, IntelliJ та інші) — плагін, потрібен ще Claude Code для термінала.
- **Застосунок Claude для комп'ютера** — {{data.ui_paths.p1_desktop_code_tab}}; {{data.plans.p1_desktop_plan}}.
:::

::: step explain
Ще дві поверхні працюють у хмарі:

- **Веб**: claude.ai/code у браузері, нічого не треба встановлювати.
- **Мобільний застосунок Claude** для iOS і Android.

*Хмарна сесія* йде на сервері Anthropic і працює, навіть коли ноутбук закритий. Код береться з GitHub. Хмарні сесії {{data.plans.p1_cloud_plans}}.
:::

::: step explain
Важлива деталь: усі поверхні працюють на одному рушії. Файл CLAUDE.md із правилами проєкту, налаштування й під'єднані сервіси діють скрізь.

Тому вибір поверхні — питання зручності, а не можливостей. Почати можна в терміналі, а продовжити в застосунку чи з телефона.
:::

::: step explain
Перший запит до незнайомого проєкту краще зробити запитанням, а не завданням на правку. Так Claude спершу вивчить код.

Порівняй:

```prompt
подивись проєкт
```

```prompt
Це сайт пекарні, він дістався мені від іншого розробника. Розкажи, що робить проєкт, на чому написаний, де точка входу і як запустити його локально. Поки нічого не змінюй.
```

У другому є контекст, зрозумілий результат і межа: «нічого не змінюй».
:::

::: step summary
**Claude Code — агент, який сам читає, редагує й перевіряє код у твоєму проєкті.**

Де запускати: термінал, VS Code, JetBrains, застосунок для комп'ютера — на твоєму комп'ютері; веб і мобільний застосунок — у хмарі. Рушій скрізь один.

Далі: встановлення і перший запуск.
:::
