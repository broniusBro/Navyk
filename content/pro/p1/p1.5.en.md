::: step hook
For the tenth time in half an hour, Claude asks: “Can I run npm test?” You're already clicking “yes” without reading.

Dave has the opposite problem: Claude deleted a folder all by itself, one it should never have touched.

Both problems come down to one setting: the *permission mode*.
:::

::: step explain
The *permission mode* decides what Claude does without your approval:

- {{data.ui_paths.p1_mode_manual}} — asks before editing files and running commands;
- {{data.ui_paths.p1_mode_accept_edits}} — edits files and runs simple commands like `mkdir` on its own, asks about everything else;
- {{data.ui_paths.p1_mode_plan}} — explores and proposes a plan, edits nothing;
- {{data.ui_paths.p1_mode_auto}} — a classifier model reviews actions on your behalf and blocks risky ones.
:::

::: step explain
You switch with {{data.ui_paths.p1_shift_tab}}. Each press moves to the next mode; the current one is shown in the line below the input field.

Since version {{data.limits.p1_auto_default_version}}, sessions in the terminal and VS Code start in {{data.ui_paths.p1_mode_auto}} by default. From Auto, the cycle goes: Manual → Accept edits → Plan → back to Auto.

You can also launch straight into the mode you want:

```bash
claude --permission-mode plan
```
:::

::: step explain
To stop answering the same questions, set up an *allowlist* of commands. The `/permissions` command opens the rules dialog:

- **allow** — permit without asking;
- **ask** — always ask;
- **deny** — forbid.

Rules are checked in the order deny → ask → allow, and the first match wins. That's why an allow rule can't override a deny.
:::

::: step explain
You can write the rules into `.claude/settings.json` in the project folder, and then the whole team gets them. An asterisk `*` stands for any text:

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "deny": ["Bash(git push *)"]
  }
}
```

Another way: choose {{data.ui_paths.p1_dont_ask_again}} in a permission prompt, and the rule is saved automatically.
:::

::: step summary
**The permission mode is how much freedom you give Claude. Switch with {{data.ui_paths.p1_shift_tab}}.**

Manual asks about everything; Accept edits edits on its own; Plan only explores; Auto relies on a classifier. Allow frequent safe commands with `/permissions` and block dangerous ones with deny.
