::: step hook
Десятый раз за полчаса Claude спрашивает: «Можно запустить npm test?» Ты уже жмёшь «да», не читая.

А у Дмитрия наоборот: Claude сам удалил папку, которую трогать было нельзя.

Обе проблемы решаются одной настройкой — *режимом разрешений*.
:::

::: step explain
*Режим разрешений* — что Claude делает без твоего подтверждения:

- {{data.ui_paths.p1_mode_manual}} — спрашивает перед правками файлов и командами;
- {{data.ui_paths.p1_mode_accept_edits}} — сам правит файлы и выполняет простые команды вроде `mkdir`, про остальное спрашивает;
- {{data.ui_paths.p1_mode_plan}} — изучает и предлагает план, ничего не правит;
- {{data.ui_paths.p1_mode_auto}} — модель-классификатор проверяет действия вместо тебя и блокирует рискованные.
:::

::: step explain
Переключение — клавиши {{data.ui_paths.p1_shift_tab}}. Каждое нажатие — следующий режим, текущий виден в строке под полем ввода.

С версии {{data.limits.p1_auto_default_version}} сессия в терминале и VS Code по умолчанию стартует в {{data.ui_paths.p1_mode_auto}}. Из автоматического режима круг идёт так: ручной → правки без вопросов → план → снова автоматический.

Можно сразу запустить нужный режим:

```bash
claude --permission-mode plan
```

::: step explain
Чтобы не отвечать на одни и те же вопросы, заведи *список разрешённых команд* (allowlist). Команда `/permissions` открывает диалог правил:

- **allow** — разрешить без вопросов;
- **ask** — всегда спрашивать;
- **deny** — запретить.

Проверка идёт в порядке deny → ask → allow, и первое совпадение решает. Поэтому deny нельзя «перебить» разрешением.
:::

::: step explain
Правила можно записать в файл `.claude/settings.json` в папке проекта, тогда их получит вся команда. Звёздочка `*` заменяет любой текст:

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "deny": ["Bash(git push *)"]
  }
}
```

Ещё способ: в запросе разрешения выбрать {{data.ui_paths.p1_dont_ask_again}}, и правило запишется само.
:::

::: step summary
**Режим разрешений — сколько свободы ты даёшь Claude. Переключай клавишами {{data.ui_paths.p1_shift_tab}}.**

Ручной — спрашивает про всё; правки без вопросов — правит сам; план — только изучает; автоматический — проверяет классификатор. Частые безопасные команды разреши через `/permissions`, опасные запрети через deny.
