::: step hook
Максим делает сайт для своей пекарни. В обычном чате с Claude он живёт так:

1. просит код;
2. копирует его в файл;
3. запускает, получает ошибку;
4. копирует ошибку обратно в чат.

И так по кругу. Половина времени уходит на «копировать-вставить». Можно ли, чтобы Claude сам открыл файлы, исправил их и проверил результат?
:::

::: step explain
Можно. Для этого есть *Claude Code* — агентный инструмент для программирования.

*Агентный* значит, что Claude сам выбирает шаги: читает файлы проекта, правит их, запускает команды и смотрит на результат. Как мастер, которого впустили в мастерскую, а не консультант по телефону.

Пример задачи целиком:

```bash
claude "write tests for the auth module, run them, and fix any failures"
```
:::

::: step explain
Где живёт Claude Code? Эти места называют *поверхностями*:

- **Терминал** — окно для текстовых команд. Самая полная версия.
- **VS Code** (и Cursor) — расширение прямо в редакторе кода.
- **JetBrains** (PyCharm, IntelliJ и другие) — плагин, нужен ещё Claude Code для терминала.
- **Приложение Claude для компьютера** — {{data.ui_paths.p1_desktop_code_tab}}; {{data.plans.p1_desktop_plan}}.
:::

::: step explain
Ещё две поверхности работают в облаке:

- **Веб**: claude.ai/code в браузере, ничего не надо устанавливать.
- **Мобильное приложение Claude** для iOS и Android.

*Облачная сессия* идёт на сервере Anthropic и работает, даже когда ноутбук закрыт. Код берётся из GitHub. Облачные сессии {{data.plans.p1_cloud_plans}}.
:::

::: step explain
Важная деталь: все поверхности работают на одном движке. Файл CLAUDE.md с правилами проекта, настройки и подключённые сервисы действуют везде.

Поэтому выбор поверхности — вопрос удобства, а не возможностей. Начать можно в терминале, а продолжить в приложении или с телефона.
:::

::: step explain
Первый запрос к незнакомому проекту лучше сделать вопросом, а не задачей на правку. Так Claude сначала изучит код.

Сравни:

```prompt
посмотри проект
```

```prompt
Это сайт пекарни, я его унаследовал от другого разработчика. Расскажи, что делает проект, на чём написан, где точка входа и как его запустить локально. Ничего пока не меняй.
```

Во втором есть контекст, понятный результат и граница: «ничего не меняй».
:::

::: step summary
**Claude Code — агент, который сам читает, правит и проверяет код в твоём проекте.**

Где запускать: терминал, VS Code, JetBrains, приложение для компьютера — на твоём компьютере; веб и мобильное приложение — в облаке. Движок везде один.
