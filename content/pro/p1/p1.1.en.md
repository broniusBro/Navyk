::: step hook
Mark is building a website for his bakery. Working with Claude in a regular chat goes like this:

1. he asks for code;
2. copies it into a file;
3. runs it and gets an error;
4. copies the error back into the chat.

Round and round. Half his time goes on copy-paste. Could Claude open the files itself, fix them and check the result?
:::

::: step explain
It can. That's what *Claude Code* is for: an agentic coding tool.

*Agentic* means Claude chooses the steps itself: it reads the project files, edits them, runs commands and looks at the result. Think of a tradesperson you've let into the workshop, not a consultant on the phone.

An example of a whole task:

```bash
claude "write tests for the auth module, run them, and fix any failures"
```
:::

::: step explain
Where does Claude Code live? These places are called *surfaces*:

- **Terminal** — a window for typing text commands. The most complete version.
- **VS Code** (and Cursor) — an extension right inside your code editor.
- **JetBrains** (PyCharm, IntelliJ and others) — a plugin; you also need Claude Code for the terminal.
- **Claude desktop app** — {{data.ui_paths.p1_desktop_code_tab}}; {{data.plans.p1_desktop_plan}}.
:::

::: step explain
Two more surfaces run in the cloud:

- **Web**: claude.ai/code in your browser, nothing to install.
- **Claude mobile app** for iOS and Android.

A *cloud session* runs on Anthropic's servers and keeps going even when your laptop is closed. The code comes from GitHub. Cloud sessions {{data.plans.p1_cloud_plans}}.
:::

::: step explain
An important detail: every surface runs on the same engine. The CLAUDE.md file with your project rules, your settings and your connected services work everywhere.

So choosing a surface is about convenience, not capability. You can start in the terminal and carry on in the app or on your phone.
:::

::: step explain
Your first prompt in an unfamiliar project is best phrased as a question, not an edit request. That way Claude explores the code first.

Compare:

```prompt
look at the project
```

```prompt
This is a bakery website I've taken over from another developer. Tell me what the project does, what it's written in, where the entry point is and how to run it locally. Don't change anything yet.
```

The second one has context, a clear outcome and a boundary: “don't change anything”.
:::

  - "Whether anything can be changed yet"

hint: "Start with one sentence about the project and your situation. Then list your questions: what it does, what it's written in, how to run it. And set a boundary: read only for now."
review:
  task: "First lesson of the Professional level. The learner writes a first prompt to Claude Code in an unfamiliar project (they may invent the project). A strong prompt: it's clear what they want — an overview of the project (R1); there's context — what the project is and why the learner is getting to grips with it (R2); it's clear what the answer should look like and what counts as good, e.g. a list of questions or a short structure (R4); there's a boundary on actions: read only, change nothing (R9). Specifying the answer format is a plus. Don't require technical detail: the audience aren't necessarily programmers."
  criteria: ["R1", "R2", "R4", "R9"]
  reference_prompt: |
    This is a Telegram bot that takes client bookings for my hair salon. A freelancer wrote it a year ago, and I want to make small changes myself. Explore the project and explain in plain language:
    1. What the bot does and what parts it's made of.
    2. What language and libraries it's written with.
    3. Where the entry point is and how to run it on my own computer.
    4. Whether there are tests and how to run them.
    Answer with a short list covering these points. Don't change anything yet, and don't run any commands that install things.
  show_reference: true
  fallback_feedback:
    - "Is it clear what the project is and why you're getting to grips with it?"
    - "Have you said exactly what you want to find out: purpose, language, how to run it, tests?"
    - "Have you set the form of the answer, e.g. a short bullet list?"
    - "Is there a boundary: read only for now, change nothing?"

::: step summary
**Claude Code is an agent that reads, edits and checks the code in your project by itself.**

Where to run it: the terminal, VS Code, JetBrains and the desktop app run on your computer; the web and the mobile app run in the cloud. It's the same engine everywhere.
