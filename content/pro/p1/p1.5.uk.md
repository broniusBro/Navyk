::: step hook
Удесяте за пів години Claude питає: «Можна запустити npm test?» Ти вже тиснеш «так», не читаючи.

А в Дмитра навпаки: Claude сам видалив теку, яку чіпати було не можна.

Обидві проблеми розв'язує одне налаштування — *режим дозволів*.
:::

::: step explain
*Режим дозволів* — що Claude робить без твого підтвердження:

- {{data.ui_paths.p1_mode_manual}} — питає перед правками файлів і командами;
- {{data.ui_paths.p1_mode_accept_edits}} — сам редагує файли й виконує прості команди на кшталт `mkdir`, про решту питає;
- {{data.ui_paths.p1_mode_plan}} — вивчає й пропонує план, нічого не редагує;
- {{data.ui_paths.p1_mode_auto}} — модель-класифікатор перевіряє дії замість тебе й блокує ризиковані.
:::

::: step explain
Перемикання — клавіші {{data.ui_paths.p1_shift_tab}}. Кожне натискання — наступний режим, поточний видно в рядку під полем введення.

З версії {{data.limits.p1_auto_default_version}} сесія в терміналі й VS Code за замовчуванням стартує в {{data.ui_paths.p1_mode_auto}}. З автоматичного режиму коло йде так: ручний → правки без запитань → план → знову автоматичний.

Можна одразу запустити потрібний режим:

```bash
claude --permission-mode plan
```

::: step explain
Щоб не відповідати на ті самі запитання, заведи *список дозволених команд* (allowlist). Команда `/permissions` відкриває діалог правил:

- **allow** — дозволити без запитань;
- **ask** — завжди питати;
- **deny** — заборонити.

Перевірка йде в порядку deny → ask → allow, і перший збіг вирішує. Тому deny не можна «перебити» дозволом.
:::

::: step explain
Правила можна записати у файл `.claude/settings.json` у теці проєкту, тоді їх отримає вся команда. Зірочка `*` замінює будь-який текст:

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "deny": ["Bash(git push *)"]
  }
}
```

Ще один спосіб: у запиті дозволу вибрати {{data.ui_paths.p1_dont_ask_again}}, і правило запишеться саме.
:::

::: step summary
**Режим дозволів — скільки свободи ти даєш Claude. Перемикай клавішами {{data.ui_paths.p1_shift_tab}}.**

Ручний — питає про все; правки без запитань — редагує сам; план — лише вивчає; автоматичний — перевіряє класифікатор. Часті безпечні команди дозволь через `/permissions`, небезпечні заборони через deny.

Далі: як провести завдання через план.
:::
