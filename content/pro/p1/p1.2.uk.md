::: step hook
Олег знайшов у старому блозі команду встановлення Claude Code через npm, а в іншому — через якийсь скрипт. Яку вибрати? І як зрозуміти, що все вдалося?

Офіційна документація радить *нативний інсталятор*: одну команду для твоєї системи. Розберімо крок за кроком.
:::

::: step explain
Усе починається в *терміналі* — вікні, куди пишуть текстові команди. На macOS це застосунок «Термінал», на Windows — PowerShell.

Команда для macOS, Linux і WSL (Linux усередині Windows):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Для Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Інсталятор не показує поступу, просто зачекай.
:::

  - left: "macOS із менеджером пакетів Homebrew"

::: step explain
Встановив? Тепер перевір. Відкрий **нове** вікно термінала (старе не знає про нову програму) і виконай:

```bash
claude --version
```

Якщо все гаразд, з'явиться номер версії і напис `(Claude Code)`.

Якщо термінал пише, що `claude` не знайдено, теки встановлення ще немає в *PATH* — списку місць, де система шукає програми. Розв'язання — у розділі Troubleshoot installation документації.
:::

::: step explain
Ще про Windows: документація радить встановити Git for Windows. Тоді Claude Code зможе користуватися звичною командною оболонкою Bash. Без нього він працюватиме через PowerShell. У WSL це не потрібно.

Нативне встановлення оновлюється саме у фоні. Встановлення через Homebrew і WinGet — ні, їх оновлюєш уручну.
:::

::: step explain
Залишилося увійти. Перейди в теку проєкту командою `cd` і запусти Claude Code:

```bash
cd ~/projects/bakery-site
claude
```

Під час першого запуску відкриється браузер для входу. Підійде {{data.plans.p1_cli_accounts}}.

Дані входу зберігаються, вдруге входити не треба. Змінити акаунт можна командою `/login` усередині сесії.
:::

::: step explain
Кілька команд на щодень. Їх пишуть просто в поле введення Claude Code:

- `/help` — список доступних команд;
- `/login` — увійти або змінити акаунт;
- `/exit` — вийти.

А цю команду пишуть у звичайному терміналі, і вона продовжує останню розмову в цій теці:

```bash
claude -c
```
:::

::: step summary
**Встановлення: одна команда нативного інсталятора → нове вікно термінала → `claude --version`.**

Потім `cd` у теку проєкту, `claude` і вхід через браузер. Нативна версія оновлюється сама.

Далі: що Claude робить, коли ти даєш йому завдання.
:::
