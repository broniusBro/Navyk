::: step hook
Марина робить сервіс для бухгалтерів: завантажуєш таблицю продажів, агент рахує, будує графіки й пише звіт.

Агента вона вже зібрала на Agent SDK, і на ноутбуці все працює. Але тепер сервісом користуватимуться сотні клієнтів. Де працюватиме агент? Хто відповідає за сервери, ізоляцію і збереження сесій?
:::

::: step explain
Головне питання — *хто крутить цикл агента*: «запитати модель → виконати інструмент → повернути результат».

- **Client SDK** (пакет `anthropic`): цикл пишеш ти сам. Кожен виклик моделі й кожен інструмент — твій код.
- **Agent SDK**: цикл та інструменти готові, але працюють у твоєму процесі, на твоїх серверах.
- **Managed Agents**: цикл і пісочницю запускає Anthropic, а ти керуєш ними через API.
:::

  - left: "Managed Agents"

hint: "Рухайся від «усе пишу сам» до «усе запускає платформа»."
:::

::: step explain
У *Managed Agents* три сутності:

- **Agent** — налаштування агента: модель, системний промпт, інструменти.
- **Environment** — шаблон контейнера: пакети, доступ до мережі.
- **Session** — один запуск: пов'язує агента з оточенням, підключає файли й віддає потік подій.

Агента й оточення створюють один раз, а сесій запускають скільки потрібно. Зараз це бета: в API — розділ `client.beta`.
:::

::: step summary
**Вибір — це відповідь на питання «хто крутить цикл агента».**

Client SDK — ти сам. Agent SDK — готова бібліотека у твоєму процесі. Managed Agents — платформа Anthropic.

Managed Agents зараз у беті, тож деталі перевіряй у документації перед запуском.

Далі: як не потонути в контексті, коли агент працює довго.
:::
