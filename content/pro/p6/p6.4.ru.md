::: step hook
Марина делает сервис для бухгалтеров: загружаешь таблицу продаж, агент считает, строит графики и пишет отчёт.

Агента она уже собрала на Agent SDK, и на ноутбуке всё работает. Но теперь сервисом будут пользоваться сотни клиентов. Где будет работать агент? Кто отвечает за серверы, изоляцию и сохранение сессий?
:::

::: step explain
Главный вопрос — *кто крутит цикл агента*: «спросить модель → выполнить инструмент → вернуть результат».

- **Client SDK** (пакет `anthropic`): цикл пишешь ты сам. Каждый вызов модели и каждый инструмент — твой код.
- **Agent SDK**: цикл и инструменты готовые, но работают в твоём процессе, на твоих серверах.
- **Managed Agents**: цикл и песочницу запускает Anthropic, а ты управляешь ими через API.
:::

pairs:
  - left: "Client SDK"
    right: "В коде, который ты пишешь сам, вызов за вызовом"
    why: "Ты сам решаешь, что делать после каждого ответа модели. Максимум контроля и максимум работы."
  - left: "Agent SDK"
    right: "В готовой библиотеке внутри твоего процесса"
    why: "Цикл и инструменты Claude Code готовы, но процесс работает на твоей машине или сервере. Хостинг и изоляция — твоя забота."
  - left: "Managed Agents"
    right: "На стороне Anthropic, вместе с песочницей"
    why: "Ты создаёшь агента и сессию через API и читаешь события, а цикл и контейнер работают у Anthropic."
hint: "Двигайся от «всё пишу сам» к «всё запускает платформа»."
:::

::: step explain
В *Managed Agents* три сущности:

- **Agent** — настройки агента: модель, системный промпт, инструменты.
- **Environment** — шаблон контейнера: пакеты, доступ к сети.
- **Session** — один запуск: связывает агента с окружением, подключает файлы и отдаёт поток событий.

Агента и окружение создают один раз, а сессий запускают сколько нужно. Сейчас это бета: в API — раздел `client.beta`.
:::

::: step summary
**Выбор — это ответ на вопрос «кто крутит цикл агента».**

Client SDK — ты сам. Agent SDK — готовая библиотека в твоём процессе. Managed Agents — платформа Anthropic.

Managed Agents сейчас в бете, поэтому детали проверяй в документации перед запуском.
