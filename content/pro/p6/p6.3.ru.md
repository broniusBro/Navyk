::: step hook
Андрей хочет агента, который прочитает проект интернет-магазина и найдёт все пометки TODO.

Писать агента с нуля — значит самому крутить цикл: спросить модель, выполнить инструмент, вернуть результат, снова спросить. Плюс сами инструменты: чтение файлов, поиск, команды.

А можно взять всё это готовым.
:::

::: step explain
*Claude Agent SDK* — библиотека, которая даёт твоей программе тот же цикл агента и те же инструменты, что у Claude Code: чтение и правка файлов, поиск, команды терминала.

Есть версии для Python и TypeScript:

```bash
pip install claude-agent-sdk                 # Python 3.10+
npm install @anthropic-ai/claude-agent-sdk   # Node.js 18+
```

Ключ API берётся из переменной окружения `ANTHROPIC_API_KEY`. В код его не пиши.
:::

::: step example
Агент Андрея на Python. Главный вызов — `query()`: он запускает цикл и по ходу работы отдаёт сообщения.

```python
import anyio
from claude_agent_sdk import query, ClaudeAgentOptions

options = ClaudeAgentOptions(
    cwd="./shop",                            # папка проекта
    tools=["Read", "Grep", "Glob"],          # какие инструменты вообще есть
    allowed_tools=["Read", "Grep", "Glob"],  # выполнять без вопроса
    permission_mode="dontAsk",               # всё остальное отклонять
)

async def main():
    async for message in query(prompt="Найди все TODO и сгруппируй по файлам", options=options):
        print(message)

anyio.run(main)
```
:::

::: step example
То же на TypeScript. Названия опций в стиле camelCase:

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Найди все TODO и сгруппируй по файлам",
  options: {
    tools: ["Read", "Grep", "Glob"],
    allowedTools: ["Read", "Grep", "Glob"],
  },
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

Если не указать `permissionMode`, режим возьмётся из настроек Claude Code. Для предсказуемости задавай его явно.
:::

::: step explain
Права задаются четырьмя настройками:

- `tools` — какие инструменты вообще есть у агента;
- `allowed_tools` — какие выполняются без вопроса;
- `disallowed_tools` — какие запрещены;
- `permission_mode` — что делать со всеми остальными вызовами.

Ловушка: `allowed_tools` не убирает другие инструменты. Он только снимает вопрос для перечисленных.
:::

::: step summary
**Agent SDK = цикл и инструменты Claude Code внутри твоей программы.**

Главный вызов — `query()`. Права задают `tools`, `allowed_tools`, `disallowed_tools` и `permission_mode`. Помни: `allowed_tools` снимает вопрос, но не убирает инструменты.

Дальше: когда хватит Agent SDK, а когда лучше обычный клиент API или готовая платформа агентов.
:::
