::: step hook
Andrew wants an agent that reads through an online shop's codebase and finds every TODO comment.

Writing an agent from scratch means running the loop yourself: ask the model, run a tool, send back the result, ask again. On top of that, the tools themselves: reading files, searching, running commands.

Or you could get all of that ready-made.
:::

::: step explain
The *Claude Agent SDK* is a library that gives your program the same agent loop and the same tools as Claude Code: reading and editing files, search, terminal commands.

There are versions for Python and TypeScript:

```bash
pip install claude-agent-sdk                 # Python 3.10+
npm install @anthropic-ai/claude-agent-sdk   # Node.js 18+
```

The API key is read from the `ANTHROPIC_API_KEY` environment variable. Don't put it in your code.
:::

::: step example
Andrew's agent in Python. The main call is `query()`: it starts the loop and yields messages as it works.

```python
import anyio
from claude_agent_sdk import query, ClaudeAgentOptions

options = ClaudeAgentOptions(
    cwd="./shop",                            # project folder
    tools=["Read", "Grep", "Glob"],          # which tools exist at all
    allowed_tools=["Read", "Grep", "Glob"],  # run without asking
    permission_mode="dontAsk",               # deny everything else
)

async def main():
    async for message in query(prompt="Find every TODO and group them by file", options=options):
        print(message)

anyio.run(main)
```
:::

::: step example
The same in TypeScript. Option names are in camelCase:

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Find every TODO and group them by file",
  options: {
    tools: ["Read", "Grep", "Glob"],
    allowedTools: ["Read", "Grep", "Glob"],
  },
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

If you don't set `permissionMode`, the mode is taken from Claude Code's settings. For predictable behaviour, set it explicitly.
:::

::: step explain
Permissions come down to four settings:

- `tools`: which tools the agent has at all;
- `allowed_tools`: which ones run without asking;
- `disallowed_tools`: which ones are blocked;
- `permission_mode`: what to do with every other call.

The trap: `allowed_tools` doesn't remove other tools. It only skips the question for the ones listed.
:::

::: step summary
**Agent SDK = Claude Code's loop and tools inside your program.**

The main call is `query()`. Permissions are set by `tools`, `allowed_tools`, `disallowed_tools` and `permission_mode`. Remember: `allowed_tools` skips the question but doesn't remove tools.
