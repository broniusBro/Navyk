::: step hook
Andrzej chce agenta, który przeczyta projekt sklepu internetowego i znajdzie wszystkie oznaczenia TODO.

Pisanie agenta od zera oznacza, że sam kręcisz pętlą: zapytaj model, uruchom narzędzie, zwróć wynik, zapytaj znowu. Do tego same narzędzia: czytanie plików, wyszukiwanie, polecenia.

A można to wszystko dostać gotowe.
:::

::: step explain
*Claude Agent SDK* to biblioteka, która daje twojemu programowi tę samą pętlę agenta i te same narzędzia co w Claude Code: czytanie i edycję plików, wyszukiwanie, polecenia terminala.

Są wersje dla Pythona i TypeScriptu:

```bash
pip install claude-agent-sdk                 # Python 3.10+
npm install @anthropic-ai/claude-agent-sdk   # Node.js 18+
```

Klucz API jest pobierany ze zmiennej środowiskowej `ANTHROPIC_API_KEY`. Nie wpisuj go w kod.
:::

::: step example
Agent Andrzeja w Pythonie. Główne wywołanie to `query()`: uruchamia pętlę i w trakcie pracy oddaje wiadomości.

```python
import anyio
from claude_agent_sdk import query, ClaudeAgentOptions

options = ClaudeAgentOptions(
    cwd="./shop",                            # folder projektu
    tools=["Read", "Grep", "Glob"],          # jakie narzędzia w ogóle są
    allowed_tools=["Read", "Grep", "Glob"],  # uruchamiać bez pytania
    permission_mode="dontAsk",               # wszystko inne odrzucać
)

async def main():
    async for message in query(prompt="Znajdź wszystkie TODO i pogrupuj je według plików", options=options):
        print(message)

anyio.run(main)
```
:::

::: step example
To samo w TypeScripcie. Nazwy opcji w stylu camelCase:

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Znajdź wszystkie TODO i pogrupuj je według plików",
  options: {
    tools: ["Read", "Grep", "Glob"],
    allowedTools: ["Read", "Grep", "Glob"],
  },
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

Jeśli nie podasz `permissionMode`, tryb zostanie wzięty z ustawień Claude Code. Dla przewidywalności ustawiaj go jawnie.
:::

::: step explain
Uprawnienia ustawiają cztery opcje:

- `tools` — jakie narzędzia agent w ogóle ma;
- `allowed_tools` — które działają bez pytania;
- `disallowed_tools` — które są zablokowane;
- `permission_mode` — co robić ze wszystkimi pozostałymi wywołaniami.

Pułapka: `allowed_tools` nie usuwa innych narzędzi. Zdejmuje tylko pytanie dla wymienionych.
:::

::: step summary
**Agent SDK = pętla i narzędzia Claude Code wewnątrz twojego programu.**

Główne wywołanie to `query()`. Uprawnienia ustawiają `tools`, `allowed_tools`, `disallowed_tools` i `permission_mode`. Pamiętaj: `allowed_tools` zdejmuje pytanie, ale nie usuwa narzędzi.

Dalej: kiedy wystarczy Agent SDK, a kiedy lepszy będzie zwykły klient API albo gotowa platforma agentów.
:::
