::: step hook
Marta robi usługę dla księgowych: wgrywasz arkusz sprzedaży, a agent liczy, rysuje wykresy i pisze raport.

Agenta zbudowała już na Agent SDK i na laptopie wszystko działa. Ale teraz z usługi będą korzystać setki klientów. Gdzie będzie działał agent? Kto odpowiada za serwery, izolację i przechowywanie sesji?
:::

::: step explain
Najważniejsze pytanie brzmi: *kto kręci pętlą agenta*, czyli „zapytaj model → uruchom narzędzie → zwróć wynik”.

- **Client SDK** (pakiet `anthropic`): pętlę piszesz sam. Każde wywołanie modelu i każde narzędzie to twój kod.
- **Agent SDK**: pętla i narzędzia są gotowe, ale działają w twoim procesie, na twoich serwerach.
- **Managed Agents**: pętlę i piaskownicę uruchamia Anthropic, a ty sterujesz nimi przez API.
:::

pairs:
  - left: "Client SDK"
    right: "W kodzie, który piszesz sam, wywołanie po wywołaniu"
    why: "Sam decydujesz, co zrobić po każdej odpowiedzi modelu. Maksimum kontroli i maksimum pracy."
  - left: "Agent SDK"
    right: "W gotowej bibliotece wewnątrz twojego procesu"
    why: "Pętla i narzędzia Claude Code są gotowe, ale proces działa na twojej maszynie lub serwerze. Hosting i izolacja to twoja sprawa."
  - left: "Managed Agents"
    right: "Po stronie Anthropic, razem z piaskownicą"
    why: "Tworzysz agenta i sesję przez API i czytasz zdarzenia, a pętla i kontener działają u Anthropic."
hint: "Przesuwaj się od „wszystko piszę sam” do „wszystko uruchamia platforma”."
:::

::: step explain
W *Managed Agents* są trzy elementy:

- **Agent** — ustawienia agenta: model, prompt systemowy, narzędzia.
- **Environment** — szablon kontenera: pakiety, dostęp do sieci.
- **Session** — jedno uruchomienie: łączy agenta ze środowiskiem, podpina pliki i oddaje strumień zdarzeń.

Agenta i środowisko tworzy się raz, a sesji uruchamia się tyle, ile trzeba. Na razie to beta: w API to sekcja `client.beta`.
:::

::: step summary
**Wybór to odpowiedź na pytanie „kto kręci pętlą agenta”.**

Client SDK — ty sam. Agent SDK — gotowa biblioteka w twoim procesie. Managed Agents — platforma Anthropic.

Managed Agents jest na razie w becie, więc przed uruchomieniem sprawdź szczegóły w dokumentacji.

Dalej: jak nie utonąć w kontekście, gdy agent pracuje długo.
