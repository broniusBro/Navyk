::: step hook
Андрій хоче агента, який прочитає проєкт інтернет-крамниці й знайде всі позначки TODO.

Писати агента з нуля означає самому крутити цикл: запитати модель, виконати інструмент, повернути результат, знову запитати. До того ж самі інструменти: читання файлів, пошук, команди.

А можна взяти все це готовим.
:::

::: step explain
*Claude Agent SDK* — бібліотека, яка дає твоїй програмі той самий цикл агента й ті самі інструменти, що й у Claude Code: читання та редагування файлів, пошук, команди термінала.

Є версії для Python і TypeScript:

```bash
pip install claude-agent-sdk                 # Python 3.10+
npm install @anthropic-ai/claude-agent-sdk   # Node.js 18+
```

Ключ API береться зі змінної оточення `ANTHROPIC_API_KEY`. У код його не пиши.
:::

::: step example
Агент Андрія на Python. Головний виклик — `query()`: він запускає цикл і під час роботи віддає повідомлення.

```python
import anyio
from claude_agent_sdk import query, ClaudeAgentOptions

options = ClaudeAgentOptions(
    cwd="./shop",                            # тека проєкту
    tools=["Read", "Grep", "Glob"],          # які інструменти взагалі є
    allowed_tools=["Read", "Grep", "Glob"],  # виконувати без запитання
    permission_mode="dontAsk",               # усе інше відхиляти
)

async def main():
    async for message in query(prompt="Знайди всі TODO і згрупуй за файлами", options=options):
        print(message)

anyio.run(main)
```
:::

::: step example
Те саме на TypeScript. Назви опцій у стилі camelCase:

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Знайди всі TODO і згрупуй за файлами",
  options: {
    tools: ["Read", "Grep", "Glob"],
    allowedTools: ["Read", "Grep", "Glob"],
  },
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

Якщо не вказати `permissionMode`, режим візьметься з налаштувань Claude Code. Для передбачуваності задавай його явно.
:::

::: step explain
Права задають чотири налаштування:

- `tools` — які інструменти взагалі є в агента;
- `allowed_tools` — які виконуються без запитання;
- `disallowed_tools` — які заборонені;
- `permission_mode` — що робити з усіма іншими викликами.

Пастка: `allowed_tools` не прибирає інші інструменти. Він лише знімає запитання для перелічених.
:::

::: step summary
**Agent SDK = цикл та інструменти Claude Code всередині твоєї програми.**

Головний виклик — `query()`. Права задають `tools`, `allowed_tools`, `disallowed_tools` і `permission_mode`. Пам'ятай: `allowed_tools` знімає запитання, але не прибирає інструменти.

Далі: коли вистачить Agent SDK, а коли краще звичайний клієнт API чи готова платформа агентів.
:::
