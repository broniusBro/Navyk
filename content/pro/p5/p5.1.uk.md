::: step hook
Тарас написав інтеграцію свого таск-трекера з Claude Desktop. За місяць команда перейшла на Claude Code, а ще за місяць попросила те саме в редакторі коду.

Щоразу він переписував інтеграцію заново.

Як зробити підключення один раз, щоб воно працювало всюди?
:::

::: step explain
*MCP* (Model Context Protocol) — відкритий стандарт, за яким ШІ-застосунки підключаються до зовнішніх систем: файлів, баз даних, API, робочих процесів.

Творці протоколу порівнюють його з портом USB-C. Будь-який кабель USB-C підходить до будь-якого ноутбука. Так і MCP-сервер, написаний один раз, підключається до Claude, ChatGPT, Visual Studio Code, Cursor та інших застосунків.
:::

::: step explain
У будь-якій MCP-схемі три ролі:

- *Хост* (host) — ШІ-застосунок, з яким працює людина: Claude Code, Claude Desktop, редактор коду.
- *Клієнт* (client) — компонент усередині хоста. На кожен сервер хост створює окремого клієнта з виділеним підключенням.
- *Сервер* (server) — програма, яка надає контекст та інструменти. Працює локально на твоєму комп'ютері або віддалено в інтернеті.
:::

::: step example
Приклад із документації MCP. Visual Studio Code — хост. Розробник підключив до нього два сервери:

- віддалений сервер Sentry з помилками застосунку;
- локальний сервер файлової системи.

Усередині VS Code з'являються два клієнти: один тримає зв'язок із Sentry, другий — із файловою системою. Клієнти між собою не змішуються.
:::

::: step explain
Важливий принцип безпеки: сервер отримує лише те, що йому потрібно для запиту.

Повна історія розмови залишається в хоста. Сервер не може прочитати весь чат і не може «зазирнути» в інші сервери. Взаємодію між серверами контролює хост.

Тому сервер погоди не дізнається, про що ти листувався із сервером банку.
:::

::: step summary
**MCP — відкритий стандарт підключення ШІ-застосунків до зовнішніх систем, «USB-C для ШІ».**

Хост — застосунок, з яким працює людина. Клієнт — компонент хоста, по одному на сервер. Сервер — програма з даними та інструментами, локальна чи віддалена.

Урок спирається на специфікацію MCP версії {{data.versions.pfive_mcp_spec}}. Далі: що саме сервер може дати хосту.
:::
