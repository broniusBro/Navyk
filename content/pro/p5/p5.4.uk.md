::: step hook
Богдан питає Claude, скільки днів лишилося до дедлайну. Інколи відповідь неточна: модель може не знати сьогоднішньої дати або помилитися в підрахунку.

Порахувати дати може звичайний код. Отже, можна дати Claude інструмент, який робить це точно.

Зберімо такий MCP-сервер на Python: один інструмент, приблизно 20 рядків.
:::

::: step explain
Робимо за офіційним посібником MCP для версії {{data.versions.pfive_mcp_spec}}. Знадобляться Python 3.10+ і менеджер пакетів `uv`. Python SDK MCP — версії {{data.versions.pfive_python_sdk_min}} або новіший.

```bash
uv init deadlines
cd deadlines
uv venv
source .venv/bin/activate
uv add "mcp[cli]"
```

⚠️ У туторіалах до 2026 року імпорт інший (`FastMCP`). Звіряй код із версією SDK.
:::

::: step example
Файл `server.py`:

```python
from datetime import date

from mcp.server import MCPServer

mcp = MCPServer("deadlines")


@mcp.tool()
def days_until(deadline: str) -> str:
    """Count days from today to a deadline.

    Args:
        deadline: Date in YYYY-MM-DD format, e.g. 2026-12-31
    """
    try:
        target = date.fromisoformat(deadline)
    except ValueError:
        return "Invalid date. Use YYYY-MM-DD, e.g. 2026-12-31."
    return f"{(target - date.today()).days} days left until {deadline}."


if __name__ == "__main__":
    mcp.run(transport="stdio")
```
:::

::: step explain
Що тут важливо:

- `@mcp.tool()` перетворює функцію на інструмент MCP;
- ім'я функції стає ім'ям інструмента, а підказки типів — схемою параметрів;
- docstring стає описом. Саме його читає Claude, коли вирішує, чи викликати інструмент;
- `transport="stdio"` — сервер для локального запуску.

І правило з минулого уроку: жодних `print()`. Для логів є модуль `logging`, він пише в stderr.
:::

::: step explain
Підключаємо до Claude Code. Усе після `--` — команда, якою Claude Code запустить сервер:

```bash
claude mcp add --transport stdio deadlines -- uv --directory /ABSOLUTE/PATH/deadlines run server.py
```

Перевірити статус можна командою `/mcp` всередині Claude Code. Для Claude Desktop те саме пишеться в `claude_desktop_config.json`, у розділ `mcpServers`.

Без хоста сервер можна погоняти в MCP Inspector: `npx @modelcontextprotocol/inspector`.
:::

segments:
  - text: "@mcp.tool()\n"
    weak: false
    why: "Декоратор на місці: функція стане інструментом MCP."
  - text: "def calc(d):\n"
    weak: true
    why: "Ім'я calc і параметр d нічого не кажуть Claude, а без підказки типу схема параметра вийде порожньою. Краще days_until(deadline: str) -> str."
  - text: "    print(\"called\", d)\n"
    weak: true
    why: "print() пише в stdout, а в stdio-сервері цей канал зайнятий протоколом. Виклик зламає JSON-RPC. Логи — через logging, він пише в stderr."
  - text: "    \"\"\"Does stuff.\"\"\"\n"
    weak: true
    why: "Дві біди. Такий docstring не каже, що робить інструмент і в якому форматі дата. До того ж він стоїть після print(), а Python вважає docstring лише перший рядок тіла функції, тож опису не буде взагалі."
  - text: "    return (date.fromisoformat(d) - date.today()).days\n"
    weak: false
    why: "Сама логіка правильна. Можна додати зрозуміле повідомлення для неправильного формату дати, як у прикладі уроку."
hint: "Перевір кожен рядок: чи зрозуміле ім'я, чи не пише код у stdout і чи має Claude нормальний опис."

::: step summary
**MCP-сервер на Python — це функція з `@mcp.tool()`, підказками типів і добрим docstring плюс `mcp.run(transport="stdio")`.**

Підключай командою `claude mcp add ... -- <команда запуску>`, вказуй абсолютний шлях і не пиши в stdout.

Далі: як підключити сервер до різних продуктів Claude, зокрема до API.
:::
