::: step hook
Kuba napisał integrację swojego systemu do zadań z Claude Desktop. Miesiąc później zespół przesiadł się na Claude Code, a po kolejnym miesiącu poprosił o to samo w edytorze kodu.

Za każdym razem pisał integrację od nowa.

Jak zrobić połączenie raz, żeby działało wszędzie?
:::

::: step explain
*MCP* (Model Context Protocol) to otwarty standard, dzięki któremu aplikacje AI łączą się z systemami zewnętrznymi: plikami, bazami danych, API, procesami pracy.

Twórcy protokołu porównują go do portu USB-C. Każdy kabel USB-C pasuje do każdego laptopa. Tak samo serwer MCP napisany raz łączy się z Claude, ChatGPT, Visual Studio Code, Cursorem i innymi aplikacjami.
:::

::: step explain
W każdym schemacie MCP są trzy role:

- *Host* — aplikacja AI, w której pracuje człowiek: Claude Code, Claude Desktop, edytor kodu.
- *Klient* (client) — komponent wewnątrz hosta. Do każdego serwera host tworzy osobnego klienta z dedykowanym połączeniem.
- *Serwer* (server) — program, który dostarcza kontekst i narzędzia. Działa lokalnie na twoim komputerze albo zdalnie w internecie.
:::

::: step example
Przykład z dokumentacji MCP. Visual Studio Code jest hostem. Programista podłączył do niego dwa serwery:

- zdalny serwer Sentry z błędami aplikacji;
- lokalny serwer systemu plików.

W VS Code pojawiają się dwaj klienci: jeden utrzymuje połączenie z Sentry, drugi z systemem plików. Klienci nie mieszają się ze sobą.
:::

::: step explain
Ważna zasada bezpieczeństwa: serwer dostaje tylko to, czego potrzebuje do obsługi żądania.

Pełna historia rozmowy zostaje u hosta. Serwer nie może przeczytać całego czatu ani „zajrzeć” do innych serwerów. Interakcje między serwerami kontroluje host.

Dlatego serwer pogody nie dowie się, o czym rozmawiałeś z serwerem banku.
:::

::: step summary
**MCP to otwarty standard łączenia aplikacji AI z systemami zewnętrznymi, „USB-C dla AI”.**

Host to aplikacja, w której pracuje człowiek. Klient to komponent hosta, po jednym na serwer. Serwer to program z danymi i narzędziami, lokalny albo zdalny.

Lekcja opiera się na specyfikacji MCP w wersji {{data.versions.pfive_mcp_spec}}. Dalej: co dokładnie serwer może dać hostowi.
:::
