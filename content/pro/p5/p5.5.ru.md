::: step hook
У Марты есть удалённый MCP-сервер базы знаний компании: `https://kb.example.com/mcp`.

Он нужен сразу в трёх местах: в Claude Code у разработчиков, в claude.ai у отдела поддержки и в бэкенде чат-бота, который работает через Claude API.

Сервер один, а способов подключения четыре. Разберём каждый.
:::

::: step explain
**Claude Code.** Удалённый сервер добавляется одной командой, статус и вход через OAuth — в `/mcp` (подробно в уроке p2.5):

```bash
claude mcp add --transport http kb https://kb.example.com/mcp
```

Локальный сервер — через `--` и команду запуска, как в прошлом уроке.

Если ты вошёл в Claude Code с аккаунтом claude.ai, коннекторы из claude.ai появятся в Claude Code сами.
:::

::: step explain
**Claude Desktop, локальные серверы.** Они прописываются в `claude_desktop_config.json`, в раздел `mcpServers`: команда и аргументы запуска. После правки приложение нужно закрыть полностью и открыть снова.

Важно: такие локальные серверы работают только в Claude Desktop на этом компьютере. В claude.ai и Cowork их нет.
:::

::: step explain
**Claude.ai: custom connector.** Нужен удалённый сервер. Путь: {{data.ui_paths.pfive_customize_connectors}}, затем {{data.ui_paths.pfive_add_custom}}, вставить URL. OAuth-данные при необходимости задаются в {{data.ui_paths.pfive_advanced_settings}}.

Доступно на тарифах {{data.plans.pfive_custom_plans}}. На Free — {{data.plans.pfive_free_custom_max}} кастомный коннектор. В Team и Enterprise добавляет {{data.plans.pfive_team_custom_who}}.

Claude подключается из облака Anthropic, поэтому сервер должен быть доступен из интернета.
:::

::: step example
**Claude API: MCP connector.** Свой MCP-клиент писать не нужно: сервер указывается прямо в запросе к Messages API. Функция в бете, нужен заголовок `anthropic-beta`.

```bash
curl https://api.anthropic.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "anthropic-beta: {{data.versions.pfive_api_beta}}" \
  -d '{
    "model": "{{data.models.pfive_example_model_id}}",
    "max_tokens": 1000,
    "messages": [{"role": "user", "content": "Как оформить возврат?"}],
    "mcp_servers": [{
      "type": "url",
      "url": "https://kb.example.com/mcp",
      "name": "kb",
      "authorization_token": "YOUR_TOKEN"
    }],
    "tools": [{"type": "mcp_toolset", "mcp_server_name": "kb"}]
  }'
```
:::

::: step explain
Что важно знать про MCP connector:

- из возможностей MCP поддерживаются только вызовы инструментов;
- сервер должен быть доступен из интернета по HTTP, адрес начинается с `https://`. Локальный stdio-сервер напрямую не подключить;
- OAuth-токен ты получаешь и обновляешь сам, а в запрос передаёшь в `authorization_token`;
- в ответе появляются блоки `mcp_tool_use` и `mcp_tool_result`.
:::

::: step summary
**Claude Code — `claude mcp add`. Claude Desktop — локальные серверы в `claude_desktop_config.json`. Claude.ai — custom connector по URL удалённого сервера. API — MCP connector: `mcp_servers` плюс `mcp_toolset`.**

Для claude.ai и API сервер должен быть доступен из интернета. Подключай только серверы, которым доверяешь.
:::
