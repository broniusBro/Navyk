::: step hook
Марта має віддалений MCP-сервер бази знань компанії: `https://kb.example.com/mcp`.

Він потрібен одразу в трьох місцях: у Claude Code в розробників, у claude.ai у відділу підтримки і в бекенді чат-бота, який працює через Claude API.

Сервер один, а способів підключення чотири. Розберімо кожен.
:::

::: step explain
**Claude Code.** Віддалений сервер додається однією командою, статус і вхід через OAuth — у `/mcp` (докладно в уроці p2.5):

```bash
claude mcp add --transport http kb https://kb.example.com/mcp
```

Локальний сервер — через `--` і команду запуску, як у минулому уроці.

Якщо ти увійшов у Claude Code з акаунтом claude.ai, конектори з claude.ai з'являться в Claude Code самі.
:::

::: step explain
**Claude Desktop, локальні сервери.** Вони прописуються в `claude_desktop_config.json`, у розділ `mcpServers`: команда й аргументи запуску. Після зміни застосунок треба повністю закрити й відкрити знову.

Важливо: такі локальні сервери працюють лише в Claude Desktop на цьому комп'ютері. У claude.ai та Cowork їх немає.
:::

::: step explain
**Claude.ai: custom connector.** Потрібен віддалений сервер. Шлях: {{data.ui_paths.pfive_customize_connectors}}, далі {{data.ui_paths.pfive_add_custom}}, вставити URL. OAuth-дані за потреби задаються в {{data.ui_paths.pfive_advanced_settings}}.

Доступно на тарифах {{data.plans.pfive_custom_plans}}. На Free можна додати {{data.plans.pfive_free_custom_max}} власний конектор. У Team та Enterprise конектори додає {{data.plans.pfive_team_custom_who}}.

Claude підключається з хмари Anthropic, тому сервер має бути доступний з інтернету.
:::

::: step example
**Claude API: MCP connector.** Власний MCP-клієнт писати не треба: сервер указується прямо в запиті до Messages API. Функція в беті, потрібен заголовок `anthropic-beta`.

```bash
curl https://api.anthropic.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "anthropic-beta: {{data.versions.pfive_api_beta}}" \
  -d '{
    "model": "{{data.models.pfive_example_model_id}}",
    "max_tokens": 1000,
    "messages": [{"role": "user", "content": "Як оформити повернення?"}],
    "mcp_servers": [{
      "type": "url",
      "url": "https://kb.example.com/mcp",
      "name": "kb",
      "authorization_token": "YOUR_TOKEN"
    }],
    "tools": [{"type": "mcp_toolset", "mcp_server_name": "kb"}]
  }'
```
:::

::: step explain
Що важливо знати про MCP connector:

- з можливостей MCP підтримуються лише виклики інструментів;
- сервер має бути доступний з інтернету через HTTP, адреса починається з `https://`. Локальний stdio-сервер напряму не підключити;
- OAuth-токен ти отримуєш і оновлюєш сам, а в запит передаєш у `authorization_token`;
- у відповіді з'являються блоки `mcp_tool_use` і `mcp_tool_result`.
:::

::: step summary
**Claude Code — `claude mcp add`. Claude Desktop — локальні сервери в `claude_desktop_config.json`. Claude.ai — custom connector за URL віддаленого сервера. API — MCP connector: `mcp_servers` плюс `mcp_toolset`.**

Для claude.ai та API сервер має бути доступний з інтернету. Підключай лише сервери, яким довіряєш.
:::
