::: step hook
Marta ma zdalny serwer MCP z firmową bazą wiedzy: `https://kb.example.com/mcp`.

Jest potrzebny od razu w trzech miejscach: w Claude Code u programistów, w claude.ai w dziale wsparcia i w backendzie chatbota, który działa przez Claude API.

Serwer jest jeden, a sposoby podłączenia są cztery. Omówmy każdy.
:::

::: step explain
**Claude Code.** Zdalny serwer dodaje się jednym poleceniem, a status i logowanie przez OAuth są w `/mcp` (szczegóły w lekcji p2.5):

```bash
claude mcp add --transport http kb https://kb.example.com/mcp
```

Lokalny serwer — przez `--` i polecenie uruchomienia, jak w poprzedniej lekcji.

Jeśli zalogowałeś się do Claude Code kontem claude.ai, konektory z claude.ai pojawią się w Claude Code same.
:::

::: step explain
**Claude Desktop, serwery lokalne.** Wpisuje się je do `claude_desktop_config.json`, w sekcji `mcpServers`: polecenie i argumenty uruchomienia. Po zmianie aplikację trzeba całkowicie zamknąć i otworzyć ponownie.

Ważne: takie lokalne serwery działają tylko w Claude Desktop na tym komputerze. W claude.ai i Cowork ich nie ma.
:::

::: step explain
**Claude.ai: custom connector.** Potrzebny jest zdalny serwer. Ścieżka: {{data.ui_paths.pfive_customize_connectors}}, potem {{data.ui_paths.pfive_add_custom}}, wklej URL. Dane OAuth w razie potrzeby podajesz w {{data.ui_paths.pfive_advanced_settings}}.

Dostępne w planach {{data.plans.pfive_custom_plans}}. Na planie Free możesz dodać {{data.plans.pfive_free_custom_max}} własny konektor. W planach Team i Enterprise konektory dodaje {{data.plans.pfive_team_custom_who}}.

Claude łączy się z chmury Anthropic, więc serwer musi być dostępny z internetu.
:::

::: step example
**Claude API: MCP connector.** Nie musisz pisać własnego klienta MCP: serwer wskazuje się bezpośrednio w żądaniu do Messages API. Funkcja jest w becie, potrzebny jest nagłówek `anthropic-beta`.

```bash
curl https://api.anthropic.com/v1/messages \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "anthropic-beta: {{data.versions.pfive_api_beta}}" \
  -d '{
    "model": "{{data.models.pfive_example_model_id}}",
    "max_tokens": 1000,
    "messages": [{"role": "user", "content": "Jak zgłosić zwrot towaru?"}],
    "mcp_servers": [{
      "type": "url",
      "url": "https://kb.example.com/mcp",
      "name": "kb",
      "authorization_token": "YOUR_TOKEN"
    }],
    "tools": [{"type": "mcp_toolset", "mcp_server_name": "kb"}]
  }'
```
:::

::: step explain
Co warto wiedzieć o MCP connector:

- z możliwości MCP obsługiwane są tylko wywołania narzędzi;
- serwer musi być dostępny z internetu przez HTTP, a adres zaczyna się od `https://`. Lokalnego serwera stdio nie podłączysz bezpośrednio;
- token OAuth zdobywasz i odświeżasz sam, a w żądaniu przekazujesz go w `authorization_token`;
- w odpowiedzi pojawiają się bloki `mcp_tool_use` i `mcp_tool_result`.
:::

::: step summary
**Claude Code — `claude mcp add`. Claude Desktop — lokalne serwery w `claude_desktop_config.json`. Claude.ai — custom connector po URL zdalnego serwera. API — MCP connector: `mcp_servers` plus `mcp_toolset`.**

Dla claude.ai i API serwer musi być dostępny z internetu. Podłączaj tylko serwery, którym ufasz.
:::
