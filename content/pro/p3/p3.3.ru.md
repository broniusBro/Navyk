::: step hook
Ольга из Одессы ведёт сайт фотостудии. Ей нужно три вещи:

1. Каждую ночь проверять репозиторий сайта на битые ссылки.
2. Каждый час разбирать новые фото в папке на её Mac.
3. Следующие полчаса следить, закончился ли деплой.

Всё это «по расписанию», но инструменты нужны разные. Почему?
:::

::: step explain
Есть три способа запускать Claude по расписанию:

- *Routine в облаке* — работает без твоего компьютера, но видит только свежую копию репозитория.
- *Локальная задача в Desktop* — работает на твоём компьютере и видит твои файлы, но только пока приложение открыто и компьютер не спит.
- *`/loop`* — повторяет запрос внутри открытой сессии Claude Code. Закрыл сессию — повторы прекратились.
:::

::: step explain
Ещё три отличия:

| | Облако | Desktop | `/loop` |
|---|---|---|---|
| Спрашивает разрешения | нет | как настроишь | как в сессии |
| Минимальный интервал | {{data.limits.pthree_cloud_min_interval}} | {{data.limits.pthree_local_min_interval}} | {{data.limits.pthree_local_min_interval}} |
| Переживает перезапуск | да | да | частично, через `--resume` |

Короткое правило: надёжно и без компьютера — облако; нужны локальные файлы — Desktop; быстро последить в сессии — `/loop`.
:::

::: step explain
`/loop` — самый быстрый способ. Интервал и запрос:

```text
/loop 5m проверь, закончился ли деплой, и скажи, что произошло
```

Единицы: `s`, `m`, `h`, `d`. Без интервала Claude сам выбирает паузу между повторами, от минуты до часа.

Повторяющиеся задачи удаляются через {{data.limits.pthree_loop_expiry}}, в одной сессии их может быть до {{data.limits.pthree_loop_max_tasks}}. Разовое напоминание проще попросить словами: «через 45 минут проверь интеграционные тесты».
:::

::: step explain
Локальную задачу создают в Desktop: {{data.ui_paths.pthree_desktop_new_routine}}, затем {{data.ui_paths.pthree_desktop_local}}. Выбор {{data.ui_paths.pthree_desktop_cloud}} создаёт облачную routine.

Если компьютер спал, после пробуждения Desktop делает *один* догоняющий запуск за последний пропущенный срок (в пределах {{data.limits.pthree_desktop_catchup_window}}). Задача «на 9 утра» может выполниться в 11 вечера. Учитывай это в промпте.

::: step summary
**Выбор зависит от двух вопросов: нужен ли включённый компьютер и нужны ли локальные файлы.**

- Без компьютера, надёжно — routine в облаке (не чаще раза в час).
- Локальные файлы — задача в Desktop (компьютер не спит).
- Быстро последить — `/loop` в открытой сессии.

Дальше: автоматический ревью pull request в GitHub Actions.
