::: step hook
Андрей из Харькова каждое утро открывает Claude Code и пишет одно и то же: «Разбери вчерашний лог сборки и скажи, что сломалось».

Пять минут в день, двадцать пять в неделю. Он хочет, чтобы это делал скрипт, а он утром только читал готовый итог. Но Claude Code ведь интерактивный: он ждёт, что человек будет сидеть рядом?
:::

::: step explain
Не обязательно. У Claude Code есть *неинтерактивный режим*: флаг `-p` (полное имя `--print`). Claude выполняет запрос, печатает ответ и завершает работу. Как обычная команда терминала: запустил, получил вывод, пошёл дальше.

```bash
claude -p "Что делает модуль auth?"
```

При успехе команда возвращает код выхода 0, при сбое — ненулевой. Скрипт может на это опираться.
:::

::: step explain
Данные можно подать на вход через конвейер `|`, а ответ сохранить в файл:

```bash
cat build-error.txt | claude -p "кратко объясни причину ошибки сборки" > output.txt
```

На вход через stdin можно подать до {{data.limits.pthree_stdin_max}}. Больше — сохрани в файл и укажи путь в запросе.

Для скрипта удобнее JSON. Флаг `--output-format` бывает `text` (по умолчанию), `json` и `stream-json`.
:::

:::

::: step explain
Вот как Андрей достаёт из JSON только текст ответа. Утилита `jq` разбирает JSON прямо в терминале:

```bash
claude -p "Разбери лог build.log и перечисли ошибки" \
  --output-format json | jq -r '.result'
```

А вот поле `total_cost_usd`: это оценка стоимости на стороне клиента, реальный счёт может отличаться.
:::

::: step explain
Без человека некому нажать «разрешить». Поэтому права задают заранее:

- `--allowedTools "Read,Edit"` — эти инструменты работают без вопросов;
- `Bash(git diff *)` — разрешить только команды, которые начинаются с `git diff`. Пробел перед `*` важен;
- `--permission-mode dontAsk` — всё, что потребовало бы подтверждения, отклоняется.

Правило: разрешай ровно то, что нужно задаче.
:::

::: step explain
Иногда нужен второй шаг в том же разговоре. Флаг `--continue` продолжает последний разговор. Если скриптов несколько, надёжнее сохранить `session_id` и передать его в `--resume`:

```bash
session_id=$(claude -p "Начни ревью" --output-format json | jq -r '.session_id')
claude -p "Продолжи это ревью" --resume "$session_id"
```
:::

::: step explain
Ещё один флаг для скриптов — `--bare`. Он не загружает хуки, навыки, плагины, MCP-серверы, авто-память и CLAUDE.md. Результат одинаковый на любой машине: чужие настройки из `~/.claude` не вмешаются.

В режиме `--bare` вход по подписке не используется, нужен ключ API в переменной `ANTHROPIC_API_KEY`. Документация рекомендует `--bare` для скриптов и CI.
:::

::: step summary
**`claude -p` — Claude Code как обычная команда терминала.**

- `--output-format json` и `jq`: ответ в `result`, id в `session_id`.
- Права задаются заранее и узко: `--allowedTools`, `--permission-mode dontAsk`.
- `--resume "$id"` продолжает нужный разговор.
- Для CI — `--bare` и ключ API.
