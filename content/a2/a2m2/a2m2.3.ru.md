::: step hook
Ты познакомил{{g:ся|ась}} с Julią на языковом обмене в Кракове. Через пару дней она пишет:

```pl
Hej! Masz czas w czwartek? Może się spotkamy na kawę? | Привет! Ты свобод{{g:ен|на}} в четверг? Может, встретимся на кофе?
```

Как ответить, чтобы договориться: когда, во сколько и где? Всё это уже почти есть в твоём арсенале — *mogę, muszę, będę*, дни недели и время. Осталось собрать формулы.
:::

::: step explain
**Предложить — три вопроса: когда, во сколько, где.**

```pl
Masz czas w sobotę? | Ты свободен в субботу?
Pasuje ci o szóstej? | Тебе удобно в шесть?
O której się spotkamy? | Во сколько встретимся?
Gdzie się spotkamy? | Где встретимся?
Spotkajmy się pod Pałacem Kultury. | Давай встретимся у Дворца культуры.
Może o trzeciej pod metrem? | Может, в три у метро?
```

*Masz czas?* — дословно «у тебя есть время?», так поляки спрашивают «ты свободен?». *Pasuje ci* [пасу́е чи] — «тебе подходит», от *pasować* — «подходить, быть впору» (сравни с украинским «пасувати»).

**Pod** — «у, возле» места встречи: *pod kinem, pod zegarem* (у часов). Это польская особенность — по-русски «под кинотеатром» звучало бы странно.
:::

::: step explain
Согласиться или отказаться — и сразу предложить другое. **To może…?** — «тогда, может…?» — главная связка торга о времени.

| согласие | отказ | другой вариант |
|---|---|---|
| Jasne! Pewnie! | Niestety nie mogę. | To może w piątek? |
| Pasuje mi. | W czwartek nie dam rady. | A o ósmej? |
| Super, do zobaczenia! | Muszę pracować. | Może w weekend? |

*Nie dam rady* [нье дам ра́ды] — «не получится, не успею». Очень частая фраза, мягче, чем «nie mogę».
:::

  - options:
      - { text: "dam", correct: true, why: "«Nie dam rady» — устойчивая фраза «не получится». Dam — от dać, «дать»." }
      - { text: "mam", correct: false, why: "«Nie mam rady» — так не говорят. Правильно: nie dam rady." }
      - { text: "mogę", correct: false, why: "«Nie mogę rady» — смешение двух фраз. Либо nie mogę, либо nie dam rady." }
  - options:
      - { text: "To", correct: true, why: "«To może…?» — «тогда, может…?». То здесь значит «тогда, в таком случае»." }
      - { text: "Co", correct: false, why: "«Co może w czwartek?» — «что может в четверг?», бессмыслица." }
      - { text: "Jak", correct: false, why: "«Jak może» — «как может». Связка для нового предложения — «to może»." }
  - options:
      - { text: "Pasuje", correct: true, why: "«Pasuje mi!» — «мне подходит!». Отвечаем тем же глаголом, что в вопросе." }
      - { text: "Jasne", correct: false, why: "«Jasne mi» — неверно. «Jasne!» говорят без mi." }
      - { text: "Muszę", correct: false, why: "«Muszę mi» — бессмыслица. Здесь нужно согласие." }
hint: "Первый пропуск — часть устойчивой фразы отказа. Второй — связка «тогда». Третий — повтор глагола из первого вопроса."

::: step summary
**Договориться = когда + во сколько + где.** *Masz czas w…? O której? Gdzie się spotkamy? Pod…*

Согласие: *Jasne! Pasuje mi.* Отказ: *Nie dam rady, muszę…* Новое предложение: *To może…?* В конце — *Do zobaczenia!*

Дальше: итоговый разговор модуля — планы на отпуск.
:::
