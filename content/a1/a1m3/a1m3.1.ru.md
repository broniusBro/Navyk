::: step hook
Тебе пишет подруга из Гданьска: *Gdzie jesteś?* — «Где ты?» Ты отвечаешь:

```pl
Jestem w domu. | Я дома.
Jesteśmy w Gdańsku! | Мы в Гданьске!
```

В русском «есть» почти исчезло: мы говорим «я дома». А в польском *być* звучит в каждой фразе — и без него не обойтись.
:::

::: step explain
**Być [быть] — «быть». В настоящем времени у каждого лица своя форма:**

| | |
|---|---|
| ja *jestem* | я есть |
| ty *jesteś* | ты есть |
| on, ona, pan, pani *jest* | он/она есть |

**Местоимение обычно не говорят**: окончание уже показывает, кто. *Jestem w domu* — «я дома».

```pl
Jestem w domu. | Я дома.
Jesteś w Krakowie? | Ты в Кракове?
Ola jest w pracy. | Оля на работе.
```
:::

::: step explain
**Множественное число:**

| | |
|---|---|
| my *jesteśmy* | мы есть |
| wy *jesteście* | вы есть (друзьям) |
| oni, one, państwo *są* | они есть |

*Są* [сом] — с носовым *ą*. Ударение по правилу: *jes-TEŚ-my*, *jes-TEŚ-cie*.

```pl
Jesteśmy w Warszawie. | Мы в Варшаве.
Gdzie jesteście? | Где вы?
Mama i tata są w domu. | Мама и папа дома.
```
:::

::: step summary
**Być: jestem, jesteś, jest — jesteśmy, jesteście, są.** Местоимения можно не говорить, а сам глагол пропускать нельзя: *Jestem w domu*.

Ты уже знаешь: *w domu, w pracy*.

Дальше: числа до 20 и как сказать, сколько тебе лет.
:::
