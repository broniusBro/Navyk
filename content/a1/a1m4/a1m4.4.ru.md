::: step hook
Вечер пятницы, Варшава, кафе на Новом Святе. Ты заходишь, и официантка улыбается. Сегодня ты проведёшь весь разговор сам{{g:|а}} — от «добрый вечер» до «до свидания».

```pl
Dobry wieczór! Czy jest wolny stolik? | Добрый вечер! Есть свободный столик?
Tak, proszę bardzo. | Да, пожалуйста.
```
:::

::: step explain
**Разговор в кафе — это всегда 4 шага.** Ты уже знаешь почти все фразы:

1. Войти: *Dobry wieczór! Czy jest wolny stolik?*
2. Заказать: *Poproszę…* — официант спросит *Coś jeszcze?* («что-нибудь ещё?»), ответ: *To wszystko* («это всё»)
3. Поесть: официант скажет *Smacznego!* — «приятного аппетита», ты ответишь *Dziękuję!*
4. Заплатить: *Poproszę rachunek.*

```pl
Coś jeszcze? | Что-нибудь ещё?
To wszystko, dziękuję. | Это всё, спасибо.
Smacznego! | Приятного аппетита!
```
:::

  - options:
      - { text: "wszystko", correct: true, why: "To wszystko [фшы́стко] — «это всё». W перед sz оглушается в [ф]." }
      - { text: "wszyscy", correct: false, why: "Wszyscy — «все» (люди). А про заказ — wszystko, «всё»." }
      - { text: "dobrze", correct: false, why: "To dobrze — «это хорошо». Не ответ на «что-нибудь ещё?»." }
hint: "Официант спрашивает «что-нибудь ещё?», ты отвечаешь «нет, это всё»."

::: step explain
**Совет у официанта:** *Co pani poleca?* / *Co pan poleca?* — «что вы посоветуете?».

Обращайся к официанту на *pan/pani*. Позвать: *Przepraszam!* — не «девушка!» и не «официант!».

⚠️ *Menu* читается [мэ́ню], как по-русски. А *karta* — не только карта для оплаты, но и меню: *Poproszę kartę*.

```pl
Przepraszam! Co pani poleca? | Простите! Что вы посоветуете?
Polecam pierogi. | Советую вареники.
```
:::

::: step summary
**Разговор в кафе: войти → заказать (poproszę + -ę) → «to wszystko» → «poproszę rachunek» → kartą / gotówką → do widzenia.** К официанту — *pan/pani*, позвать — *przepraszam*.

Модуль «Кафе и еда» пройден! Ты уже можешь поесть в Польше, ни слова не сказав по-русски.
:::
