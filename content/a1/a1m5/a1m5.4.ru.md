::: step hook
Варшава, трамвай 17. Входит контролёр:

```pl
Dzień dobry, kontrola biletów. Ma pan bilet? | Добрый день, проверка билетов. У вас есть билет?
```

Хорошо, что у тебя есть ответ: *Tak, mam bilet.* Сегодня учим глагол, который поляки говорят каждые пять минут.
:::

::: step explain
По-русски мы говорим «**у меня есть** билет». А по-польски — «**я имею** билет»: *Mam bilet.*

**Не переводи дословно** «у меня есть»: *u mnie jest* по-польски звучит странно. Говори *mam*.

```pl
Mam bilet. | У меня есть билет.
Masz czas? | У тебя есть время?
Anna ma kartę miejską. | У Анны есть городская карта.
```

*Mam* [мам], *masz* [маш], *ma* [ма]. Украинцам проще: «я маю» — почти то же самое!
:::

::: exercise match_pairs
id: "a1m5.4.e1"
type: "match_pairs"
question: "Соедини форму mieć с переводом."
pairs:
  - { left: "mam", right: "у меня есть", why: "Mam — «я имею». Окончание -m у формы «я», как в jestem." }
  - { left: "masz", right: "у тебя есть", why: "Masz — «ты имеешь». Окончание -sz [ш] — почти всегда форма «ты», как в русском «-шь»." }
  - { left: "ma", right: "у него есть", why: "Ma — «он/она имеет». Самая короткая форма. С Pan/Pani тоже ma: Ma pan bilet?" }
  - { left: "mają", right: "у них есть", why: "Mają [ма́ён] — «они имеют». Носовое ą на конце звучит как [он]." }
hint: "Смотри на окончания: -m — я, -sz — ты, без окончания — он/она."
:::

::: step explain
Все формы *mieć* в настоящем времени:

```pl
ja mam | у меня есть
ty masz | у тебя есть
on, ona, pan, pani ma | у него, у неё, у вас (вежл.) есть
my mamy | у нас есть
wy macie | у вас есть
oni mają | у них есть
```

Как и с *być*, местоимение обычно опускают: окончание уже всё говорит. Вопрос — с *czy* в начале или просто интонацией: *Czy masz czas?* = *Masz czas?*
:::

::: step summary
**«У меня есть» = *mam*.** *Mam, masz, ma, mamy, macie, mają*. С *Pan/Pani* — *ma*.

Модуль «В городе» пройден: ты спросишь дорогу, поймёшь *prosto, w prawo*, сядешь в трамвай и покажешь билет.

Дальше: модуль «Магазин» — *Ile to kosztuje?*
:::
