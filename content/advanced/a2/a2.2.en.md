::: step hook
Emma runs a small café in Ghent. Claude made her an Excel file of the month's costs, with a total of €8,430.

Emma corrected the rent: it was €2,500, now it's €2,700. But the total stayed at €8,430.

The spreadsheet looks great, but it doesn't calculate anything. What went wrong?
:::

::: step explain
The “Total” cell contained a *fixed number*, not a *formula*.

A formula is like a till: ring up a new item and the total changes by itself. A fixed number is like a total written in pen on a receipt: you correct a line, but the total stays the same.

Claude can make spreadsheets with working formulas. But it's best to say so directly.
:::

::: exercise compare_answers
id: "a2.2.e1"
type: "compare_answers"
variant: "which_better"
question: "Emma asked for the spreadsheet twice. Which prompt is more likely to give her a spreadsheet that recalculates itself?"
cards:
  - id: "A"
    label: "Prompt 1"
    prompt: "Make an Excel file with my costs for October and work out the total."
    answer: |
      Done: the file “Costs_October.xlsx”. Total for the month: €8,430.
  - id: "B"
    label: "Prompt 2"
    prompt: "Make an Excel file with my costs for October. Calculate all totals and percentages with Excel formulas, not fixed numbers: I'll be changing the amounts and want the total to update by itself."
    answer: |
      Done: the file “Costs_October.xlsx”. The total in cell C14 uses the formula =SUM(C2:C13), and each item's share uses =C2/$C$14. Change any amount and the total and percentages will update.
options:
  - text: "Prompt 2: it says directly that formulas are needed and explains why"
    correct: true
    why: "Yes. The requirement “formulas, not fixed numbers” plus the reason “I'll be changing the amounts”, and Claude understands the spreadsheet needs to be live. In its reply, it even showed which formulas it used."
  - text: "Prompt 1: it's shorter, and Claude always uses formulas anyway"
    correct: false
    why: "Relying on “anyway” is risky. A total can just as easily be a fixed number. If it matters to you that the spreadsheet calculates itself, say so."
  - text: "There's no difference: both spreadsheets will show €8,430"
    correct: false
    why: "Today, yes. But when Emma changes the rent, only the spreadsheet with formulas will show the new total. The difference shows up when the data changes."
hint: "Imagine Emma changes one amount tomorrow. In which file does the total change?"
:::

::: step explain
How to describe a spreadsheet so it works from the start:

1. **What the spreadsheet is for** and who will change it.
2. **Input cells**: what you type in by hand (amounts, prices, rates).
3. **What gets calculated**: totals, percentages, balance — with formulas.
4. **Structure**: sheets and columns.
5. **Checking**: ask Claude to explain the formulas, and change a number yourself.
:::

::: exercise find_error
id: "a2.2.e2"
type: "find_error"
question: "Niall in Galway asks for a spreadsheet to work out his couriers' pay. Tap the weak spots."
prompt: "Make an Excel sheet for the pay of 6 couriers. The rate is €3.50 per delivery. Work out each person's total yourself and type it in as numbers. Do it the way it's usually done."
segments:
  - text: "Make an Excel sheet for the pay of 6 couriers. "
    weak: false
    why: "It's clear what file it is and what it's for. A good start."
  - text: "The rate is €3.50 per delivery. "
    weak: false
    why: "A concrete fact without which the calculation is impossible. Even better: ask for the rate in a separate cell so it can be changed in one place."
  - text: "Work out each person's total yourself and type it in as numbers. "
    weak: true
    why: "This leads straight to a “dead” spreadsheet: add a delivery and the total won't change. Better: “calculate the total with a formula: number of deliveries × rate”."
  - text: "Do it the way it's usually done."
    weak: true
    why: "Fails the colleague test. Which columns? Are there bonuses, deductions, taxes? Describe the structure yourself, or Claude will invent its own."
hint: "Find the spot that will stop the spreadsheet recalculating, and the spot where Claude has to guess."
:::

::: exercise build_prompt
id: "a2.2.e3"
type: "build_prompt"
question: "Build a prompt for a household budget spreadsheet that does its own maths. Leave out the blocks you don't need."
blocks:
  - id: "b1"
    text: "Make an Excel file for our household budget for 2027: my wife and I want to see how much is left each month and save €6,000 by December."
    role: "goal"
    why: "What to do and why. The goal “save €6,000” tells Claude it needs a balance and savings."
  - id: "b2"
    text: "“Input” sheet: income and spending by category, by month. This is where we type in the amounts by hand; highlight these cells in yellow."
    role: "context"
    why: "Input cells are kept separate from calculations. That way it's clear at a glance what can be changed and what should be left alone."
  - id: "b3"
    text: "“Totals” sheet: the balance for each month, savings so far this year and how much is still needed to reach €6,000 — all with formulas referencing the “Input” sheet."
    role: "format"
    why: "The key requirement of this lesson: totals use formulas. Change an amount on the “Input” sheet and “Totals” will update."
  - id: "b4"
    text: "At the end, briefly list which formulas are used in the totals so I can check them."
    role: "format"
    why: "An explanation of the formulas helps you check the spreadsheet even if you're not great with Excel."
  - id: "b5"
    text: "Make it as professional and beautiful as possible!"
    role: "noise"
    why: "Not a single specific requirement. What “professional” means for a budget, Claude will have to guess."
  - id: "b6"
    text: "Just type in the final totals to save time."
    role: "noise"
    why: "This contradicts the main point: fixed numbers instead of formulas will make the spreadsheet “dead”."
target_order: ["b1", "b2", "b3", "b4"]
hint: "Order: what the spreadsheet is for → where to enter data → what is calculated with formulas → how to check. Skip any block that would stop the spreadsheet calculating."
:::

::: exercise fill_gap
id: "a2.2.e4"
type: "fill_gap"
question: "Claude has sent the spreadsheet. Fill in the gaps in the checking plan."
text: "Open the file and ___ one amount on the input sheet. Check whether the total ___. Click the total cell and make sure it contains ___."
gaps:
  - options:
      - text: "change"
        correct: true
        why: "The quickest check: change an input number and see whether the spreadsheet responds."
      - text: "delete"
        correct: false
        why: "No need to delete anything: you could break references. Just change a number and then put it back."
      - text: "retype from scratch"
        correct: false
        why: "There's no reason to retype it. The point is to check how the spreadsheet reacts to a change."
  - options:
      - text: "has changed"
        correct: true
        why: "If the total changed, the formulas work. If not, the total is a fixed number."
      - text: "looks nice"
        correct: false
        why: "Looks matter, but a spreadsheet can look lovely and still not calculate. Check the maths first."
      - text: "matches last month"
        correct: false
        why: "Totals for different months aren't supposed to match. You're checking whether the spreadsheet reacts to your edit."
  - options:
      - text: "a formula, such as =SUM(…)"
        correct: true
        why: "The formula bar shows what's inside the cell. A formula starts with an “=” sign."
      - text: "bold text"
        correct: false
        why: "The font tells you nothing about the calculation. A fixed number can be bold too."
      - text: "a number without an “=” sign"
        correct: false
        why: "That's exactly the sign of a problem: a fixed number won't recalculate."
hint: "The check is simple: change → look → peek inside the cell."
:::

::: step summary
**A spreadsheet should calculate, not remember.** Ask for totals as formulas, describe the input cells separately, and explain what the spreadsheet is for.

Got the file? Change one number and see whether the total changes.
