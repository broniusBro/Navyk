::: step hook
Ирина, бухгалтер из Одессы, записала всё в одно место — в Instructions for Claude: «пиши просто», «отпуск в Турции 3 июля», «акт сверки оформляй по 12 правилам».

Теперь она спрашивает рецепт сырников, а Claude вдруг вспоминает про акт сверки и вылет. Что пошло не так?
:::

::: step explain
Правила Ирины разного масштаба, а лежат в одном месте. Instructions for Claude действуют в *каждом* разговоре, поэтому всё оттуда лезет везде.

У правила три возможных дома:

- {{data.ui_paths.settings_instructions}} — всё, что касается тебя в любом чате;
- *инструкции проекта* — правила одной темы, только в её чатах;
- *навык* — порядок действий для типа задач, достаётся по необходимости.
:::

  - left: "«Я бухгалтер, объясняй простыми словами, отвечай на русском»"
    right: "Instructions for Claude"
    why: "Это про Ирину в целом: язык и манера нужны в любом чате, от налогов до сырников."
  - left: "«Мы с мужем летим в Турцию 3 июля, помогай собрать всё к поездке»"
    right: "Инструкции проекта «Отпуск»"
    why: "Это важно только для темы отпуска. В проекте правило всегда под рукой, но в другие чаты не просачивается."
  - left: "«Акт сверки оформляй так: шапка, таблица взаиморасчётов, итог, подписи — и ещё 12 правил»"
    right: "Навык"
    why: "Это порядок действий для повторяющейся задачи. Навык откроется, когда Ирина попросит акт сверки, в каком бы чате она ни была."
hint: "Спроси про каждое правило: оно нужно везде, только в одной теме или только для определённой задачи?"
:::

::: step explain
Три вопроса, чтобы выбрать:

1. *Нужно в любом разговоре?* → Instructions for Claude.
2. *Нужно постоянно, но только в одной теме?* → инструкции проекта.
3. *Это способ сделать определённую задачу, и она встречается в разных местах?* → навык.

Их можно сочетать: проект «Работа» + навык «Акт сверки» прекрасно уживаются.
:::

::: step explain
На работе есть ещё один вариант. На планах {{data.plans.a5_org_skills_plans}} владелец организации в Claude может раздать навык всем сотрудникам: например, оформление по фирменному стилю. Тогда каждому сотруднику не нужно загружать его самому.
:::

::: step summary
**Везде — Instructions for Claude. Одна тема — инструкции проекта. Один тип задач в разных местах — навык.**

Не складывай всё в одно место: лишние правила мешают там, где они ни при чём.

Дальше: плагины — готовые наборы из навыков и коннекторов.
:::
