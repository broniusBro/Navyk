::: step hook
Dan from Cork writes to Claude:

```prompt
Here are my expenses for September. Turn them into an Excel spreadsheet with a chart by category.
```

A minute later, a real .xlsx file appears in the chat, ready to download and open. Dan didn't install anything or create any skills. So where did Claude get this ability?
:::

::: step explain
Anthropic, the company behind Claude, made *built-in skills* for four kinds of files:

- Excel — spreadsheets;
- Word — documents;
- PowerPoint — presentations;
- PDF — creating and processing.

You don't need to call them by name. Claude sees for itself that the task is about a spreadsheet and pulls out the right skill, just like in the last lesson.
:::

::: exercise match_pairs
id: "a5.2.e1"
type: "match_pairs"
question: "Which built-in skill will each prompt trigger?"
pairs:
  - left: "“Make a shift rota for November so I can filter by employee”"
    right: "Excel"
    why: "Filters, columns, formulas: that's a spreadsheet. Claude will build an .xlsx file."
  - left: "“Turn this garage rental agreement into a document I can print and sign”"
    right: "Word"
    why: "A text document for printing and editing is Word (.docx)."
  - left: "“Put together 8 slides on the quarter's results for the team meeting”"
    right: "PowerPoint"
    why: "Slides to present are PowerPoint (.pptx)."
  - left: "“Pull the price table out of this PDF price list”"
    right: "PDF"
    why: "The PDF skill doesn't just create files, it can process them too, for example extracting text and tables."
hint: "Think about what file you need at the end: a spreadsheet, a document, slides or a PDF."
:::

::: step explain
There's one condition: Claude needs code execution turned on. The file is built by a program inside an isolated “sandbox”.

Check here: {{data.ui_paths.a5_code_execution}}. The toggle is on by default. On a company work account, your admin controls it.

The list of skills with their toggles: {{data.ui_paths.a5_customize_skills}}. Claude won't use a skill that's switched off.
:::

options:
  - text: "Whether code execution and file creation is turned on"
    correct: true
    why: "Without it the built-in skills don't work and the skills section goes grey. On a work account, the toggle may have been turned off by the organisation's admin, so that's who to ask."
  - text: "Write the prompt in capital letters so Claude knows it's important"
    correct: false
    why: "Capital letters don't switch anything on. Claude already understood the task; what it lacks is a tool to create the file."
  - text: "Ask Claude to “try harder”"
    correct: false
    why: "Effort isn't the issue. While code execution is off, Claude simply has nothing to build a .pptx file with."
  - text: "Delete the account and create a new one"
    correct: false
    why: "Far too drastic, and it won't help: the toggle you need is in the settings. Deleting an account can't be undone; it's not something you do to fix a setting."
hint: "The explanation above mentioned one condition without which the built-in skills don't work."
:::

::: step explain
The skill knows *how* to build the file. But *what* goes in it is still decided by your prompt. “Make a presentation” with no facts gets you nice-looking but empty slides.

Everything you've learned about prompts still applies: goal, context, format.
:::

::: exercise find_error
id: "a5.2.e4"
type: "find_error"
question: "Dan asks for a presentation. Tap all the weak spots in his prompt."
prompt: "Make a PowerPoint presentation about the quarter's results. You must turn on the pptx skill and repeat its name three times or it won't work. Make it look nice."
segments:
  - text: "Make a PowerPoint presentation "
    weak: false
    why: "It's clear what file is needed. That's enough for Claude to use the built-in skill."
  - text: "about the quarter's results. "
    weak: true
    why: "What results? Whose? For whom? Without figures and an audience, Claude will fill the slides with generic statements. It needs facts: revenue, projects, who's watching."
  - text: "You must turn on the pptx skill and repeat its name three times or it won't work. "
    weak: true
    why: "Unnecessary: the built-in skill kicks in on its own, and repeating its name is pointless. That space is better spent on facts about the quarter."
  - text: "Make it look nice."
    weak: true
    why: "Everyone has their own idea of “nice”. Better to set the format: how many slides, what goes on each, whether there are charts, which colours."
hint: "Look for where facts are missing, where Dan explains to Claude something it would do anyway, and where the format isn't set."
:::

::: exercise improve_prompt
id: "a5.2.e5"
type: "improve_prompt"
question: "Improve the prompt so Claude makes a useful Excel file on the first try."
weak_prompt: "Make an expenses spreadsheet in Excel"
placeholder: "Make an Excel file where…"
ideas:
  - "What data: where the figures come from, what period"
  - "Which columns and sheets"
  - "What to calculate: totals, percentages, summaries"
  - "Whether you need a chart, and what kind"
  - "Why you need the spreadsheet"
min_chars: 60
hint: "Describe what data goes into the spreadsheet, which columns and totals you need, whether you want a chart and why you need the file. The skill will build the .xlsx; your job is the content."
review:
  task: "The learner improves the prompt “Make an expenses spreadsheet in Excel”. The lesson is about Claude's built-in skills: Claude builds the Excel file on its own if code execution is on, so there's no need to call the skill by name. The quality of the file depends on the prompt. A strong prompt: it's clear what spreadsheet to make and with what data (R1); there's context — where the data comes from, what period, why the spreadsheet is needed (R2); the format is set — columns, sheets, totals, chart (R3); it's clear what counts as a good result, e.g. “so I can see where most of the money goes” (R4). The learner may make up the data. If the learner asks Claude to repeat the skill's name or writes “you must turn on the skill”, gently say it isn't necessary."
  criteria: ["R1", "R2", "R3", "R4"]
  reference_prompt: |
    Make an Excel file to track spending for our family of three for October. I'll enter the expenses myself, so fill in 5 rows with examples.
    Columns: date, amount in euros, category (drop-down list: groceries, transport, bills, kids, going out, other), notes.
    On a second sheet: totals by category using formulas, each category's share of total spending, and a pie chart.
    The goal is to work out by the end of the month where we could save €100, so the biggest categories should stand out straight away.
  show_reference: true
  fallback_feedback:
    - "Is it clear what spreadsheet to make and what data will go in it?"
    - "Is the period stated, and where the figures come from?"
    - "Are the columns, sheets and calculations listed?"
    - "Does it say whether a chart is needed, and what kind?"
    - "Does it explain why you need the spreadsheet and what you want to learn from it?"
:::
