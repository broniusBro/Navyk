::: step hook
Claire, an accountant from Galway, put everything in one place, her Instructions for Claude: “keep it simple”, “holiday in Turkey on 3 July”, “format reconciliation statements using these 12 rules”.

Now she asks for a pancake recipe, and Claude suddenly brings up reconciliation statements and her flight. What went wrong?
:::

::: step explain
Claire's rules work at different scales, but they all sit in one place. Instructions for Claude apply in *every* conversation, so everything in there turns up everywhere.

A rule has three possible homes:

- {{data.ui_paths.settings_instructions}}: everything about you, in any chat;
- *project instructions*: rules for one topic, only in its chats;
- a *skill*: a procedure for a kind of task, pulled out when needed.
:::

::: exercise match_pairs
id: "a5.4.e1"
type: "match_pairs"
question: "Sort Claire's rules into the right places."
pairs:
  - left: "“I'm an accountant, explain things in plain words, use British spelling”"
    right: "Instructions for Claude"
    why: "This is about Claire in general: language and style matter in any chat, from tax to pancakes."
  - left: "“My husband and I fly to Turkey on 3 July, help me get everything ready for the trip”"
    right: "Project instructions for “Holiday”"
    why: "This only matters for the holiday topic. In a project the rule is always at hand, but it doesn't leak into other chats."
  - left: "“Format reconciliation statements like this: header, table of balances, total, signatures — plus 12 more rules”"
    right: "Skill"
    why: "This is a procedure for a recurring task. The skill will open whenever Claire asks for a reconciliation statement, whichever chat she's in."
hint: "Ask about each rule: is it needed everywhere, only in one topic, or only for a particular task?"
:::

::: step explain
Three questions to help you choose:

1. *Needed in every conversation?* → Instructions for Claude.
2. *Needed all the time, but only in one topic?* → project instructions.
3. *Is it a way of doing a particular task that comes up in different places?* → a skill.

You can combine them: a “Work” project plus a “Reconciliation statement” skill get along perfectly.
:::

::: exercise single_choice
id: "a5.4.e2"
type: "single_choice"
question: "Andrew writes sales proposals using his company's template. Sometimes in a specific client's project, sometimes in an ordinary chat. Where should the proposal formatting rules go?"
options:
  - text: "In a skill: it will open whenever Andrew asks for a proposal, in any chat and any project"
    correct: true
    why: "The rule is tied to a task, not a topic. A skill works across all of Claude and switches on only for proposals, so there's no need to copy it into every project."
  - text: "In the instructions of every client project"
    correct: false
    why: "He'd have to copy the same thing into every project and update it everywhere each time the template changes. And in an ordinary chat the rules wouldn't apply at all."
  - text: "In Instructions for Claude"
    correct: false
    why: "Then the proposal template would “hang around” in every conversation, even when Andrew is choosing a vacuum cleaner. That's extra context and a risk the format turns up where it doesn't belong."
  - text: "Nowhere: paste the template into the chat every time"
    correct: false
    why: "It works, but this is exactly the routine skills save you from. And it's easy to forget one of the rules."
hint: "Is the rule needed everywhere, in one topic, or for a particular task that comes up in different places?"
:::

    weak: true
    why: "A rule for one topic. It belongs in the Holiday project's instructions, so it won't pop up in work chats."
  - text: "When I ask for a reconciliation statement, format it using the 12 rules below. "
    weak: true
    why: "A long procedure for one task. That's a ready-made skill: it will load only when Claire asks for a statement, instead of taking up space in every chat."
  - text: "Use British spelling."
    weak: false
    why: "A general preference for all conversations. It stays in Instructions for Claude."
hint: "Keep only what's needed in every conversation. Anything about one topic or one task should move."

::: exercise multi_choice
id: "a5.4.e4"
type: "multi_choice"
question: "What's true about skills and projects? Select all that apply."
options:
  - text: "Project knowledge and instructions are loaded in every chat in that project, even when they aren't needed right now"
    correct: true
    why: "Yes, the help centre calls them static background knowledge. That's why you put things there that the topic needs all the time."
  - text: "A skill switches on only when the task fits it"
    correct: true
    why: "Yes. Until then Claude sees only its name and description, which is very little context."
  - text: "A skill and a project can be used together"
    correct: true
    why: "Yes. A “Client X” project holds the client's materials, while a “Proposal” skill knows how to format the proposal. The help centre says outright that the features can be combined."
  - text: "A skill only works inside one project"
    correct: false
    why: "No, a skill works across all of Claude: in any chat and any project where the task fits."
  - text: "The more rules in Instructions for Claude, the better"
    correct: false
    why: "No. Everything in there applies in every conversation. Extra rules get in the way in chats where they're irrelevant, like reconciliation statements in a pancake recipe."
hint: "Remember when each one loads: a project always in its own chats, a skill for a task, Instructions for Claude everywhere."
:::

::: step explain
At work there's one more option. On {{data.plans.a5_org_skills_plans}} plans, the organisation's owner in Claude can roll out a skill to every employee, for example one for the company's brand style. Then nobody has to upload it themselves.
:::

type: "single_choice"
question: "Olivia, a marketer at a company on a Claude work plan, wants all 30 employees to make presentations in the brand colours and fonts. What's the smartest move?"
options:
  - text: "Make a brand-style skill and ask the organisation's owner in Claude to roll it out to everyone"
    correct: true
    why: "The rule is for the “presentation” task, and everyone needs it. A skill from the organisation will show up for everyone, and it can be updated in one place."
  - text: "Send everyone the rules so each person pastes them into Instructions for Claude"
    correct: false
    why: "The presentation style would get in the way of every other conversation, and each update would mean asking 30 people to rewrite everything."
  - text: "Ask everyone to add the rules to every new chat"
    correct: false
    why: "Someone will forget, someone will paste an old version. This is exactly the routine skills save you from."
  - text: "Put the rules in the instructions of one of Olivia's projects"
    correct: false
    why: "Project instructions apply only in that project's chats. The other 29 employees won't see them."
hint: "The rule is needed by every employee and only for one task. Which tool fits a task and can be shared across the organisation?"
:::

::: step summary
**Everywhere: Instructions for Claude. One topic: project instructions. One kind of task in different places: a skill.**

Don't put everything in one place: extra rules get in the way where they're irrelevant.

:::
