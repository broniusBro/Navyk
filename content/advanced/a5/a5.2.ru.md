::: step hook
Дима из Харькова пишет Claude:

```prompt
Вот мои расходы за сентябрь. Сделай из них таблицу Excel с графиком по категориям.
```

Через минуту в чате появляется настоящий файл .xlsx: можно скачать и открыть. Дима ничего не устанавливал и навыков не создавал. Откуда у Claude это умение?
:::

::: step explain
Создатели Claude, компания Anthropic, сделали *встроенные навыки* для четырёх видов файлов:

- Excel — таблицы;
- Word — документы;
- PowerPoint — презентации;
- PDF — создание и обработка.

Звать их по имени не нужно. Claude сам видит, что задача про таблицу, и достаёт нужный навык, как в прошлом уроке.
:::

::: exercise match_pairs
id: "a5.2.e1"
type: "match_pairs"
question: "Какой встроенный навык сработает на каждый запрос?"
pairs:
  - left: "«Сделай график смен на ноябрь, чтобы я мог фильтровать по сотрудникам»"
    right: "Excel"
    why: "Фильтры, столбцы, формулы — это таблица. Claude соберёт файл .xlsx."
  - left: "«Оформи договор аренды гаража в документ, который можно распечатать и подписать»"
    right: "Word"
    why: "Текстовый документ для печати и правок — это Word (.docx)."
  - left: "«Собери 8 слайдов об итогах квартала для собрания отдела»"
    right: "PowerPoint"
    why: "Слайды для показа — это PowerPoint (.pptx)."
  - left: "«Вытащи таблицу с ценами из этого прайса в PDF»"
    right: "PDF"
    why: "Навык PDF умеет не только создавать файлы, но и обрабатывать их, например доставать текст и таблицы."
hint: "Думай о том, какой файл нужен на выходе: таблица, документ, слайды или PDF."
:::

::: step explain
Одно условие: у Claude должно быть включено выполнение кода. Ведь файл собирается программой в изолированной «песочнице».

Проверь: {{data.ui_paths.a5_code_execution}}. По умолчанию переключатель включён. В рабочем аккаунте компании им управляет администратор.

Список навыков с переключателями: {{data.ui_paths.a5_customize_skills}}. Выключенным навыком Claude не воспользуется.
:::

  - text: "Написать запрос заглавными буквами, чтобы Claude понял, что это важно"
    correct: false
    why: "Регистр букв ничего не включает. Claude и так понял задачу, ему не хватает инструмента для создания файла."
  - text: "Попросить Claude «постараться получше»"
    correct: false
    why: "Дело не в старании. Пока выполнение кода выключено, собрать файл .pptx ему просто нечем."
  - text: "Удалить аккаунт и создать новый"
    correct: false
    why: "Слишком радикально и не поможет: нужный переключатель есть в настройках. Удаление аккаунта — необратимое действие, к нему не прибегают ради настройки."
hint: "В объяснении выше было одно условие, без которого встроенные навыки не работают."
:::

    correct: false

:::

::: step explain
Навык знает, *как* собрать файл. Но *что* в нём будет, по-прежнему решает твой запрос. «Сделай презентацию» без фактов даст красивые, но пустые слайды.

Всё, что ты учил про запросы, работает и здесь: цель, контекст, формат.
:::

::: step explain
Теперь сам. Возьми свою настоящую задачу с таблицей: расходы семьи, график тренировок, учёт заказов. Данные можно придумать.

Navyk отправит твой запрос на разбор Claude.
:::

::: step summary
**Встроенные навыки Claude делают файлы Excel, Word, PowerPoint и PDF сами — нужно только включённое выполнение кода.**

Навык знает, как собрать файл, а что в нём будет, решает твой запрос.

Дальше: пишем свой навык без единой строчки кода.
:::
