::: step hook
Вика ведёт проекты для клиентов. Каждую пятницу она пишет им отчёт и каждый раз вставляет в чат одну и ту же простыню:

```prompt
Напиши отчёт клиенту. Помни: начинаем с главного за неделю, потом «сделано», «в работе», «что нужно от вас». На «вы», без жаргона, до 200 слов…
```

Двадцать пятниц подряд одно и то же. Можно ли один раз объяснить и больше не повторять?
:::

::: step explain
Можно. Для этого есть *навык* (skill) — папка с инструкциями, а иногда ещё с шаблонами и скриптами.

Представь опытного коллегу с полкой папок: «Как мы пишем отчёты», «Как оформляем презентации». Весь день он их не держит открытыми. Пришла задача про отчёт — достал нужную папку и сделал по ней.
:::

:::

::: step explain
Как Claude понимает, какую папку достать? У каждого навыка есть название и короткое описание. Claude видит только их — это как корешки на полке.

Если запрос подходит, Claude открывает инструкции. Дополнительные файлы читает, только когда они нужны. Это называется *постепенное раскрытие*: десяток навыков почти не тратит контекст, пока не понадобится.
:::

::: step explain
Не путай навык с тем, что ты уже знаешь:

- *проект* — фоновые знания, которые всегда загружены в чатах этого проекта;
- *Instructions for Claude* — общие правила для всех разговоров;
- *коннектор* — доступ к сервису, например к почте или диску.

Навык — порядок действий для задачи. Он включается по необходимости и работает не только внутри одного проекта.
:::

::: exercise match_pairs
id: "a5.1.e3"
type: "match_pairs"
question: "Соедини инструмент с тем, что он даёт Claude."
pairs:
  - left: "Проект"
    right: "Файлы и контекст одной темы, которые всегда под рукой в её чатах"
    why: "Проект — это рабочая папка темы: материалы ремонта, подготовки к экзамену. Они загружены в каждом чате проекта, даже если сейчас не нужны."
  - left: "Instructions for Claude"
    right: "Общие пожелания, которые действуют в каждом разговоре"
    why: "Например, «отвечай на русском, пиши просто». Это про тебя в целом, а не про конкретный тип задач."
  - left: "Навык"
    right: "Порядок действий для определённого типа задач, который Claude достаёт, когда задача подходит"
    why: "Отчёт клиенту, оформление презентации по фирменному стилю, протокол встречи. Пока такой задачи нет, навык почти не занимает места."
  - left: "Коннектор"
    right: "Доступ к внешнему сервису: почте, календарю, хранилищу файлов"
    why: "Коннектор даёт доступ к данным, а навык может научить, как этими данными пользоваться. Они хорошо работают вместе."
hint: "Спроси про каждый инструмент: он «всегда включён», «включён в одной теме», «включается под задачу» или «открывает доступ к сервису»?"
:::

::: step explain
Какие задачи стоит превратить в навык? Те, что повторяются и делаются по одним и тем же правилам. Навык заменяет ту самую простыню, которую ты копируешь в чат раз за разом.

Разовые задачи навык не ускорит: проще написать хороший запрос.
:::

  - text: "Делать презентации отдела в фирменных цветах и шрифтах компании"
    correct: true
    why: "Это классический пример из справки Claude: фирменный стиль один, а презентаций много."
  - text: "Превращать заметки со встреч в протокол: решения, задачи, ответственные, сроки"
    correct: true
    why: "Встреч много, а структура протокола одна. Навык избавит от объяснения формата каждый раз."
  - text: "Один раз придумать тост на свадьбу друга"
    correct: false
    why: "Это разовая задача. Хороший запрос с фактами о друге сработает лучше, чем навык, который больше не пригодится."
  - text: "Узнать сегодняшний курс евро"
    correct: false
    why: "Здесь нужны свежие данные, а не правила работы. Это задача для поиска, навык не знает, какой курс сегодня."
hint: "Ищи задачи, которые повторяются и каждый раз делаются одинаково."
:::

::: step explain
Теперь вспомни свою неделю. Какую задачу ты объясняешь Claude снова и снова? Опиши её так, чтобы из описания можно было сделать навык. Сам навык соберём через урок.

Navyk отправит твоё описание на разбор Claude.
:::

placeholder: "Каждую неделю я… Делать это нужно так: …"

  - "Для кого результат"
  - "Структура или шаблон результата"
  - "Тон и длина"
  - "Типичная ошибка, которой надо избегать"
min_chars: 80
hint: "Представь, что передаёшь эту задачу новому коллеге навсегда: когда за неё браться, что сделать, как должен выглядеть результат и почему именно так."
review:
  task: "Ученик описывает свою повторяющуюся задачу так, чтобы из описания можно было сделать навык Claude (папку с инструкциями, которую Claude открывает, когда задача подходит). Хорошее описание: понятно, что за задача и что на выходе (R1); есть контекст — для кого результат, когда задача возникает, почему правила именно такие (R2); задан вид результата — структура, тон, длина (R3); понятно, что такое хороший результат и чего избегать (R4). Бонус: ученик называет слова, которыми обычно просит эту задачу, — это пригодится для описания навыка. Не требуй формата SKILL.md: его ученик изучит позже. Если задача разовая, мягко подскажи, что навык окупается на повторяющихся задачах."
  criteria: ["R1", "R2", "R3", "R4"]
  reference_prompt: |
    Каждую пятницу я пишу клиентам отчёт о ходе их проекта (мы делаем сайты). Обычно прошу Claude так: «отчёт клиенту», «итоги недели для заказчика».
    Клиенты не технари и читают отчёт с телефона, поэтому важно коротко и без жаргона.
    Структура: одна фраза о главном за неделю, затем три блока — «Сделано», «В работе», «Что нужно от вас» (с конкретным сроком).
    Тон: на «вы», спокойный и уверенный. Если что-то задерживается, говорим об этом прямо и сразу предлагаем новый срок.

  show_reference: true
  fallback_feedback:

    - "Сказано ли, когда она возникает и какими словами ты её обычно просишь?"
    - "Указано ли, для кого результат и почему правила именно такие?"
    - "Описан ли вид результата: структура, тон, длина?"
    - "Ясно ли, что считается хорошим результатом и чего избегать?"
    - "Задача действительно повторяется? Навык окупается на том, что ты делаешь снова и снова."
:::

::: step summary
**Навык — папка с инструкциями для повторяющейся задачи. Claude видит только её название и описание и открывает её, когда задача подходит.**

Проект — знания темы, Instructions for Claude — правила для всех чатов, коннектор — доступ к сервису.

Дальше: навыки, которые уже встроены в Claude.
:::
