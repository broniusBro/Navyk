::: step hook
Олег работает в логистической компании. Заказы живут во внутренней системе, которой нет в каталоге.

Разработчики пишут ему в чат: «У нас есть MCP-сервер, вот адрес, подключай». Звучит как заклинание. Разберёмся, что это и куда этот адрес вставить.
:::

::: step explain
*MCP* (Model Context Protocol) — открытый стандарт, по которому ИИ-приложения подключаются к данным и инструментам. Его часто сравнивают с портом USB-C: один разъём для любых устройств.

*MCP-сервер* — программа, которая открывает сервис для ИИ. Если сервер работает в интернете, это *remote MCP*, удалённый сервер. Его можно подключить к Claude по адресу.
:::

::: step explain
Важная деталь: к серверу обращается *облако Anthropic*, а не твой компьютер.

Поэтому сервер должен быть доступен из публичного интернета. Адрес вида `localhost` или сервер во внутренней сети компании за VPN не подключится. Разве что администраторы откроют доступ для IP-адресов Anthropic.
:::

::: step summary
**Свой коннектор — это подключение к любому удалённому MCP-серверу по адресу. Сервер должен быть доступен из интернета, а доверие к нему — твоё решение.**

На работе с Team или Enterprise свой коннектор добавляет владелец организации в {{data.ui_paths.a4_org_connectors}}.

Дальше: почему много коннекторов — не всегда хорошо.
:::
