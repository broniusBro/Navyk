::: step hook
Dan works at a logistics company. Orders live in an internal system that isn't in the directory.

The developers message him: “We've got an MCP server, here's the URL, go ahead and connect it.” Sounds like a magic spell. Let's work out what it is and where that URL goes.
:::

::: step explain
*MCP* (Model Context Protocol) is an open standard that lets AI applications connect to data and tools. It's often compared to a USB-C port: one connector for any device.

An *MCP server* is a program that opens up a service to AI. If the server runs on the internet, it's a *remote MCP* server. You can connect it to Claude using its URL.
:::

::: step explain
An important detail: the server is contacted by *Anthropic's cloud*, not by your computer.

So the server has to be reachable from the public internet. A `localhost` address or a server on your company's internal network behind a VPN won't connect. Unless your admins open access for Anthropic's IP addresses.
:::

::: step summary
**Your own connector is a connection to any remote MCP server by its URL. The server has to be reachable from the internet, and whether to trust it is your call.**

At work on Team or Enterprise, custom connectors are added by the organisation owner in {{data.ui_paths.a4_org_connectors}}.

:::
