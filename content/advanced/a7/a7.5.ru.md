::: step hook
Ирина из Гданьска откликается на вакансию менеджера проектов:

```prompt
Напиши сопроводительное письмо на эту вакансию и проверь себя, чтобы было идеально.
```

```claude
Готово! Я перепроверил письмо — оно убедительное и полностью соответствует вакансии.
```

Но в вакансии просили опыт с Jira и английский, а в письме об этом ни слова. «Проверь себя» не сработало. Почему?
:::

::: step explain
Claude проверял, не зная *по чему* проверять, и всё это внутри одного ответа.

Anthropic описывает надёжный шаблон — *самокоррекцию* в три шага:

1. **Черновик.**
2. **Критика по критериям:** Claude сверяет черновик с конкретным списком.
3. **Доработка:** Claude исправляет текст по этой критике.

В API это три отдельных вызова. В чате — три отдельных сообщения: ты видишь критику до правки.
:::

::: exercise order_steps
id: "a7.5.e1"
type: "order_steps"
question: "Расставь шаги самопроверки письма Ирины по порядку."
shuffle: true
items:
  - text: "Попросить черновик письма, приложив текст вакансии"
    why: "Сначала нужен материал для проверки. Не надо требовать идеала с первого раза."
  - text: "Попросить критику по списку: Jira, английский, 3 факта из опыта, до 200 слов"
    why: "Критерии — сердце метода. Без них «проверь» превращается в «похвали»."
  - text: "Прочитать критику и убрать замечания, с которыми не согласна"
    why: "Ради этого шаги и разделены: ты видишь промежуточный результат и можешь вмешаться до правки."
  - text: "Попросить переписать письмо по оставшимся замечаниям"
    why: "Доработка опирается на конкретную критику, а не на «сделай лучше»."
hint: "Нельзя критиковать то, чего нет, и нельзя исправлять по критике, которую ещё не написали."
:::

::: step explain
Две ловушки критики.

**Без критериев** Claude не знает, что важно, и хвалит.

**«Найди как можно больше недостатков»** — обратная крайность. Создатели Claude предупреждают: кого попросили искать недочёты, тот найдёт их и в хорошей работе. Если гоняться за каждым, текст раздувается. Проси отмечать только то, что нарушает критерии.
:::

::: exercise single_choice
id: "a7.5.e2"
type: "single_choice"
question: "Какое сообщение для шага «критика» лучше?"
options:
  - text: "«Сверь письмо с критериями: упомянут опыт с Jira; сказано про уровень английского; есть 3 факта из опыта с цифрами; до 200 слов. Отметь только то, что нарушает эти пункты, по каждому — одна фраза. Пока не переписывай»"
    correct: true
    why: "Есть конкретные критерии, ограничение «только нарушения» и формат критики. «Пока не переписывай» сохраняет шаги раздельными: Ирина сначала увидит замечания."
  - text: "«Проверь письмо и сделай его идеальным»"
    correct: false
    why: "Это то, с чего начала Ирина. Нет критериев — нечего сверять. И проверка сразу смешана с правкой."
  - text: "«Найди в письме как можно больше недостатков, минимум 10»"
    correct: false
    why: "Claude найдёт 10, даже если письмо хорошее. Часть замечаний будет придиркой, и правка по ним испортит текст."
  - text: "«Ты строгий HR. Оцени письмо по шкале от 1 до 10»"
    correct: false
    why: "Роль хорошая, но цифра без критериев ничего не скажет: что именно исправлять, чтобы стало 9?"
hint: "Ищи вариант с конкретным списком, ограничением на замечания и без немедленной правки."
:::

::: step explain
Не всё нужно делать в три сообщения.

- *Простая задача:* хватит фразы в конце запроса: «Перед тем как закончить, проверь ответ по критериям: …». Так советует гайд.
- *Важный текст:* три шага в отдельных сообщениях.
- *Нужен непредвзятый взгляд:* критику проведи в новом чате. Создатели Claude отмечают, что со свежим контекстом он не цепляется за то, что сам только что написал.
:::

  - left: "Письмо инвестору, от которого зависит раунд"
    right: "Три шага отдельными сообщениями: черновик, критика, доработка"
    why: "Ставки высокие, поэтому стоит увидеть критику до правки и выкинуть лишние замечания."
  - left: "Claude три раза правил свой текст и уже защищает его"
    right: "Критика в новом чате: только текст и критерии"
    why: "Свежий контекст: Claude видит текст и критерии, а не историю того, как он их писал."
hint: "Смотри на ставки и на то, насколько Claude «втянут» в свой текст."
:::

::: step explain
Теперь сам. Возьми текст, который скоро отправишь: резюме, письмо, пост, КП, отчёт.

Напиши сообщение для *второго шага* — критики. Черновик уже есть, его текст замени на «…». Navyk отправит твоё сообщение на разбор Claude.
:::

::: step summary
**Черновик → критика по критериям → доработка. Три шага, не один.**

Давай конкретные критерии, проси отмечать только нарушения и читай критику до правки. Для простых задач хватит фразы «перед ответом проверь по критериям…».
