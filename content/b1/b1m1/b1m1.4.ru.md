::: step hook
Вечер у польских друзей. Кто-то спрашивает:

```pl
Opowiedz, jak trafiłeś do Polski! | Расскажи, как ты оказался в Польше!
```

Все смотрят на тебя. Сегодня собираем всё, что знаешь о виде глагола, в одну живую историю — с началом, поворотом и финалом.
:::

::: step explain
Скелет любой истории — **связки** плюс правильный вид:

```pl
Na początku wszystko szło dobrze. | Сначала всё шло хорошо.
W pewnym momencie zgubiłem paszport. | В какой-то момент я потерял паспорт.
Okazało się, że leżał w samochodzie. | Оказалось, что он лежал в машине.
Na szczęście udało mi się zdążyć. | К счастью, мне удалось успеть.
```

*Okazało się* и *udało się* — безличные формы со *się*: дословно «оказалось», «удалось мне». Почти как в русском.
:::

  - options:

      - { text: "postałem", correct: false, why: "Postać — «постоять немного». С «przez trzy godziny» звучит странно, как «три часа постоял» в смысле «чуть-чуть»." }
      - { text: "stanąłem", correct: false, why: "Stanąć — «встать», одно мгновенное действие. Три часа нельзя «встать»." }
  - options:
      - { text: "kupiłem", correct: true, why: "W końcu + результат: билет куплен. Совершенный вид kupiłem." }
      - { text: "kupowałem", correct: false, why: "Kupowałem — процесс покупки без результата. После «w końcu» ждём финала." }
      - { text: "kupię", correct: false, why: "Будущее время не подходит для истории о прошлом." }

::: step explain
Чтобы история звучала живо, **слушатель тоже говорит**. Полезные реакции и вопросы:

```pl
Serio? I co dalej? | Серьёзно? И что дальше?
No i jak to się skończyło? | Ну и чем это кончилось?
Nie wierzę! | Не может быть!
Ale miałeś pecha! | Ну тебе и не повезло!
```

*Pech* [пэх] — «невезение», *mieć pecha* — «не повезти». Пишется *pech*, а в родительном — *pecha*.
:::

::: step summary
**История = фон (несовершенный вид) + события (совершенный) + связки.**

Скелет: *zdarzyło mi się… → na początku… → w pewnym momencie… → okazało się, że… → na szczęście / niestety… → na koniec…*

Модуль про вид глагола пройден! Дальше: как выражать мнение — *moim zdaniem…*
:::
