::: step hook
Vicky asked Claude for a birthday message for a colleague and got a text that was almost right. It's just too formal.

She opens a new chat and types the whole prompt again. Then again. And again.

She could have sent one short message in the same chat. Let's see how.
:::

::: step explain
Talking to Claude is a *conversation*: it remembers what you've discussed in this chat. So there's no need to repeat everything from scratch.

Like a fitting at the tailor's: you don't make a new suit, you say “take this up by two centimetres”.

Type exactly what to change in the message box {{data.ui_paths.chat_input}}, and Claude will fix it.
:::

::: exercise single_choice
id: "b2.7.e1"
type: "single_choice"
question: "Claude wrote Vicky a birthday message, but it's too formal. Which next message is best?"
options:
  - text: "“Make it simpler and warmer, like it's from a colleague I have lunch with. Keep the coffee joke, drop ‘wishing you continued professional success’”"
    correct: true
    why: "It's a specific correction: what to change (the tone), what it should be (like from a colleague), what to keep and what to drop. Claude will fix exactly that and leave the rest alone."
  - text: "“That's not it, redo it”"
    correct: false
    why: "Claude doesn't know what exactly is wrong. It'll rewrite everything at random and may end up even further off. Remember the colleague test: they'd ask “what's wrong with it?”."
  - text: "Delete the chat and type the same prompt again in a new one"
    correct: false
    why: "The answer was almost right, and in a new chat Claude can't see it. The same prompt will give a similar result, and you'll lose the good coffee joke."
  - text: "“You did a bad job”"
    correct: false
    why: "A judgement without directions. Claude will apologise and guess at a new version. Better to say straight away what the text should be like."
hint: "A good correction answers: what to change, how it should be, and what to keep."
:::

::: step explain
Another option is *editing in place*. When Claude writes a long draft (a plan, a report, a letter), it can open next to the chat.

Highlight the part you want, write your edit, and Claude will change only that part. Like a note in the margin: “shorten this paragraph”.

Handy when the whole text is good and there's just one bit you don't like.
:::

::: exercise single_choice
id: "b2.7.e2"
type: "single_choice"
question: "Claude wrote Nathan a 5-day hiking plan for the Scottish Highlands. It's all great, but day three has too much walking. What's the best thing to do?"
options:
  - text: "Highlight day three in the draft and write: “Make this an easy day: no more than 8 km, with lunch by the loch”"
    correct: true
    why: "Editing in place changes only the section you need. The other four days stay as they are, and you won't have to check the whole plan again."
  - text: "Ask: “Rewrite the whole plan”"
    correct: false
    why: "The good days will change too, and you'll have to check everything from scratch. If you don't like one part, fix one part."
  - text: "Start a new chat and describe the trip again"
    correct: false
    why: "The plan is almost done, and the new chat can't see it. That's extra work and uses up more of your limits."
  - text: "Leave it as it is: Claude knows best"
    correct: false
    why: "You know your own fitness better than Claude does. If something doesn't suit you, say so: that's what the conversation is for."
hint: "You like almost everything except one small bit. Which option changes only that?"
:::

::: exercise order_steps
id: "b2.7.e3"
type: "order_steps"
question: "Put in order how to get Claude's answer just right."
shuffle: true
items:
  - text: "Send a well-thought-out prompt: goal, context, format"
    why: "The better the first prompt, the fewer corrections later. This is everything you've learned in this module."
  - text: "Read the answer and pin down what exactly is wrong"
    why: "First understand the problem: tone, length, a fact, one paragraph? Without that, your correction is a guess."
  - text: "Write a specific correction, or highlight a section and edit it in place"
    why: "One message, one clear correction: what to change, how it should be, what to keep."
  - text: "Check the new version"
    why: "Make sure the correction worked and nothing good got lost."
  - text: "If it's still wrong after two corrections, start a new chat with an improved prompt"
    why: "This is the last step, for when corrections don't help: the chat is cluttered with failed attempts, and a clean start with a better prompt usually works better."
hint: "A good prompt first; a backup plan at the end in case corrections don't help."
:::

::: step explain
Sometimes corrections don't help. You've corrected the same thing twice, and Claude still gets it wrong.

By then the chat is cluttered with failed attempts. Better to open {{data.ui_paths.new_chat}} and write one improved prompt: include everything you learned from the corrections.

A new, unrelated task is also a reason to start a new chat.
:::

::: exercise single_choice
id: "b2.7.e4"
type: "single_choice"
question: "For the third time, Karen asks Claude to make an expenses table in euros, and it uses dollars again. What's the best thing to do?"
options:
  - text: "Open a new chat and write the full prompt straight away: “Expenses table in euros, columns: date, category, amount in €”"
    correct: true
    why: "After two failed corrections, the old chat gets in the way: it's full of “wrong” tables. A new chat with a precise prompt that includes everything Karen has learned usually solves the problem first time."
  - text: "Write the same thing a fourth time, in caps lock"
    correct: false
    why: "Volume doesn't help. The problem is that the conversation is already tangled, not that Claude didn't hear."
  - text: "Keep correcting until it works"
    correct: false
    why: "Every new attempt adds another wrong table to the chat and uses up your limits. After two corrections, starting over is cheaper and faster."
  - text: "Decide that Claude can't make tables"
    correct: false
    why: "It can. Usually the issue is a tangled conversation. A clean start with a clear prompt proves it."
hint: "How many times has Karen already corrected it? Remember the two-corrections rule."
:::

::: exercise single_choice
id: "b2.7.e5"
type: "single_choice"
question: "Vicky has finished the birthday message and wants to ask Claude for a lasagne recipe for dinner. Where's the best place to ask?"
options:
  - text: "In a new chat: it's a different task"
    correct: true
    why: "The birthday message and lasagne have nothing to do with each other. In a new chat, Claude isn't distracted by the old conversation, and it's easier for you to find both chats later."
  - text: "In the same chat, right after the birthday message"
    correct: false
    why: "You can, but the extra context doesn't help: a long conversation about different things uses more of your limits, and Claude may latch onto the old topic."
  - text: "In the same chat, but ask it to forget the birthday message first"
    correct: false
    why: "It's simpler and more reliable to open a new chat than to ask Claude to “forget” something. New task, new chat."
hint: "Are these two tasks related?"
:::

::: step summary
**A good answer often comes out of a conversation.**

Correct specifically: what to change, how it should be, what to keep. Don't like one bit? Edit it in place. After two failed corrections, or for a new task, open a new chat.

Next up: the module test, where you'll put it all together.
:::
