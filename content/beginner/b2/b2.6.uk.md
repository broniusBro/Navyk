::: step hook
Ліза відкриває кав'ярню в Києві й просить назву:

```prompt
Придумай 5 назв для кав'ярні. Хочеться чогось теплого й незвичайного.
```

```claude
1. Coffee Time
2. Затишна чашка
3. Кавовий куточок
4. Aroma
5. Ранок
```

«Тепле й незвичайне» Ліза уявляє зовсім не так. Як їй пояснити, що вона має на увазі?
:::

::: step explain
Стиль важко описати словами. «Незвичайне» для Лізи і для Claude — різне.

Зате його легко *показати*. Як у перукарні: простіше показати фото стрижки, ніж пояснювати «коротше, але не надто».

Творці Claude називають приклади одним із найнадійніших способів задати формат і тон відповіді.
:::

::: step explain
Правила хорошого прикладу:

- *схожий* на те, що потрібно: приклад назви для назв, приклад допису для дописів;
- *різні* між собою: якщо обидва приклади про бабусю, Claude вирішить, що бабуся обов'язкова;
- *відокремлений* від прохання: «Ось приклади, які мені подобаються:».

Почати можна з 1–2 прикладів. Для найкращого результату Anthropic радить 3–5.
:::

::: exercise single_choice
id: "b2.6.e2"
type: "single_choice"
question: "Остап хоче, щоб Claude придумав підписи до фото його собаки в Instagram. Яка пара прикладів краща?"
options:
  - text: "«Охороняю диван від небезпечних подушок» і «Понеділок? Не чув»"
    correct: true
    why: "Приклади різні: один про дім, інший про настрій. Але стиль один: короткий жарт від імені собаки. Claude зрозуміє саме стиль, а не тему."
  - text: "«Охороняю диван від подушок» і «Охороняю ліжко від ковдр»"
    correct: false
    why: "Приклади надто схожі. Claude може вирішити, що кожен підпис має починатися з «Охороняю…», і видасть десять однакових жартів."
  - text: "«Мій пес дуже милий» і «Гарна фотографія»"
    correct: false
    why: "У прикладах немає того стилю, який потрібен Остапові. Claude повторить і нудний тон, бо він наслідує приклади."
  - text: "Краще без прикладів, Claude сам зрозуміє"
    correct: false
    why: "Іноді зрозуміє, але «смішно» для кожного своє. Пара прикладів — найшвидший спосіб показати, який гумор тобі до вподоби."
hint: "Хороші приклади схожі стилем, але не темою і не словами."

      - text: "текст"
        correct: false
        why: "Так Claude може вирішити, що цей текст треба просто повторити або відредагувати. Слово «приклад» точніше."
      - text: "наказ"

        why: "Це не наказ, а зразок. Важливо, щоб Claude зрозумів: брати треба стиль."

        correct: true
        why: "Це прохання взяти стиль прикладу і змінити зміст. Так три SMS будуть різними, а не копією одного."
      - text: "точнісінько так само"
        correct: false

      - text: "не так, як у прикладі"
        correct: false
        why: "Це суперечить самому прикладу, та ще й це заборона, а не опис."
  - options:
      - text: "не довшим за 160 символів, щоб умістилося в одне SMS"

        correct: false
        why: "Це заборона без міри. Скільки символів? Для SMS це важливо."

        correct: false

::: step explain
Тепер твоя черга. Попроси Claude придумати 5 назв для кав'ярні й покажи 2 приклади стилю, який тобі подобається.

Приклади можеш вигадати або взяти назви знайомих місць. Головне, щоб вони були різними. Navyk надішле запит на розбір.
:::

::: step summary
**Не можеш описати стиль — покажи його на 1–2 різних прикладах.**

Скажи, що це зразки, і що в них подобається. Claude візьме стиль, а не слова.

Далі: як продовжувати розмову, якщо відповідь не ідеальна.
:::
