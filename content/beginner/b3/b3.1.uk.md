::: step hook
Оксані зі Львова надійшли нові умови від інтернет-провайдера: PDF на шість сторінок дрібним шрифтом. Передруковувати його вона не стала, а просто прикріпила файл до повідомлення.

```prompt
[прикріплено файл: umovy_taryfu.pdf]
Це нові умови від мого інтернет-провайдера. Що зміниться для мене з листопада і чи треба щось робити? Відповідай списком, 3–5 пунктів.
```

```claude
Що зміниться з 1 листопада:
- Абонплата за тарифом «Домашній 100» зростає зі 180 до 220 грн на місяць (розділ 2).
- Швидкість залишається та сама, 100 Мбіт/с.
- Роутер провайдера тепер оплачується окремо, 30 грн на місяць (п. 3.4).
- Робити нічого не треба, нові умови почнуть діяти самі. Якщо ти не згодна, за п. 5.1 договір можна розірвати, попередивши за 14 днів.
```

Шість сторінок, а відповідь забрала пів хвилини. Розберімося, як це зробити.
:::

::: step explain
*Завантажити файл* означає прикріпити його до повідомлення, як фото до електронного листа. Claude прочитає файл разом із твоїм запитанням.

Підходять документи (PDF, DOCX, таблиці, текст) і зображення (фото, скриншоти). Повний список форматів: {{data.limits.file_types}}.
:::

::: step explain
Прикріпити файл можна трьома способами:

1. Натисни {{data.ui_paths.attach_button}} у полі введення й вибери {{data.ui_paths.add_files}}.
2. Перетягни файл мишею просто у вікно чату.
3. Скопіюй картинку чи скриншот і встав у поле введення (Ctrl+V).

Потім напиши запитання й натисни {{data.ui_paths.send}}.
:::

shuffle: true
items:
  - text: "Відкрити чат із Claude"
    why: "Файл прикріплюють до повідомлення в чаті. Для нового запитання зручніше новий чат, щоб старі теми не заважали."
  - text: "Натиснути кнопку додавання файлу в полі введення й вибрати договір"
    why: "Це перший крок завантаження. Замість кнопки можна перетягнути файл у вікно чату, результат той самий."
  - text: "Переконатися, що файл прикріпився до повідомлення"
    why: "Швидка перевірка, що Claude отримає файл. Інакше він відповість «загалом», не бачачи договору."
  - text: "Написати запитання щодо файлу"
    why: "Файл без запитання нічого не каже про твою мету. Запитання пояснює, що саме шукати в договорі."
  - text: "Надіслати повідомлення"
    why: "Файл і запитання надходять разом, тому Claude відповідає з урахуванням документа."
hint: "Надсилання завжди в самому кінці. Перед запитанням файл уже має бути прикріплений."
:::

    correct: false

    correct: false

::: step explain
Файл без запитання — це як принести папери юристові й мовчки піти. Скажи, що тобі потрібно від документа. Порівняй:

```prompt
Подивись
```

```prompt
Це розклад уроків сина на друге півріччя. У які дні в нього 7 уроків і він закінчує пізніше 14:30?
```

У другому випадку Claude знає, що шукати.
:::

  - text: "«Перевір»"

::: step explain
Claude отримує файл цілком, з усім умістом. Перед завантаженням переглянь його: чи немає там чужих паспортних даних, номерів карток, телефонів і адрес.

Якщо для запитання вони не потрібні, замалюй їх або завантаж тільки потрібні сторінки. Чужих особистих даних без потреби не надсилай.
:::

::: step summary
**Прикріпи файл і постав щодо нього конкретне запитання.**

Способи: кнопка додавання файлу, перетягування або вставлення картинки. Перед завантаженням прибери чужі особисті дані, які для запитання не потрібні.

Далі: скільки і яких файлів можна завантажити.
:::
