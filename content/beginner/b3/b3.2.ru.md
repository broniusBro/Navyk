::: step hook
Марко из Варшавы загружает в Claude правила своего жилого комплекса. Это скан-сборник на сотни страниц с приложениями. На экране появляется ошибка **Uploaded file is too large** (загруженный файл слишком большой).

Файл не прошёл. Почему так бывает и что теперь делать?
:::

::: step explain
У загрузки есть *лимиты* — ограничения, как вес багажа в самолёте. Сейчас в одном чате действуют такие:

- файлов в одном чате: {{data.limits.chat_files_per_chat}};
- размер одного файла: {{data.limits.chat_file_size}};
- страниц в PDF: {{data.limits.pdf_pages_max}};
- размер картинки: {{data.limits.image_max_px}}.

Лимиты меняются. Navyk проверяет их по справке Claude.
:::

::: step explain
Важная тонкость. В небольшом PDF (до {{data.limits.pdf_visual_pages}}) Claude видит и текст, и картинки: графики, таблицы-сканы, схемы. В PDF длиннее он читает *только текст*.

С DOCX, TXT и другими не-PDF файлами так всегда: Claude берёт из них только текст, а вставленные картинки не видит.
:::

::: exercise single_choice
id: "b3.2.e1"
type: "single_choice"
question: "Марко нужен ответ только про парковку и шум после 22:00. Что ему лучше сделать с огромным сборником правил?"
options:
  - text: "Сохранить нужные разделы в отдельный небольшой PDF и загрузить его"
    correct: true
    why: "Справка Claude советует делить большие документы на части. Бонус: в маленьком файле Claude быстрее найдёт нужное и меньше отвлечётся на лишние сотни страниц."
  - text: "Загружать тот же файл снова, пока не пройдёт"
    correct: false
    why: "Лимит не случайный сбой. Файл больше допустимого, и от повторов он не уменьшится."
  - text: "Сделать вывод, что Claude не работает с документами"
    correct: false
    why: "Работает, просто у загрузки есть пределы. Документ нужно уменьшить, а не отказываться от помощи."
  - text: "Спросить Claude про правила ЖК, не прикладывая файл"
    correct: false
    why: "Правила конкретного комплекса Claude не знает. Без документа он ответит общими словами или ошибётся."
hint: "Справка Claude советует одно простое действие для слишком больших документов."
:::

  - text: "Claude вообще не умеет читать графики"
    correct: false
    why: "Умеет, если график в картинке или в небольшом PDF. Проблема в длине файла, а не в графиках."
  - text: "Ольга неправильно задала вопрос"
    correct: false
    why: "Вопрос тут ни при чём. Даже идеальный вопрос не поможет, если картинку из длинного PDF Claude не получил."
  - text: "График слишком цветной"
    correct: false
    why: "Цвета не мешают. Дело в том, что из длинного PDF Claude берёт только текст."
hint: "Вспомни, чем короткий PDF отличается от длинного для Claude."
:::

  - text: "Написать в вопросе «посмотри на картинку внимательнее»"
    correct: false
    why: "Просьба не поможет: картинка из DOCX к Claude просто не попала. Он не может посмотреть на то, чего не получил."
  - text: "Переименовать файл, чтобы в названии было слово «схема»"
    correct: false
    why: "Название файла не меняет его содержимое. Картинка всё равно не будет прочитана."
  - text: "Загрузить тот же DOCX ещё раз в новом чате"
    correct: false
    why: "Новый чат не поможет: из DOCX снова будет извлечён только текст."
hint: "Подумай, какой формат Claude читает целиком, вместе с картинками."

::: step summary
**У загрузки есть лимиты, а длинный PDF Claude читает без картинок.**

Большой файл раздели и загрузи нужные части. Нужна графика — дай короткий PDF или скриншот. Текущие лимиты Navyk показывает по справке Claude.
