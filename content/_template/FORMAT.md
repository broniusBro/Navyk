# Формат урока brolingvo · polski

Файл: `content/{level}/{module}/{lesson_id}.ru.md`, например `content/a1/a1m2/a1m2.3.ru.md`.
Язык объяснений — русский (ru), изучаемый язык — польский. Обращение к ученику на «ты», тепло и коротко.
Шапка YAML между `---`, дальше блоки `:::`. Один блок = один экран.

## Шапка

```yaml
---
id: "a1m2.3"              # совпадает с course.json и именем файла
lang: "ru"
level: "a1"               # a1 | a2 | b1
module: "a1m2"
title: "Skąd jesteś?"     # как в course.json
goal: "После урока ты сможешь сказать, откуда ты, и спросить собеседника."
duration_min: 5           # 3..6
prerequisites: []
free_preview: false       # true только у модуля a1m1
volatile: false
verified_at: "2026-11-04"
vocab:                    # 6–12 новых слов урока: попадают в словарь ученика и повторения
  - { pl: "skąd", ru: "откуда" }
  - { pl: "jestem z…", ru: "я из…" }
repeat:                   # интервальное повторение: какие упражнения вернуть и когда
  - concept: "skad_jestes"
    exercises: ["a1m2.3.e1", "a1m2.3.e4"]
    schedule:
      - { day: 1, type: single_choice }
      - { day: 3, type: build_sentence }
      - { day: 7, type: type_answer }
---
```

## Экраны-объяснения

```
::: step hook | explain | summary
Текст Markdown, не больше 60 слов повествования.

```pl
Dzień dobry! | Добрый день!
Jestem z Ukrainy. | Я из Украины.
```
:::
```

- Блок ```pl — карточки фраз: `польский | перевод`, по одной в строке. У каждой — кнопка озвучки.
  Пиши только настоящий, естественный польский; каждая фраза ≤ 12 слов.
- Транскрипцию даём кириллицей в скобках в тексте объяснения, а не в блоке pl: *cz* как [ч], *sz* как [ш].
- Жирным выделяем правило, курсивом — польские слова в русском тексте.
- `hook` — первый экран (живая ситуация из жизни в Польше), `summary` — последний (правило + что дальше).

## Упражнения: `::: exercise <type>` (тело — строгий YAML)

Общие поля: `id` (`<lesson>.e<N>`), `type`, `question`, `hint` (обязательно, не раскрывает ответ).
Необязательно: `audio: "польский текст"` — кнопка озвучки над заданием; `audio_only: true` — текст аудио не
показывается (аудирование). Правило автономности: у каждого варианта/пары/слова есть `why`.
В уроке 5–8 упражнений, минимум 4 разных типа. Строки в двойных кавычках, внутри — «ёлочки».

### single_choice / multi_choice
```yaml
options:
  - { text: "Jestem z Polski.", correct: true, why: "…" }
  - { text: "Jestem Polska.", correct: false, why: "…" }
```

### match_pairs
```yaml
pairs:
  - { left: "dziękuję", right: "спасибо", why: "…" }   # 3–6 пар
```

### fill_gap
```yaml
text: "Ja ___ z Ukrainy."            # каждый ___ = элемент gaps по порядку
gaps:
  - options:
      - { text: "jestem", correct: true, why: "…" }
      - { text: "jest", correct: false, why: "…" }
```

### order_steps — расставить реплики диалога или шаги по порядку
```yaml
items:                                 # в верном порядке
  - { text: "Dzień dobry!", why: "…" }
```

### build_sentence — собрать фразу из слов-плашек
```yaml
translation: "Я из Украины."           # что собрать
words: ["Jestem", "z", "Ukrainy."]     # верный порядок; знаки препинания приклеены к слову
extra: ["jest", "Ukraina"]             # 0–3 слова-ловушки
accept: [["Z", "Ukrainy", "jestem."]]  # необязательно: другие верные порядки
why: "Объяснение порядка слов и формы."
```

### type_answer — написать по-польски (проверка без ИИ)
```yaml
prompt: "Напиши по-польски: «Спасибо, до свидания!»"
accept: ["Dziękuję, do widzenia!", "Dziękuję i do widzenia!"]   # все верные варианты
why: "…"
```
Проверка игнорирует регистр, пробелы и знаки препинания. Ответ без польских букв (dziekuje)
засчитывается с замечанием про диакритику.

### speak — скажи вслух (распознавание речи pl-PL; без микрофона — «послушай и повтори»)
```yaml
phrase: "Dzień dobry"
translation: "Добрый день"
tip: "[дзѐнь до́бры] — ń мягкое, как в слове «день»."
why: "…"
```

### translate — перевод с проверкой ИИ-помощника
```yaml
source: "Меня зовут Анна, я из Киева."
accept: ["Mam na imię Anna, jestem z Kijowa.", "Nazywam się Anna, jestem z Kijowa."]
review:
  task: "Ученик A1 переводит фразу знакомства. Важно: mam na imię / nazywam się, z + родительный (z Kijowa)."
  focus: ["mam na imię / nazywam się", "z + родительный падеж"]
  fallback_feedback:                   # чек-лист самопроверки, если ИИ недоступен
    - "Есть ли «mam na imię» или «nazywam się»?"
    - "После «z» город в родительном: z Kijowa, z Warszawy."
```
Точное совпадение с `accept` засчитывается сразу, без ИИ. Иначе ИИ-помощник разбирает ответ.

### dialog — ролевой разговор с ИИ-собеседником (последнее упражнение урока «Разговор…», можно и в других)
```yaml
scenario:
  title: "W kawiarni"
  setting: "Ты в кафе в Кракове. Закажи кофе и круассан и попроси счёт."
  partner: "Kelnerka Ola, 25 lat, przyjazna, mówi prosto i powoli."   # роль ИИ, по-польски
  opener: "Dzień dobry! Co podać?"                                    # первая реплика ИИ
  goals:                                # 2–4 цели, ИИ отмечает выполненные
    - "Поздороваться"
    - "Заказать напиток через «poproszę»"
    - "Попросить счёт"
  vocab: ["poproszę", "kawa", "rachunek"]
  max_turns: 8
sample:                                 # образец разговора: показывается без ИИ и после разговора
  - { who: "partner", pl: "Dzień dobry! Co podać?", ru: "Добрый день! Что подать?" }
  - { who: "you", pl: "Dzień dobry! Poproszę kawę.", ru: "Добрый день! Мне кофе, пожалуйста." }
```

## Качество (проверяет методист и CI)
- Польский — живой и правильный, с диакритикой; никакого «русского калька» без пометки.
- Объясняем через сравнение с русским (и украинским, где помогает): похожие слова, ложные друзья.
- Каждое новое слово встречается в уроке минимум 3 раза в разных упражнениях.
- Не больше одной новой грамматической идеи на урок.
